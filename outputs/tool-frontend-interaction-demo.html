工具使用门槛 · 交互原型

以「文本检测」工具页为例，演示免费和积分两种使用门槛的完整交互流程

模式 A 完全免费

  • 不展示额度/积分信息，或仅展示「免费使用」标识
  • 点击「立即检测」直接执行，无二次确认
  • 可无限次使用，按钮始终可用

模式 B 积分使用

  • 后台可配置每日免费次数（如 3 次/天）和单次消耗积分（如 10 积分/次）
  • 顶部展示「今日免费剩余 X/Y」+ 当前积分余额
  • 有免费次数 → 直接检测，消耗 1 次免费额度
  • 免费用完 → 点击检测弹出确认：「本次将消耗 N 积分」
  • 积分不足 → 按钮仍可点，弹窗引导充值/做任务
交互流程（模式 B）
① 进入页面 → 读取今日已用次数 & 积分余额 → 渲染额度条
② 点击「立即检测」→ 校验输入 → 判断免费/付费路径
③ 免费路径：直接检测 → Toast「检测完成，今日免费剩余 X 次」
④ 付费路径：弹窗确认消耗积分 → 确认后检测 → 扣积分 → 展示结果
⑤ 积分不足：弹窗「积分不足，去充值 / 做任务赚积分」
当前场景：完全免费 — 点击「立即检测」直接出结果，无额度限制
