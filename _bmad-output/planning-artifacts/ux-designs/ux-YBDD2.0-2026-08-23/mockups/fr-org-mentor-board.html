FR-011 · 导师迭代V1.0

这是纯后台能力：看板只看数，导师管理才能改人

本轮交付机构导师看板和导师管理。没有 C 端页面。看板按机构聚合导师/社群/会员/收益，点得进去看导师明细。管理页才是导师主档：新增、编辑、删除、三种 Excel 导入。

两套页不要混用

对照机构导师看板导师管理
对象 先看机构，再下钻导师 直接看导师主档
身份枚举 主导师 / 协同导师 / 见习导师（机构内角色） 导师长 / 专项运营 / 专项服务 / 助教导师 / 创业导师
能不能改 只读。不新增、不编辑、不删除机构和导师 详情 / 编辑 / 删除 / 批量导入
收益口径 会员累计收益：会员加入该机构/该导师期间 累计收益 + 在籍收益（仍绑定的用户）
看板身份和管理身份不是同一套词。有人问「这个主导师怎么在管理里叫专项运营」，先对右豹 ID，不要按称呼硬对。
机构导师看板

机构一行是总览；只有「导师数量 > 0」能点进去

筛机构名称（模糊）。查询刷新并回到第 1 页；重置只清空条件，不自动查。顶上四格统计跟当前查询结果走：机构数、导师合计、会员合计、会员累计收益。

哪些数字能点

位置字段能不能点
机构列表导师数量> 0 进入该机构导师明细；0 灰色不可点
机构列表社群数量、导师团数量即使 > 0 也不可点，只是去重后的只读数
导师明细关联导师团数量> 0 弹窗列出团名，不跳转、不能改
导师明细社群数量> 0 弹窗列出社群名，同样只读

下钻导师列表时，导师筛选项会被清空。导师侧可按名称、身份、右豹 ID 再筛。更新时间是看板最近一次聚合刷新，不是你打开页面的时间。

对账口径 · 最容易说错

收益只计「绑在这个对象期间」产生的钱，不是会员一辈子的钱

机构「会员累计收益」和导师「会员收益」窗口规则相同：加入时间 ≤ 收益发生时间 < 解绑时间。没解绑时，右端对齐看板更新时间。加入之前、解绑之后都不算。

会员数为什么加起来对不上

  • 机构「会员数量」按机构会员去重。
  • 导师「会员数量」按该导师名下统计。
  • 同一会员可以挂多名导师，所以各导师会员数之和可以大于机构会员数。这不是脏数据。
同一会员多次加入/解绑：每个绑定时段分别算再加总，中间空档不计。同一会员同时挂多名导师：各导师只计挂在自己名下那段时间的收益，互不挪用。

和导师管理里的「用户收益」

  • 管理页拆成累计和在籍：累计仍是加入后、解绑前；在籍只含当前还绑着的用户。
  • 底薪不在列表出现，只在详情/编辑抽屉里。
  • 两页都按时间窗口，不要拿会员全生命周期流水硬对看板数字。
导师管理

主档聚合看人，详情/编辑共用一只抽屉

列表按排序升序。必填：所属机构、导师身份、导师名称、导师右豹 ID、导师飞书 ID。打开新增/编辑时会关掉详情和规则抽屉，避免叠两层。

列表上能点的数

  • 关联数据（社群数 + 导师团数）：任一 > 0 进子页「关联数据」Tab。表头形如「X 个社群 · X 个导师团，累计 X 个学员」。
  • 下属导师数量：> 0 进同一子页的「下属导师」Tab。表头按专项运营 / 专项服务 / 助教 / 创业四类计数。
  • 数量为 0：灰色，不可点。
  • 删除用确认弹窗，遮罩点不关；确认后从列表消失。
筛选项：导师信息（名称/右豹ID/飞书ID/标签）、所属机构、身份、是否自营、状态。重置同样不自动查询。
批量导入

先选导入类型，再出对应 Excel 列；对不上的行直接失败，不瞎建

工具栏「批量导入」。选类型后动态渲染模版列，可先下载再上传。三种类型校验不一样，失败只打该行，不要理解成整表作废（以实际上传结果为准）。

类型关键列失败条件
导入导师 机构、身份、名称、右豹ID、飞书ID 必填；可带底薪、签约、合同、自营、导师团、排序 机构必须已存在；身份必须是管理页那五个枚举；右豹 ID 不能和现有导师重复；填了导师团名称也必须已有该团，不新建团
导入导师团队 导师名称、导师右豹ID、团队名称 名称 + 右豹 ID 必须已在导师管理且对得上；团队名称必须是现有导师团，不存在则该行失败
导入签约信息 导师名称、导师右豹ID、底薪、签约日期、合同编号 同样必须名称 + 右豹 ID 同时命中已有导师，缺一或对不上该行失败
导入不会在系统里「顺便新建一个导师团」。团名写错就是该行失败。对导师也必须名称和右豹 ID 一起对，只对其中一个不算。
客服 / 运营话术

先问是看板对不上，还是主档人找不到

本需求没有用户端页面。外部导师/学员看不到这两张表。运营内部对账按下面说。

Q1. 机构下导师会员数加起来比机构会员多？
正常。机构会员去重，导师会员按人挂靠。一人多导师就会「分项之和 > 机构去重数」。
Q2. 某会员历史流水很多，为什么机构收益没那么高？
只计加入该机构之后、解绑之前的收益。进机构前和离开后的单都不算进这个机构。
Q3. 为什么点不了机构上的社群数 / 导师团数？
设计如此。机构这两列只读去重。要看具体名字，先点导师数量进明细，再点该导师的团数或社群数，弹窗只列名称。
Q4. 看板里的「主导师」在管理页找不到这个身份？
两套枚举。看板是机构内角色（主导师/协同/见习），管理是主档岗位（导师长/专项运营等）。用右豹 ID 搜管理页。
Q5. 列表上看不到底薪？
底薪故意不在列表。打开详情或编辑抽屉才能看/改。
Q6. 导入提示团队不存在，能不能让系统自动建团？
不能。团队名称必须已在现有导师团里。先把团建好（本看板/管理不提供建团入口时，走既有导师团数据），再导。
Q7. 重置筛选后机构怎么还是筛过的？
重置不清查询结果。再点「查询」才会按空条件刷新。
Q8. 能不能在看板里改导师或删机构？
不能。看板只读。改人去「导师管理」。本 FR 也不提供新增/删除机构。

对外不要承诺的事

  • 没有 C 端「我的导师/机构」页面可给学员看。
  • 不能按会员全生命周期流水对看板收益。
  • 导入不会自动新建机构或导师团；右豹 ID 冲突不会覆盖已有导师。
  • 数量为 0 的格子不会变成可点链接。

FR-011 · 需求规则 · v6

后台需求 · 导师迭代V1.0

1业务目标

运营以机构为主要对象，查看该机构下的导师、导师团与社群聚合数据，并下钻到具体导师。本 FR 无 C 端呈现。

2数据表与字段

机构看板（主表）

  • 机构名称：机构主对象。
  • 社群数量：该机构下去重后的社群数，只读展示，不可点击。
  • 导师团数量：该机构下去重后的导师团数，只读展示，不可点击。
  • 导师数量：该机构下导师数；大于 0 时可点击，进入该机构导师明细。
  • 会员数量：该机构下会员去重人数。
  • 会员累计收益：该机构下会员累计收益（会员去重后汇总）。按会员加入该机构的时间窗口统计：仅计入加入时刻起（含）至解绑时刻止（不含）产生的收益；加入之前与解绑之后的收益不计入。
  • 更新时间：本行看板数据最近一次聚合刷新时间。

导师明细（下钻表）

  • 导师名称：导师在机构内的展示名。
  • 导师身份：导师在机构内的角色。本 Demo 枚举：主导师 / 协同导师 / 见习导师。
  • 右豹ID：导师的右豹帐号 ID，等宽展示。
  • 关联导师团数量：该导师关联的导师团数；大于 0 时可点击，弹窗列出导师团名称。
  • 社群数量：该导师关联的社群数；大于 0 时可点击，弹窗列出社群名称。
  • 会员数量：该导师名下会员数。
  • 会员收益：该导师名下会员收益合计。口径与机构「会员累计收益」相同，窗口按会员加入该导师的时间计算：加入之前与解绑之后不计入。

3列表与筛选

  • 机构列表筛选项：机构名称（模糊匹配）。查询刷新列表，页码重置至第 1 页。
  • 重置：清空筛选值，不自动触发查询，Toast 提示「筛选条件已重置」。
  • 导师列表示选项：导师名称（模糊）、导师身份（枚举）、右豹ID（精确或前缀）。规则同机构列表。
  • 下钻导师列表时，导师筛选项重置为空。
  • 机构列表顶部汇总：当前查询结果的机构数、导师合计、会员合计、会员累计收益合计。

4下钻与弹窗

  • 点击机构行导师数量：进入该机构导师明细页，页头展示机构名称，可返回机构列表。
  • 点击导师行关联导师团数量：弹窗标题「关联导师团」，列出该导师的导师团名称。
  • 点击导师行社群数量：弹窗标题「关联社群」，列出该导师的社群名称。
  • 弹窗仅展示名称，不提供跳转与编辑。点击遮罩或「关闭」、按 ESC 关闭。

5边界规则

  • 数量为 0 的导师数量 / 关联导师团数量 / 社群数量：灰色数字，不可点击。
  • 机构侧「社群数量」「导师团数量」即使大于 0 也不可点击；名称弹窗只出现在导师明细。
  • 机构「会员数量」按机构会员去重；导师「会员数量」按该导师名下统计。同一会员可关联多名导师，故各导师会员数之和可以大于机构会员数。
  • 会员累计收益 / 会员收益统计窗口：
    • 以会员与对应对象（机构 / 导师）的加入时间、解绑时间为准，不按会员全生命周期收益。
    • 一笔收益的发生时间满足 加入时间 ≤ 发生时间 < 解绑时间 才计入对应对象；未解绑则右端为统计截止（看板更新时间）。
    • 加入之前的历史收益、解绑之后产生的收益，均不作为对应对象的收益。
    • 同一会员多次加入 / 解绑：各绑定期分别计算后加总；间隙期不计入。
    • 同一会员同时挂在多名导师下：各导师只计该会员挂在自己名下期间的收益，互不挪用。
  • 机构「社群数量 / 导师团数量」为机构下去重；导师侧为该导师关联数，不做机构级去重展示。
  • 更新时间以数据聚合刷新为准，不随页面打开时间变化；未解绑会员的收益窗口右端对齐该更新时间。
  • 本 FR 不提供新增 / 编辑 / 删除机构或导师；Demo 数据不持久化。

6业务流程

见页内 Tab 「业务流程」 · 图1 机构导师看板。

1业务目标

运营以导师主档为对象，聚合查看身份、签约、关联社群/导师团、下属导师与用户收益，并支持新增、编辑、删除。

2数据表与字段

导师管理（主表）

  • 导师信息：聚合导师名称、导师标签、导师右豹ID、飞书ID。
  • 所属机构：导师归属机构。
  • 身份：导师身份。枚举：导师长 / 专项运营 / 专项服务 / 助教导师 / 创业导师。
  • 签约：是否自营、签约时间、合同编号。
  • 排序 / 状态：列表靠后、状态紧随排序。状态为 正常 / 禁用。底薪不在列表展示，仅详情可见。
  • 关联数据：社群数 + 导师团数；任一 > 0 可点击进入子页「关联数据」Tab。
  • 下属导师数量：> 0 可点击进入子页「下属导师」Tab。
  • 用户数量：该导师名下用户数。
  • 用户收益：聚合展示累计收益、在籍收益。累计按加入后解绑前统计；在籍为当前仍绑定用户的收益。加入之前与解绑之后不计入。
  • 操作：详情（抽屉）/ 编辑（同一只表单抽屉）/ 删除（确认弹窗）。

新增 / 编辑抽屉（共用）

  • 字段：所属机构、导师身份、导师名称、导师标签、导师右豹ID、导师飞书ID、导师底薪、签约时间、合同编号、是否自营、状态、描述、排序。
  • 所属机构、导师身份、导师名称、导师右豹ID、导师飞书ID 为必填。

关联数据（子表）

  • 表头：X 个社群 · X 个导师团，累计 X 个学员。
  • 字段：社群名称、导师团名称、导师团用户数、用户收益（累计 / 在籍）。

下属导师（子表）

  • 表头：X 个专项运营 · X 个专项服务 · X 个助教导师 · X 个创业导师。
  • 字段：导师名称、导师身份、关联导师团（具体名称）、用户数量、用户收益（累计 / 在籍）。

3列表与筛选

  • 筛选项：导师信息（名称 / 右豹ID / 飞书ID / 标签）、所属机构、导师身份、是否自营、状态。
  • 查询刷新列表；重置只清空条件，不自动查询。
  • 列表按排序升序展示。底薪不出现在列表。

4子页面与操作

  • 关联数据 / 下属导师数量点击后进入同一子页面，横向 Tab 切换。
  • 新增与编辑打开同一只 520px Form Config Drawer；打开时关闭详情与规则抽屉。
  • 删除：确认弹窗遮罩不可点关；确认后从列表移除。
  • 批量导入：工具栏入口；弹窗内选择导入类型后动态渲染 Excel 模版列，可下载模版后上传。
  • 导入导师 Excel 列：所属机构、导师身份、导师名称、导师右豹ID、导师飞书ID、签约底薪、签约日期、合同编号、自营/非自营、导师团名称、排序。必填：所属机构、导师身份、导师名称、导师右豹ID、导师飞书ID。
  • 导入导师团队 Excel 列：导师名称、导师右豹ID、团队名称。
  • 导入导师签约信息 Excel 列：导师名称、导师右豹ID、签约底薪、签约日期、合同编号。

5边界规则

  • 关联数据或下属数量为 0：灰色数字，不可点击。
  • 导入导师团队 / 签约信息：必须同时校验导师名称 + 导师右豹ID已存在于导师管理，缺一或对不上则该行失败。
  • 导入导师团队：团队名称必须已存在于现有导师团，不存在则该行失败，不新建导师团。
  • 导入导师：所属机构必须是已有机构；导师身份必须落在枚举内；右豹ID 不可与现有导师重复。
  • 导入导师时若填写导师团名称，同样须落在现有导师团中，否则该行失败。
  • Demo 数据不持久化。
