组件规范 Design System

迭代需求 Demo 内按钮、文字链、确认弹窗、编辑弹窗、详情抽屉、Toast 的统一规范。所有 FR 页（模板 A / B）须复用以下 class 与交互模式，保证全站一致。

Button 文字链 表格操作 确认弹窗 编辑弹窗 详情抽屉 Toast Tag

1 · Button 按钮

高度 34px（筛选区 32px）；圆角 7px。主操作每区域仅一个 Primary。

Primary
查询、提交、保存、确认
.btn .btn-primary
Ghost
取消、重置、次要操作
.btn .btn-ghost
Rule
Page Header「需求规则」入口
.btn .btn-rule
Danger
确认弹窗内 destructive 主按钮；慎用大面积使用
.btn-danger / .btn-danger-ghost

2 · 文字链（Text Link）

表格操作列、行内轻量操作。不用 Button 样式，保持信息密度。

Default
详情、编辑、导出等常规操作
.link
Muted
日志、次要查看类
.link .link-muted
Danger
删除、下架等；点击后须出确认弹窗
.link .link-danger

3 · 表格操作列组合

顺序建议：详情 → 编辑 → 日志 → 删除。链接间距 12px；危险操作置末。

ID名称状态操作
PA-10021豹豹1号正常
列表区右上角「新增」使用 .btn-primary，不与行内文字链混用。

4 · 确认弹窗（Confirm Modal）

居中 overlay；宽 400px。删除/撤回/不可逆操作用 Danger 主按钮；可取消操作用 Ghost + Primary。

使用场景
  • 删除发布帐号、撤回分配（若允许）等不可逆操作
  • 二次确认提交（如批量操作）
  • 不用于详情/编辑（详情→Drawer，编辑→Modal 表单）

5 · 编辑弹窗（Edit Modal）

居中 overlay；宽 480px。Footer：取消 Ghost + 保存 Primary。Demo 提交后 Toast + 关闭。

6 · 详情抽屉（Detail Drawer）

右侧滑入 overlay；宽 480px。关键词详情 list、需求规则等长内容只读场景。不挤压主列表宽度。

7 · Toast 反馈

底部居中；深色胶囊。Mock 提交成功、筛选重置等轻量反馈，2.5s 自动消失。

8 · 状态 Tag

仅用于表格内业务状态，不用于框架 chrome（FR 徽章除外）。

正常 待审核 已删除
class：.tag-ok .tag-warn .tag-del

确认操作

确定要执行此操作吗？此操作在 Demo 中仅为 Mock 反馈。
