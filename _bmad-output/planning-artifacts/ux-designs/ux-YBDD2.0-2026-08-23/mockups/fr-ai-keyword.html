AI申词 FR-013 v1 当前

用户已知书籍 ID、或只要用选书中心已上架书时，走独立批量 AI 申词：选项目与推广类型，手填 ID 和/或勾选官方推荐，多本书每本 1–10 词，先预览更换再一次提交。

场景切换

官方推荐是选书中心已上架书的独立拷贝（ID 用 BK-10xx），无推荐标记、无维护表。下架书不出现。推广类型来自项目题词配置。

FR-013 · v1 需求规则

1业务目标

用户已经知道书籍 ID、或只要用选书中心里的书时，不必再逛选书中心单本申词，直接在 AI申词里批量出词并一次提交。

2页面与入口

  • 入口：独立「AI申词」H5，不挂在选书中心详情里。
  • 项目：必选。Demo：不鸣推文（有推荐）、星河小说（自有书库，推荐空）、未配置项目（类型空）。
  • 推广类型：读取该项目题词配置。Demo 枚举：真人出镜、图文、解压TTS、解说混剪、AIGC。
  • 手填 ID：换行 / 逗号 / 空格分隔，按 ID 去重。命中书库带书名，未命中标「未匹配书名」仍可申。
  • 官方推荐：选书中心已上架书的独立拷贝，同书名，ID 用 BK-10xx。无推荐 flag、无推荐维护表。下架书不出现。有自有书库的项目推荐为空。
  • 待申词行：ID、书名或「未匹配书名」、数量 1–10（默认 3）、词芯片、「更换」。

3交互规则

  • 双层批量：多本书；每本独立数量；「更换」只按该行换词。
  • 推荐已加入的 ID 再手填，Toast「已添加」，不重复行。
  • 数量 0 或超过 10，点更换时钳到 1–10 再出词；数量为空 Toast。
  • 一次提交 = 一条批次。先预览 / 更换，再提交。
  • 提交成功走现有申词审核，本 FR 不重定义审核态。

4边界规则

  • 缺项目 / 类型 / 有效 ID / 任一行未出词，不可提交，Toast 点名缺项。
  • 项目没有类型时，下拉为空并阻断。
  • 不做手动「申请关键词」Tab；不在本页做上下架或新推荐表。

5业务流程

见页内 Tab 「业务流程」。

1业务目标

运营按批次查看 AI申词提交：一次提交对应一条记录，详情展开多本书和词，审核复用现有流程。

2数据表与字段

  • 申词批次：批次 ID、用户、项目、推广类型、书籍数、词数、审核状态、申请时间。
  • 详情展开：每本书的 ID、书名或「未匹配书名」、关键词列表。
  • 推广类型落库当时值。审核状态复用现有：待审核 / 已通过 / 已驳回。

3列表与筛选

  • 可按批次 ID / 项目、审核状态筛选。
  • 详情用 overlay 抽屉，不挤压列表。

4边界规则

  • 一批就是一笔审核单，不在本 FR 拆成多笔。
  • 本页只做批次记录表，不做书库上下架、不做新推荐维护表。
  • 审核通过 / 驳回复用现有申词后台，本 Demo 不另做审批弹窗。
