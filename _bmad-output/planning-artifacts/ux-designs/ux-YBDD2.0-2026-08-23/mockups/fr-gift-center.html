FR-008 · v1 需求规则

1业务目标

节假日实物礼要让入选用户打开就被看见，再确认快递走到哪一步。不是物流查询页。

2页面与入口

  • 礼品中心：个人中心下独立入口，不并入活动中心。仅列表，不提供宫格。
  • 节日列表：封面节日图 + 统一礼物角标、标题、描述、标签、收益达标进度、状态（恭喜获得 / 遗憾错失）、底部时间；点卡片出详情。指定用户礼为「定制礼品」卡片，不展示收益进度。
  • 卡片字段：封面 + 礼物角标、标题、描述、标签。收益礼：进度条（当前累计 vs 达标，标明已达标 / 未达标），文案不用「门槛」。定制礼：无进度条。无查看详情按钮；点卡片即出详情。
  • 详情：点卡片弹出详情弹窗（不跳转新页）；弹窗海报、介绍文案、物流单号、缺地址 CTA 在弹窗内。
  • 不做荣誉通知：无自动弹层、无荣誉徽、无再看荣誉。
  • 列表范围：仅展示后台状态为「显示」的礼品；状态=隐藏时 C 端不展示。礼品不下架。C 端不展示未获得标签。
  • 站内信：入选一条、发货一条；点击均进入礼品中心。文案后台可配。
  • 地址：缺地址时详情点「去补全收货地址」→ 弹窗提示「规则：跳转至现在的收获地址页面」，跳转既有地址页，本 FR 不重做表单。

3交互规则

  • 点整张卡片打开详情，无「查看详情」按钮。
  • 进度条（收益礼，列表与详情相同）：展示当前累计收益相对达标额，并标明是否达标。文案不用「门槛」。例：达标 5 万、当前 5.2 万 → 已达标。详情额外展示收益统计日期。
  • 定制礼品：发放方式为指定用户时，C 端以专属卡片呈现、不展示收益进度；文案强调「特别为你」，不告知圈选规则。
  • 外层状态：恭喜获得（已达发放条件）、遗憾错失（活动年已结束且未达标）。当年尚未结束则为待达标。
  • 详情灰区：只展示物流（待发货 / 已发货+单号 / 自动签收 / 未发放 / 待发放）。不把收益进度放进灰区。
  • 无地址仍可看列表与详情弹窗；点补全地址只出跳转规则弹窗，不在礼品中心内填地址。
  • 视觉：沿用 C 端橙色浅底（与活动中心同色板）；列表静态，无 3D/悬浮动效。

4边界规则

  • 同一礼品每人最多中一次。
  • 礼品不会下架；往期礼品只要状态=显示，仍留在 C 端列表。
  • 不做拒绝、转赠、积分商城打通。

5业务流程

见页内 Tab 「业务流程」：圈人、地址、导单号、站内信合在一张判断图。

1业务目标

运营配置礼品与发放人员规则，查看命中名单，导入物流单号或补礼品；缺地址先不寄。

2数据表与字段

  • 礼品：标题、描述、介绍（对应C端弹窗详情文案）、礼物标签（可配多个，C 端卡片展示）、展示图、详情图、礼品弹窗海报（附件上传，不用 URL）、状态（显示 / 隐藏）、创建人、创建时间；入选/发货站内信文案（可配）。
  • 状态与前端展示：仅当状态=「显示」时，该礼品才出现在 C 端列表与详情；状态=「隐藏」时前端不展示。礼品仍不下架，名单与物流继续可操作。
  • 发放人员（新增/编辑单选，必选其一）：指定用户 或 收益达标。指定用户填用户ID，C 端呈现为「定制礼品」、不展示收益进度。收益达标填累计收益达标额 + 收益统计区间，C 端展示当前累计 / 达标，并按是否达标计算恭喜获得 / 遗憾错失。
  • 发放名单：列表与表单均显示命中人数，点击进入明细。
  • 发放人员明细：用户ID、入选方式（指定用户 / 收益达标·具体收益值 / 补礼品）、收获地址、物流平台、物流单号、当前状态（已获得 / 已发货 / 自动签收）、站内信（未发 / 入选站内信已发 / 发货站内信已发）、更新时间。

3列表与操作

  • 礼品信息：按标题、状态查；新增/编辑用 Modal；发放名单列点人数进详情。
  • 发放名单顶部统计：入选站内信未发、发货站内信未发、缺地址（按全量名单计，不受筛选影响）。
  • 名单操作放在筛选区「查询」后：发送入选站内信、发送发货站内信、导入物流单号（Excel：用户ID、物流平台、物流单号）；补礼品名单（弹窗批量输入用户ID + 备注）。行内可对单人发送。
  • 明细筛选：用户ID、当前状态。

4边界规则

  • 无地址：占名额、收获地址显示「缺地址」、不寄。
  • 导入单号后状态改为已发货，满 7 天系统自动签收。
  • 已在本礼名单中的用户再次命中或补录，跳过。
  • 站内信只对未发送用户触发：入选 / 发货各自独立；已发该条的用户不再发送，未发才写入。
新增礼品
仅状态=显示时，C 端才展示该礼品
对应C端弹窗详情文案
C 端卡片展示全部标签。建议 1～4 个，如「实物礼 / 春节 / 需达5万」或「定制礼品 / 特别为你」。
对应 C 端详情弹窗顶部海报
只能选一种。指定用户 → C 端定制礼品卡，无进度条；收益达标 → C 端展示当前累计 / 达标。
导入物流单号

Excel 列：用户ID、物流平台、物流单号。仅匹配本礼发放名单；缺地址行跳过且不改状态。

补礼品名单

批量补录未命中规则但需发放的用户。入选方式记为「补礼品」。已在本礼名单中的用户跳过。
