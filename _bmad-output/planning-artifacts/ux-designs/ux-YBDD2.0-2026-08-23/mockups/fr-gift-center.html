FR-008 · v1 需求规则

1业务目标

节假日实物礼要让入选用户打开就被看见，再确认快递走到哪一步。不是物流查询页。

2页面与入口

  • 入口：个人中心下独立入口，不并入活动中心。仅列表。
  • 可见范围：仅后台状态=「显示」的礼品出现在 C 端；隐藏不展示。礼品不下架，往期显示礼仍留在列表。
  • 列表卡片：封面 + 礼物角标、标题、描述、标签、底部时间。点整张卡片出详情弹窗。收益礼展示达标进度与三态（恭喜获得 / 待达标 / 遗憾错失）；指定用户礼为「定制礼品」卡片，无进度条。
  • 详情弹窗：弹窗海报、介绍文案、收益统计日期（收益礼）、灰区展示物流状态 / 单号 / 收货地址；缺地址时地址行标「缺地址」并出「去补全收货地址」。
  • 站内信：入选一条、发货一条；点击均进入礼品中心。文案后台可配。

3交互规则

  • 进度（收益礼，列表与详情相同）：当前累计 / 达标额，标明已达标或未达标。详情额外展示收益统计日期。当前累计与后台入选用同一口径：该用户在统计闭区间内的用户项目收益（已结算+未结算）。
  • 卡片三态（按「今天」与区间结束日、当前累计与达标额判定，优先级如下）：
    1. 恭喜获得：当前累计 ≥ 达标额（无论区间是否结束；等于也算）。
    2. 待达标：当前累计 < 达标额，且今天 ≤ 区间结束日。
    3. 遗憾错失：当前累计 < 达标额，且今天 > 区间结束日。不再补发。
  • 定制礼品：文案强调「特别为你」，不告知圈选规则。
  • 物流灰区：物流状态（恭喜获得后待发货 / 已发货+单号 / 自动签收；待达标=待发放；遗憾错失=未发放）+ 收货地址。有地址展示完整地址；无地址展示「缺地址」。
  • 地址：无地址仍可看列表与详情；点补全地址只出规则弹窗「跳转至现在的收获地址页面」，跳转既有地址页，本 FR 不重做表单。
  • 视觉沿用 C 端橙色浅底，与活动中心同色板。

4边界规则

  • 同一礼品每人最多中一次（指定用户、收益达标、补礼品共用本礼名单去重）。
  • 收益礼未入选时仍展示卡片与进度，不展示可寄物流。

1业务目标

运营配置礼品与发放人员规则，查看命中名单，导入物流单号或补礼品；缺地址先不寄。

2数据表与字段

  • 礼品：标题、描述、介绍（对应C端弹窗详情文案）、礼物标签（可配多个）、展示图、详情图、礼品弹窗海报（附件上传）、状态（显示 / 隐藏）、创建人、创建时间、入选/发货站内信文案。
  • 状态：仅状态=「显示」时 C 端展示；隐藏则前端不展示。名单与物流仍可操作。
  • 发放人员（单选必填）：指定用户填用户ID，保存即按 UID 写入名单，不看收益；收益达标填累计收益达标额 + 统计起止日，按下方判定写入。
  • 发放人员明细：用户ID、入选方式（指定用户 / 收益达标·具体收益值 / 补礼品）、收获地址、物流平台、物流单号、当前状态（已获得 / 已发货 / 自动签收）、站内信（未发 / 入选已发 / 发货已发）、更新时间。

3收益达标判定

  • 候选用户：全量拥有项目收益账户的用户。C 端所有登录用户可见「显示」中的收益礼并看自己的进度；只有判定入选的人才进发放名单。
  • 收益口径：用户维度、统计闭区间内的用户项目收益，含已结算 + 未结算。收益归属时间落在 [开始日 00:00:00, 结束日 23:59:59]（平台时区）才计入。
  • 比较符：用户项目收益 ≥ 达标额即达标，等于也算。达标额须 > 0，单位元，按分精度比较。
  • 入选时机：统计期内按收益变动或日批扫描；首次满足即锁定写入，入选方式记「收益达标 · 当时收益值」。写入后收益回落不撤销、不踢出。
  • 未入选：期内未达 = 待达标，继续扫；期结束仍未达 = 遗憾错失，不再写入、不再补扫。
  • 一人一次：本礼名单已有该 UID（含指定用户、补礼品）则跳过，不改已有行。
  • 改规则：已入选不因提高达标额、缩短区间、隐藏礼品被踢出。降低达标额或拉长尚未结束的区间，只补入尚未入选且新规则下达标的人。
  • 隐藏礼品：C 端不展示，后台仍按规则计算名单、可发信导单号。
  • 补礼品：运营补录，跳过本判定；已在名单则跳过。

4列表与操作

  • 礼品信息：按标题、状态查；新增/编辑用 Modal；发放名单列点人数进明细。
  • 名单顶部统计（按全量，不受筛选影响）：入选站内信未发、发货站内信未发、缺地址。
  • 筛选区「查询」后操作：发送入选站内信、发送发货站内信、导入物流单号（Excel：用户ID、物流平台、物流单号）、补礼品名单（用户ID + 备注）。行内可对单人发送。
  • 明细筛选：用户ID、当前状态。

5边界规则

  • 无地址：占名额、收获地址显示「缺地址」、不寄。
  • 导入单号后状态改为已发货，满 7 天系统自动签收。
  • 已在本礼名单中的用户再次命中或补录，跳过。
  • 站内信只打未发用户：入选 / 发货各自独立，已发不再发送。
