FR-007 · 需求规则 · v1

1业务目标

部分项目在右豹侧已按体裁拆分，但官方未区分，官方关键词库共享。订单在右豹侧仍需按体裁给到对应用户。运营手工筛词分单人效过低，故对部分项目支持合并上传 + 自动分发。无 C 端呈现。

2后台 Tab

  • 项目分组：表格展示分组名称与项目成员；新增/编辑用项目多选（交互同订单优化「优化项目」）；仅同组可分发；一个项目最多属于一组。
  • 分发记录：合并上传订单并触发分发；列表看批次结果；详情逐单展示关键词命中与去向。

3项目分组（当前）

  • 第一组：番茄小说、番茄小说-漫剧、番茄小说-短剧
  • 第二组：番茄畅听、番茄畅听-漫剧、番茄畅听-短剧
  • 第三组：悟空短剧、悟空网文、悟空漫剧
  • 第四组：红果短剧APP-短剧、红果短剧APP-漫剧、红果短剧APP-网文

未列入以上分组的项目不参与本能力。分组可增删改，但历史分发记录保留当时的分组快照。

4分发逻辑

  • 合并上传时选择所属分组，系统展示该组项目 list；以订单关键词查询右豹关键词库所属项目后写入对应项目订单。
  • 目标项目必须属于所选分组，否则跨组拦截、不分发。
  • 关键词未命中右豹库：记未匹配（只汇总笔数与金额），不写入任何目标项目；可导出未匹配单，不支持重新分发。
  • 本 FR 不新建关键词表，复用右豹现有关键词库的所属项目字段。

5分发记录字段

  • 批次号、所属分组、上传订单量、已分发、未匹配、分发时间、状态。不展示上传项目。
  • 已分发按组内项目聚合：项目名：xx笔订单；xxx元。未匹配只展示总笔数与金额，不按项目拆分。
  • 状态：全部命中且无拦截为「已完成」；存在未匹配或跨组为「部分未匹配」。
  • 操作：详情、下载源文件、下载未匹配、删除（需确认）。不提供重新分发。

6边界规则

  • 无 C 端入口、无用户侧交互；仅管理后台导入与结果查询。
  • 已写入目标项目的订单不自动回滚；删除记录不影响已落入各项目订单表的数据。
  • 批次一旦分发即定稿：已分发与未匹配均不可在本页再次分发；未匹配只能下载后由运营另作处理。
  • 官方关键词库共享，不在本能力中按体裁拆官方词库。
