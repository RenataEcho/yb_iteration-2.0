# 广场收益池 — Experience Spine

## Foundation

单表面：右豹 App C 端作品广场（本迭代页）。视觉身份见 `DESIGN.md`。不单开首页。历史广场 / 详情 / 领取页只读复用。

## Information Architecture

| Surface | 从哪来 | 目的 |
|---|---|---|
| 作品广场 · 已登录 | App 打开本迭代广场 | 先看池子，再按项目刷稿；右下盲盒浮标进今日盲盒 |
| 作品广场 · 未登录 | 未登录打开广场 | 隐藏池子；盲盒加锁，点了提示先登录；宫格仍可看 |
| 今日盲盒 | 广场盲盒浮标 | 未开盒 / 可拆 / 已开出 / 拆完 / 已收官 |

底栏仍是 广场 / 已领。已领是历史页，本增量不改。

→ Mock：`demo/iteration/yijian-daifa-pool-demo.html`。脊柱胜于 mock。

## Voice and Tone

| Do | Don't |
|---|---|
| 「领取稿件关联关键词累计产生的收益」 | 「你已赚」「含预估」 |
| 「全员可见 · 非可提现」 | 「立即提现」 |
| 「还剩 23 盒 / 拆开这一盒 / 开出 ×1 / 今日第 28 盒」 | 「限时秒杀！！！」 |

## Component Patterns

- **收益池**：只读展示收益。不可点进钱包。未登录不占位。
- **项目条 / 筛选 / 搜索**：行为与 FR-014 广场相同；占用中稿件不对他人显示。
- **盲盒浮标**：已登录点进开盒页；未登录锁态，点了只提示先登录。只在广场两态出现，进活动页即隐。
- **盲盒舞台**：未开只露 `?`，拆完才亮次数牌。证明这是拆，不是填表。
- **今日货架**：50 格小盒，已拆填橙，下一盒闪，自己的盒加圈。
- **刚刚有人拆走**：最近开盒名单带盒序，制造竞争。
- **开盒罩 / 开出成就**：先掀盖开出 ×1，再出示今日第几盒、压过人数、开盒用时。
- **宫格**：点卡提示「卡片不展示金额」；领取门禁仍走历史详情。

## State Patterns

| 面 | 态 | 行为 |
|---|---|---|
| 池 | 已登录 | 出示同一个展示收益 |
| 池 | 未登录 | 整块隐藏，项目条上移 |
| 今日盲盒 | 可拆 / 已开出 / 拆完 / 未开盒 / 已收官 | 规则同 PRD FR-9，面上用盒和开出说 |
| 宫格 | 无结果 | 「没有可领取的稿件」 |

## Interaction Primitives

点击项目过滤宫格。筛选按钮循环：全部 → 各选项。BN 自动轮播。浮标只在广场两态悬浮。点「拆开这一盒」先开盒罩再进已开出。领次成功回广场。

## Accessibility Floor

展示收益与剩余名额用文本数字，不单靠色块。池内对比：金/白字压在 `{colors.ink}` 上。

## Key Flows

1. **林晓打开广场** — 第一眼是顶部收益池，再是番茄 / 红果项目条与真实封面。高潮：她相信代发在赚钱，随手领稿。卡片没有金额。
2. **林晓拆盒** — 广场刷稿时右下小盒还剩 23 → 点进今日盲盒，正中一只在晃、货架下一盒在闪、别人刚拆走 26/27 → 点「拆开这一盒」→ 盒盖掀开，开出 ×1 → 「今日第 28 盒 · 压过 22 人」。高潮：她拆中了还在架上的盒，不是领了一张券。回广场开用次数。
