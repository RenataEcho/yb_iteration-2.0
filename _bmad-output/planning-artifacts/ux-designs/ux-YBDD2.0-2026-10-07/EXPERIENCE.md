# EXPERIENCE · 2.0优化

**冲突规则：** 本文件 + [DESIGN.md](DESIGN.md) 优先于 mock。验收对照 [demo/iteration/creator-home-2-opt-demo.html](../../../demo/iteration/creator-home-2-opt-demo.html)（V125）；PRD FR-021 为需求真源。

## Foundation

- **Form-factor:** 移动端 App 主画布（390px 逻辑宽）；桌面为居中手机预览 + Demo 双端切换器。
- **UI system:** 无独立组件库文档；实现须落地 DESIGN.md tokens（橙系 C 端 + `#dataPage` 黑金）。
- **双端:** C 端 App（五 Tab + 全屏子页）| 管理后台（学院菜单 + 首页运营「金刚区配置」）。Demo 切换：`Alt+C` / `Alt+B`，`sessionStorage['rb-demo-workspace']`。

## Information Architecture

### C 端 · 一级（底栏）

| Tab | 主页面 | 备注 |
|-----|--------|------|
| 首页 | `home` | Banner 下有金刚区；无路径气泡、无绑定邀请码 |
| 变现 | `monetize` | 赛道 + decision-chips + 列表/宫格 |
| 工具 | `tools` | 场景 + 工具市场 |
| 数据 | `data` | 黑金 Hero；空态 / 示例数据 |
| 我的 | — | Demo toast 占位 |

### Demo 展示板纬度

`fr-creator-home-2-opt.html` 的 C 端展示板按纬度分行。新手学院单独一条，不插在首页和商学院中间。变现、数据、分析在同一条。工具和提工具需求在另一条。底栏顺序仍是首页 / 变现 / 工具 / 数据 / 我的。

| 纬度 | 画面 |
|------|------|
| 首页与学院 | 创作者首页、商学院、图文详情、视频详情 |
| 新手学院 | STEP 1、课程详情、STEP 2 已选项目、领取关键词、选择官方稿件、关键词不足、稿件不足、发布回填（开发规则弹窗）、回填成功弹窗。新窗口完整 Demo 从首页金刚区「新手学院」进入同一套页面，返回回到首页。 |
| 变现与数据 | 变现、数据、数据分析、晒成果 |
| 工具 | 工具市场、提工具需求（工具页入口打开的表单） |

### C 端 · 全屏子页（隐藏底栏）

- **商学院** — 页标题「商学院」。频道：项目教学 | 案例拆解 | 进阶技巧 | 我的学习
- **课程详情** — 图文（标题 + 正文 + 通栏图，文末推荐课程）| 视频（单视频+进度）

### 首页模块顺序（自上而下）

顶栏 → Banner → 金刚区 → 三格数据 → 商学院/活动中心双卡 → 设置工作台 → 榜单（横滑两榜）→ 找项目（国内/国外 Tab）→ 右豹动态（**首页 2 条**）→ OPC 机构 → 品牌 footer。

首页不出现「有邀请码？」或「绑定邀请码」。

### 学院管理后台

侧栏：**课程管理** | **分类管理** | **学习数据** | **金刚区配置**（首页运营）| **新手学院**（新手课程、新手项目、新手关键词、客服）| （占位：项目管理、工具管理）

分类「新建 / 编辑」打开弹窗，保存后列表按排序刷新；已启用分类同步到商学院频道，停用则隐藏该频道。「我的学习」不在此配置。

**金刚区配置** 是首页金刚区的唯一数据源。列表列：标题、图标、排序、跳转路径、点击次数、点击人数、状态、创建时间、操作（编辑、删除）。新增与编辑共用一个弹窗，只改标题、图标、排序、跳转路径、状态。图标由后台上传图片，编辑时不重新上传则沿用原图。跳转路径是文本框，支持端内链接和 H5 链接；H5 链接必须携带 `id` 参数。点击次数、点击人数、创建时间由系统记录，弹窗里只说明、不可改。停用后首页隐藏该入口；删除后入口和点击数据一起消失。排序数字越小越靠左。

**新手学院** 与课程管理并列，不写入学习数据，不产生学习进度。四个配置页沿用现在学院后台的深色侧栏和列表加弹窗，不另起视觉。C 端新手学院只读这些配置。

| 页 | 列表 | 新增 / 编辑 |
|----|------|-------------|
| 新手课程 | 排序、封面字、标题、一句话、时长、上架/下架、编辑、删除 | 标题、一句话、封面字、时长、视频、讲解（一整段）、排序、上下架 |
| 新手项目 | 排序、图标字、展示名、收益文案、编辑、移除 | 从现有项目里选一个，再填展示名、图标字、收益文案、排序。没有上下架 |
| 新手关键词 | 表头统计：关键词数、已分配数、未分配数。列表：关键词、项目、书籍 ID、书籍链接、关键词状态（未分配 / 已分配）、审核状态（待审核 / 已通过 / 已驳回）、已分配用户 ID、回填信息、查看详情、删除。详情只读，含书籍名称、申词批次、生成时间。另有申词记录：申词批次、生词项目、生词数量、执行状态（执行中 / 已完成）、生成时间 | 按钮是「批量新增」。选项目，每行一个书籍 ID 或书籍链接，设置每个书生成的关键词数量，AI 直接批量生成。新词审核状态为待审核，用户 ID 为空。不在这里手填单个词，也不指定分给谁 |
| 客服 | 无列表 | 只上传一张二维码。底部客服栏和「官方稿件已经领完」弹窗共用 |

- 课程排序越小，C 端越靠前。下架后 C 端不展示，后台列表仍在。至少保留一门上架。
- 封面字显示在课程封面方块里。`[ASSUMPTION]` 建议 4 个字，输入最多 8 个字。视频这一项在演示里填地址或文件名。
- 从新手项目里移除，只影响新手学院，不改变该项目在变现里的上下架。
- 一个关键词全局唯一，只分给一个人。关键词状态只有未分配、已分配。已分配时列表和详情都写出用户 ID，未分配写「未分配」。审核状态是待审核、已通过、已驳回。回填信息是用户交回的作品链接，没有则显示未回填。未分配的可以删除。已分配的只能查看详情。
- 批量新增提交后先记一条申词记录，状态为执行中；生成结束后改为已完成，新词进入列表，状态为未分配、回填为未回填。同一批里相同的一行只算一本书。
- 换客服二维码后，两处一起更新。

## Voice and Tone

- **商学院卡：** 可见标题「商学院」，学习导向，🎓 前缀；**活动卡：** 收益/活动，🔥 前缀。
- **金刚区：** 标题用后台配置原文，不另写口号。种子四项仍是：新手学院、收益榜单、社群中心、邀请好友。
- **工具 Sheet：** 必须可读 **「为什么推荐」**（效率、少重复操作）。
- **数据示例：** 明示演示、不计入账户；空态不假装有真实收益。
- **后台学习数据：** 「不建设复杂教务体系」— 克制承诺。

## Component Patterns

### 双卡轮播（商学院 / 活动）

- 各 2 帧；点击切帧；**4.2s** 自动轮播。
- **商学院卡：** 可见标题「商学院」。点击 **capture 优先** → 打开商学院，不触发轮播切帧。
- 活动卡：点击仍切轮播帧，不打开商学院。

### 金刚区

- 位置：Banner 正下方、三格数据之上。数据来自后台「金刚区配置」里状态为启用的项，按排序从小到大从左到右，四列，多出的换行。没有启用项时，卡片内写「暂无启用的金刚区入口」。
- 种子路径：社群中心 → `youbao://page/org-list`（现有机构详情页列表）；邀请好友 → `youbao://page/invite`（现有邀请落地页）；收益榜单 → `youbao://page/opc-rank`（现有 OPC 经营榜单，与横滑榜 OPC 卡同一页）；新手学院 → `youbao://page/newbie`（新手学院页，不进入商学院）。
- 跳转路径是文本。支持端内链接和 H5 链接。H5 链接必须带 `id`，例如 `https://h5.example.com/act?id=10086`。社群中心、邀请好友、收益榜单打开现有页。新手学院打开本刀的新手学院页。

### 榜单横滑

- 两榜卡片仍在首页；每榜最多 5 条；TOP3 强、4–5 弱。
- 点 OPC 经营数据榜进入 OPC 经营榜单，与金刚区「收益榜单」同一目的页。
- 点平台项目榜进入该榜自己的完整榜。

### 找项目

- 赛道 Tab 切换列表；行内：图标、标题、副文案（项目数·顶尖月入 + 收益 em）；底部分割行 **project-tool-chips** + 更多。
- Chip / 更多 → **工具 Bottom Sheet**（单工具或全集）；遮罩关；「去使用」关 Sheet 并进入使用流。

### Sheets 族

- 设置工作台 Sheet、工具 Sheet、数据示例 Sheet — 统一：mask 点击关闭、从底滑入、z-index 工具层 ≥900。
- 工具页市场卡片 **没有** 适用项目 / 推荐项目行。变现侧工具详情里的适用项目仍保留。

### 学院列表 / 详情

- 频道 filter；我的学习 → 最近学习 / 收藏。列表里非视频课标为 **图文课程**。
- 图文详情顶部与视频课相同：标题、分类标签、类型、简介。其下用正文替换视频播放器，高度随内容增高，不套播放器的固定高度；正文为段落（约 15px、行高 1.75、色 `#3d4c63`）与 16:9 通栏图（圆角 8px）交替。页面向下滚动阅读全文。
- **推荐课程** 在正文滚动到底之后（同分类优先）。无推荐时显示空态。推荐区不计入完课。
- 图文完课 = 正文最后一块进入阅读；视频 ≥90% = 完课；收藏 toggle。

## State Patterns

| 状态 | 行为 |
|------|------|
| 首页 vs 子页 | 商学院/详情：底栏 hidden |
| 新手学院（种子） | 启用时入口可见；点击打开新手学院页 |
| 金刚区停用 | 该项不出现在首页；点击数据保留 |
| 金刚区删除 | 确认后从列表和首页移除，点击数据清除 |
| 金刚区保存 | 标题空、未上传图标、排序非整数、标题重复、跳转路径为空、H5 链接未带 id 时 toast 拦截，不关弹窗 |
| 数据 Tab 空态 | `rb123-empty`；分析入口拦截或引导；可开示例数据 Sheet |
| 示例数据模式 | 顶栏「退出演示」回空态 |
| 课程编辑（后台） | 无标题 → 保存拦截 toast |
| 分类「我的学习」 | 后台不可配置（仅 C 端资产入口） |
| 新手课程保存 | 带星号项缺一、排序不是非负整数、或将导致零门上架时 toast 拦截，不关弹窗 |
| 新手项目移除 | 确认文案写明不改变变现里的上下架 |
| 新手关键词已分配 | 查看态。词、书籍、删除都不可用。回填信息只展示 |
| 批量新增 | 没有项目、没有书籍行、或每书数量不是 1 到 50 的整数时拦截。提交后切到申词记录，先看到执行中 |
| 客服二维码 | 未上传就保存时 toast 拦截 |

## Interaction Primitives

- **Tab 切换：** `.app-page` active 切换。路径气泡已退出，任何 Tab 都不显示。
- **金刚区：** 每个启用入口是一颗按钮，无障碍名称等于可见标题。点击记一次点击次数；同一会话对同一入口只记一次点击人数。种子四个入口都离开首页。新手学院进入新手学院页。
- **Toast：** 短反馈（我的 Tab、去使用等）。
- **列表/宫格（变现）：** 宫格 **隐藏** 推荐工具行（V32）。

## Key Flows

### Flow 1 · 小周：学院 → 找项目 → 工具 Sheet（UJ-1）

1. 首页识别标题为「商学院」的学习卡 → 进入商学院（底栏消失）。
2. 项目教学 → 打开图文课 → 读正文与通栏图 → 文末看到推荐课程 → 返回。
3. 回首页 → 找项目国内 Tab → 点 tool chip → Sheet 见推荐原因 → 去使用。

**Climax:** 学习与赚钱路径在同一 App 内可串联，工具理由可读。

### Flow 2 · 小周：从金刚区打开已有页（UJ-4）

1. 首页 Banner 下方看到后台启用的入口（种子为四个）。
2. 点社群中心 → 机构详情页列表；返回。点邀请好友 → 邀请落地页；返回。点收益榜单 → OPC 经营榜单。
3. 点新手学院 → 打开新手学院页。
4. 运营在「金刚区配置」里停用一项后，回到首页该项消失。

**Climax:** 三个已定入口打开的是已经在用的页面；首页看到的入口由后台配置决定。

### Flow 3 · 李姐：后台课 + 完课口径（UJ-3）

1. 课程管理 → 新建视频课 → 保存上架。
2. 学习数据 → 读 analytics 说明：图文正文末块 / 视频 90%。
3. （Demo）预览 → 可选切 C 端。

**Climax:** 运营理解完课定义，且不期待教务级功能。

### Flow 4 · 李姐：配置新手学院

1. 打开管理后台「新手学院 / 新手课程」，看到四门已上架课。把一门改为下架并保存，列表仍在，状态变成下架。
2. 打开「新手项目」，确认知乎故事、番茄小说、红果短剧都在，弹窗里没有上下架。
3. 打开「新手关键词」，表头看到关键词数、已分配数、未分配数。列表里有书籍 ID、书籍链接、关键词状态和回填信息。点批量新增，填两个书籍 ID、每书 2 个词，提交后在申词记录里先看到执行中，完成后词进入未分配。
4. 打开「客服」，换一张二维码并保存。

**Climax:** 李姐改的是 C 端新手学院读到的配置，学习数据里不会多出一条进度。
