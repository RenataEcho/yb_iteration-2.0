# EXPERIENCE · 任务协作先领后填

`DESIGN.md` 是视觉身份。本文件只写这次增量怎么工作。与 Demo 冲突时，两份 spine 优先。

主人公沿用迭代 3.0 的领取用户 **林晓**。

## Foundation

右豹 App 手机页。没有新的设计系统。帐号运营的领取、下载、下发不在这次改动里。

状态演示在迭代页 `demo/iteration/fr-yijian-daifa-iter3.html` 的前端交互，画面来自 `yijian-daifa-iter3-demo.html`。每一态打开就能看见，不用先点领取。

## Information Architecture

| Surface | Reached from | Purpose |
|---|---|---|
| 任务协作选词 | 任务协作稿件详情点领取 | 选出具体关键词，或先领后填 |
| 尽快申请关键词 | 选了固定项并领取成功 | 告知 1 小时内要填写，否则稿件释放 |
| 领取记录 | 底栏已领 | 未填词时显示「填写关键词」；超时显示「超时未填写关键词」 |
| 这本书的关键词 | 点「填写关键词」 | 从这本书已有的词里选一个 |

## Voice and Tone

| Do | Don't |
|---|---|
| 暂无关键词,先领稿件稍后申请词 | 先领着，词以后再说 |
| 尽快申请关键词 | 别忘了哦 |
| 1 小时内没有填写关键词，该稿件过期释放。 | 超时将自动取消订单 |
| 填写关键词 | 去补词 |
| 请先到领取记录页面填写关键词 | 下载失败 |
| 超时未填写关键词 | 已过期 |

## Component Patterns

| Component | Use | Behavioral rules |
|---|---|---|
| 选择关键词 | 任务协作详情 | 点领取先打开。第一项固定是「暂无关键词,先领稿件稍后申请词」。选具体词再领取，仍走原来的扣费和下载。 |
| 尽快申请关键词 | 选固定项且领取成功 | 不开始下载。说明 1 小时内没有填写关键词，该稿件过期释放。这次领取已扣次数或积分。 |
| 填写关键词 | 领取记录，1 小时内 | 点它打开底部浮层，不进入稿件详情。浮层只列这名用户这本书的关键词。点中一个，字段改成这个词。 |
| 下载提示 | 还没填词时的下载 | 详情里的下载和领取记录里的下载都只出现「请先到领取记录页面填写关键词」，不保存稿件。 |
| 超时未填写关键词 | 满 1 小时仍未填写 | 字段改成这句。点它不打开浮层。点下载不保存稿件。稿件已释放。已扣次数和积分都不退。 |

`[ASSUMPTION]` 领取页上除固定项以外的词，演示与领取记录浮层用同一份：这名用户这本书的关键词。PRD 仍把领取页这份来源留在开放问题。

## State Patterns

| State | Surface | Treatment |
|---|---|---|
| 选词 | 任务协作详情 | 浮层已打开。关键词抬头仍是「未领取」。 |
| 已先领 | 稿件详情 | 弹窗「尽快申请关键词」。不出现下载进度。 |
| 待填写 | 领取记录 | 关键词是橙色「填写关键词」。 |
| 选词填写 | 领取记录 | 底部浮层列出「豪门团宠」「团宠日常」。没有固定项。 |
| 下载被拦 | 领取记录 | 深色提示停在「请先到领取记录页面填写关键词」。 |
| 超时 | 领取记录 | 关键词是灰色「超时未填写关键词」。 |

## Interaction Primitives

点遮罩或关闭，选词浮层收起，不改变领取。点固定项完成领取：扣 1 次，弹出尽快申请关键词，不下载。点这本书的一个词，字段改为该词，之后下载不再被这句拦住。

## Accessibility Floor

固定项整句可见，不截成一行省略号。超时文案与可点的「填写关键词」不用同一种橙色。

## Key Flows

### 流程 1 — 林晓先领，稍后再填

1. 她打开一条任务协作稿，点领取，看到选择关键词。
2. 她点「暂无关键词,先领稿件稍后申请词」。
3. **高潮：** 次数扣掉了，稿件没有进相册。弹窗要她尽快申请关键词，并写明 1 小时内不填就释放。
4. 她到领取记录，点「填写关键词」，从这本书的词里选一个。之后可以下载。

失败：满 1 小时仍没填。字段变成「超时未填写关键词」。次数和积分都不退。她不能再把词填回这次领取。

## Responsive & Platform

只有手机。迭代页用现有手机框把六态横排摆开。
