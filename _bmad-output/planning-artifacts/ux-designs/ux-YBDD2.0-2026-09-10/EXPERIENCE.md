# FR-014 · PC 剪辑供稿 — 体验

> 视觉 token 见 `DESIGN.md`。冲突时 spine 优先于 mock。

## Foundation

- **C 端**：手机。只服务领取用户。不做剪辑手入驻、上传、工作台。
- **PC 端**：已有右豹创作者中心桌面。本 FR 只在该业务线增加「剪辑供稿」。
- **管理后台**：运营录入剪辑手 / 管稿件。不替代 PC 上传。

## Information Architecture

| Surface | 端 | 目的 |
|---|---|---|
| 作品广场 / 详情 / 领取 / 水印 / 回填 | C | 领稿变现。无剪辑手流程 |
| PC 招募入口 | PC | 海报 + 客服二维码。无站内申请表 |
| PC 未录入阻断 | PC | 未进剪辑手管理不能上传，回招募 |
| 剪辑手看板 | PC | 已授权项目、上传稿件、已被领取、已产生收益 |
| 最近上传 | PC | 书籍 ID、稿件信息（大小 + 稿件名称） |
| 上传弹窗 | PC | 三步：文件夹或压缩包 → 填齐后台同款字段 → 提交审核 |
| 上传 list | PC | 与后台同字段，无下载链接；审核态；仅空闲可删 |
| 后台七表 | 运营 | 与 v4 相同 |

→ 交付 mock：`demo/iteration/yijian-daifa-pc.html`，壳 Tab `fr-opc-yijian-daifa.html?tab=pc`

## Voice and Tone

| Do | Don't |
|---|---|
| 「扫描二维码联系客服，后台录入后才能上传」 | 「立即申请成为剪辑手」带表单 |
| 「项目中心（已有）」 | 假装本 FR 重做整个 PC |
| 「已产生收益」旁写已回填口径 | 编造每篇单价公式 |

## Component Patterns

| 组件 | 行为 |
|---|---|
| 已有左栏项 | 点击提示「现有功能，本 FR 不改」 |
| 剪辑供稿 | 进看板；未录入改走阻断 |
| 上传弹窗 | 无已录入 / 无授权项目 / 项目禁用 / 未选文件夹或压缩包 / 字段不齐 → 拦截 |
| 看板四卡 | 只统计当前登录剪辑手自己的稿 |
| 上传 list | 出示占用与审核；驳回出示原因；不提供 C 端领取操作 |

## State Patterns

| 状态 | 处理 |
|---|---|
| 未录入 | 不能上传；只见招募与阻断 |
| 已停用 | 同未录入：不能上传 |
| 已录入 | 看板 + 上传弹窗 + list |
| 项目禁用 | 上传下拉里不出现；已传稿仍在 list |
| 审核中 | PC list 可见；C 端广场不可见 |
| 已通过且空闲 | C 端广场可见 |
| 已驳回 | PC list 出示原因；不进广场 |
| 删除 | 仅 `occ=空闲`；占用中 / 已完成禁用删除 |

## Key Flows

**庭宇（已录入剪辑手）在电脑上供稿**

1. 打开已有 PC 创作者中心，进入「剪辑供稿」。
2. 看板看到授权项目、已传、已被领、已产生收益。
3. 点上传，弹窗选文件夹或压缩包，填齐字段，提交审核。
4. list 多一行且为审核中；广场还看不到。
5. 后台通过后，用户在 C 端广场领到该稿。

**高潮：** 电脑提交的稿先过平台审核，通过后才出现在手机广场——供稿闭环在 PC，领取闭环在 C，不交叉做对方的事。

**未录入的人**

1. PC 看见招募海报和客服码。
2. 点上传被阻断，回到招募。无申请表。
