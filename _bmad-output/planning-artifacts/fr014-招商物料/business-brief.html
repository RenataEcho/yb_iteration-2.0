右豹「一键代发」业务介绍

面向剪辑手招募 · 面向市场合作。口径对齐产品合同，不含内部编号与实现细节。分成比例、授权项目、是否免审以商务与运营书面确认为准。

一句话

有制作能力的人交成片，没有制作能力的人领成片去发、去赚。
剪辑手把图集、视频供到平台；用户领取后按项目规则发布，关键词产生的订单收益按事先约定的分成结算。

解决什么问题

短视频与图文项目要持续出片，但大量有流量、有词、有项目资格的人做不出成片。平台把「做片」和「发片变现」拆开：

角色他们缺什么一键代发给他们什么
剪辑手稳定的项目与结算入口授权项目、批量交稿、按领取后的关键词订单分成
领取用户剪辑与成片能力可领的图集 / 视频、发布技巧、下载后直达抖音相册
品牌项目内容供给与达人产能把已有品牌项目接入供稿池，成片可被有词用户领取发布

给剪辑手：为什么加入

适合谁

  • 能稳定产出图集或视频成片
  • 愿意按项目、按书籍供稿，而不是只发自己的号
  • 接受电脑端交稿（手机 App 不能传剪辑供稿）
  • 接受平台审核（部分创作者可协商免审，以录入为准）

你怎么赚钱

用户领取你的稿件时，必须先选定该项目里已审核通过的关键词。该词后续产生的平台订单收益，按领取当时锁定的分成比例拆账：

  • 剪辑手侧：订单收益 × 分成比例
  • 用户侧：订单收益 − 剪辑手分账

结算状态沿用平台已有的关键词订单结算，不另开一套账。电脑「创作者中心 → 剪辑供稿」看板可看：已授权项目、上传数、被领取数、已结算收益；右豹端稿件支持按日 / 按月看明细并导出。

两条供稿路

右豹（站内广场）

成片进入平台作品广场，供已有项目资格的用户领取、回填、发布。适合要平台流量与关键词分账的创作者。

站外

开通后可走独立链接 / 二维码。对方不用登录即可按份下载。适合已有私域、社群、线下合作。站外稿不进右豹广场。

两条路可以只开一条，也可以都开，以入驻时选择为准。

怎么入驻（没有线上申请表）

  1. 看招募海报（卖点、适合谁、底部客服码）
  2. 加客服沟通项目、分成、发布渠道
  3. 运营在后台录入：右豹 ID、分成比例、是否需要审核、发布平台
  4. 电脑打开创作者中心，进入剪辑供稿即可交稿

扫码不等于已入驻。未录入时只能看招募说明，不能上传。

交稿怎么做

  • 只在电脑 · 创作者中心 · 剪辑供稿
  • 一次传：一个项目 + 一本书 + 一种类型（图集或视频）
  • 视频：文件名即标题；图集：一个文件夹一条，文件夹名即标题
  • 可填发布技巧，也可一键用 AI 按书籍生成后再改
  • 右豹稿：提交后进入平台审核（或按约定免审直通）；通过且无人占用才进广场
  • 站外稿：按文件夹分享，扫码即下

成片会留多久

  • 传上去一直没人领：15 天后系统删除云端文件
  • 有人领过：领取人约 3 天内可下载；云端再保留到首次领取后约 7 天
  • 你自己删除：云端立刻一起删，不能恢复；已被占用或已完成的稿不能删
  • 站外：每成功下载一份，该份素材即从云端去掉

请按项目节奏供稿，不要把云盘当长期片库。

给市场 / 商务：如何对外招商

产品定位

右豹一键代发是品牌项目的成片供给与领取分发能力：

  • 不替代现有项目、申词、回填、结算中台
  • 不做成「人人上传自制剪辑」
  • 做成「专业剪辑手供稿 + 有词用户领取发布」的产能网络

一句话对外：把会做片的人和会发片的人接在同一条项目链上，按关键词订单分成。

可谈的三类合作

1. 剪辑产能合作（主招商）
工作室、MCN、兼职剪辑、图文工作室。谈：授权哪些品牌项目、分成、是否审核、右豹 / 站外、月供稿量与类型（图集 / 视频）。

2. 品牌项目扩供
已有品牌项目、缺成片。谈：项目是否接入一键代发池、Logo 与名称带出、启用 / 停用、领取用户是否已有该项目申词资格。

3. 站外分发合作
剪辑手或渠道已有私域。谈：无登录落地页、按份下载、不进平台广场、与站内分账规则分开（站外收益按剪辑手在该项目-书籍下的自产词口径，细节商务确认）。

给合作方的价值主张

  • 供给可管：项目授权、启用禁用、素材类型、审核 / 免审都在运营侧
  • 占用可清：同一成片同时只被一人领取；超时未按规则回填会释放，避免死锁库存
  • 结算可对：分账绑在「领取当时的分成」和「该词的订单结算」上，改比例不回溯已领记录
  • 履约有约束：领取用户须在约定时限内回填发布；多次不履约将失去继续领取资格
  • 渠道可拆：站内广场走平台用户；站外走链接码，互不混进广场

不承诺什么（商务红线）

  • 不承诺保底领取量、保底收益
  • 不承诺站内申请、自助开通剪辑手身份
  • 不承诺 App 内上传
  • 不把本产品说成「代运营整号」或「平台替你发抖音」——平台提供成片、发布技巧与下载后拉起抖音相册，发布动作仍在领取人侧
  • 分成、免审、项目名单必须以录入结果为准，口头承诺无效

商务洽谈清单（建议一次谈清）

  1. 合作身份：个人剪辑手 / 工作室（是否统一右豹 ID）
  2. 发布平台：仅右豹 / 仅站外 / 都要
  3. 分成比例（写入录入，领取时锁定）
  4. 稿件是否需要平台审核
  5. 授权品牌项目清单
  6. 供稿类型与命名规范（图集文件夹 / 视频文件名）
  7. 月度供稿节奏（对齐 15 天未领取清理）
  8. 结算对账周期（对齐平台关键词订单已结算）
  9. 客服对接人与录入时间

用户侧怎么转起来

  1. 用户在作品广场按项目、剪辑师、素材、图集/视频浏览可领成片
  2. 详情可预览（图集有限张、视频短试看），展示分成比例，不展示具体金额
  3. 领取前须：账号可领、剩余次数足够、选好已通过的关键词、该稿空闲
  4. 领取成功后限时回填到该项目页面，并可用官方下载（约 3 天）发布；图集可加水印后再下
  5. 关键词订单结算时，若该词已绑定本次已回填的代发领取，则按分成拆到用户与剪辑手

领取次数含平台配置的免费额度，也可用积分兑换「次数包」。具体档位与积分价以当时商品为准。

招募海报可用短文案

主标题　会做片，就在这变现。

副标题　把成片供进品牌项目，用户领取去发，关键词订单按分成结算。

适合谁　能稳定出图集 / 视频的剪辑、工作室；只在电脑交稿。

三句卖点　授权项目可接 · 批量上传 · 领取后按词分成。

行动　长按识别客服二维码，开通「剪辑供稿」。

脚注　扫码后需运营录入方可上传。未录入不能交稿。收益以平台订单结算为准。

电梯稿（30 秒）

右豹一键代发，让会剪辑的人给品牌项目供成片，让不会做片但有项目、有词的人直接领取去发。剪辑手加客服开通电脑端「剪辑供稿」，图集和视频都能传；用户在 App 里领、回填、发布。钱从关键词订单来，按入驻时谈好的分成，领取当时锁定，结算后两边都能对上账。也可以开通站外链接，给私域按份下载。要合作，先定项目、分成、审不审、走站内还是站外。

本文仅作对外业务解释，不构成保底收益或自助开通承诺。分成、项目授权与审核以运营书面录入为准。
