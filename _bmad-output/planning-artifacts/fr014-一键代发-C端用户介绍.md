# 右豹「一键代发」· 领取用户说明

面向 **C 端领取用户**（有项目、有词、自己不做片）。  
不是剪辑手招募稿，也不讲后台。分成比例、免费次数、积分档位以 **App 当时展示** 为准。

可转发网页版：同级目录 `fr014-招商物料/user-brief.html`（打开后可「打印 / 存为 PDF」）。  
剪辑手 / 商务口径见 `fr014-一键代发-对外招商介绍.md`。

---

## 一句话

**成片已经做好。你领、你发、你回填；这个词后面赚到的钱，要按约定分给剪辑手。**

你不用剪、不用做图。平台把剪辑手供好的图集 / 视频放到作品广场，你选好自己的关键词领取，按发布技巧发出去，再回填数据。钱仍然来自你这个关键词的订单，不是平台另发一笔「代发工资」。

---

## 适合谁

- 已经有品牌项目资格，并且该项目下有 **审核通过** 的关键词
- 会发抖音 / 快手 / 小红书 / 视频号，但不想自己做片
- 愿意在领取后 **24 小时内回填**，并认真做引流、出单

不适合：没有项目、没有已通过的词、只想囤素材不发、或希望领取后收益 100% 归自己的人。

---

## 最重要的一句话（请先读完再领）

**领取稿件之后，该关键词产生的收益，将按约定的分成比例分给剪辑手。**

具体是：

1. **领取时必须先选词。** 你选中的那个已通过关键词，会和这次领取绑在一起。
2. **分成在领取当时锁定。** 详情页会出示分成比例（只出比例，不出金额）。事后剪辑手或平台改比例，**不回溯** 你这次已经领过的记录。
3. **钱从关键词订单来。** 这个词后面产生、并结算到账的平台订单收益，按锁定比例拆开：
   - 剪辑手分到：订单收益 × 分成比例
   - 你分到：订单收益 − 剪辑手这一份
4. **必须回填才算代发绑定。** 只领取、不回填，不构成代发分账；超时未回填，稿件会释放，已扣次数不退。
5. **回填后不能改绑。** 回填时不能改项目、书籍、关键词。这个词之后的结算，都按这次领取锁定的分成走。
6. **每个关键词只领一个作品。** 为确保作品收益分成准确，每个关键词仅可领取一个作品。领取前请确认作品信息，感谢您的理解与配合。已超时释放的词可以再领；未回填或已回填的词不能再绑另一份作品。

请把它当成合作，不是「白嫖成片」。剪辑手把片做好，你负责发出去、把词做出单；两边按约定分这笔词的收益。

## 使用流程

按这个顺序做，不要跳。

### 1. 先确认自己能领

打开右豹 App，确认三件事：

- 你已经在对应 **品牌项目** 里有资格
- 该项目下至少有一个关键词状态是 **审核通过待发布** 或 **审核通过已回填**
- 账号没有被停权（终身未回填超过 3 次会被禁止继续领取）

没有已通过的词，广场里再好看也不能领。可先去该项目题词，等审核通过再回来。

### 2. 到作品广场挑成片

首页或作品广场进入 **一键代发** 成片池。

- 按项目图标筛选（只看你要发的那个项目）
- 需要时再按剪辑师、素材、图集 / 视频缩小范围
- 可用书名、稿件名搜索
- 列表 **不展示收益金额**，不要凭封面猜能赚多少

点进详情再决定领不领。

### 3. 看详情，再决定

详情里你能看到：标题、项目、书籍、剪辑师、**分成比例**、领取步骤。

- **图集**：最多预览 3 张（角标仍是真实张数）
- **视频**：可试看约 5 秒
- 预览 **不扣次数、不等于领取**，也不能长按保存

看清分成比例。能接受「这个词以后的单要分给剪辑手」，再点领取。

### 4. 有次数，才能选词领取

点领取后，系统按这个顺序拦：

1. 是否被停权  
2. 当天免费次数 + 已购次数是否够  
3. 你是否选好了该项目已通过的词  
4. 这份稿是否还空闲（同时只给一个人）

次数不够：先在当前页用积分兑换次数包，兑换成功后再领。  
选词时：必须选 **和这份稿同一本书** 的已通过词（词带了书籍 ID 时）。没有默认带入，不能跳过选词只扣次。

领取成功即 **扣 1 次（不退）**，这份稿对其他人隐藏。

### 5. 下载、发布、回填（24 小时内必须做完回填）

领取成功后停在详情，中部出现 **发布技巧**（可复制）。底栏是：

- **添加水印**（仅图集；视频暂不支持）
- **下载并发布到抖音**（保存到相册后拉起抖音选片）

然后立刻去做两件事：

1. **按发布技巧发出去**（见文后「发片注意事项」）  
2. 打开 **我的领取 → 立即回填**，把作品信息填回该项目已有回填页  

回填窗口是 **领取后 24 小时**。  
官方下载窗口是 **领取后约 3 天**（未回填、已回填都可以在这 3 天内再下；超时未回填则下载失效）。

### 6. 出单后怎么到账

关键词订单转为 **已结算** 时：

- 若这个词已经绑定你这次 **已回填** 的领取 → 按锁定分成自动拆到你和剪辑手
- 若没有代发绑定 → 仍按原来的规则，全额进你的账户

待结算只累计，不算到账。同一笔订单 + 同一个词只入一次账。你在项目收益明细里会看到：应结算、代发分账、实际到你账上的金额。

## 次数怎么算

- 平台按工作日 / 节假日配置 **每日免费领取次数**（以 App 剩余次数为准，用完即止）
- 免费不够，可用积分兑换次数包；档位、积分价、划线价以兑换浮层当时展示为准
- **领一次扣一次，不退。** 超时没回填、下载过期、自己不发，次数都不会退回来
- 同一份稿超时释放后，你还可以再领，但要 **再扣一次、再选一次词**

成片本身有制作成本。领了不发、乱发、糟蹋素材，既浪费库存，也占了别人能拿去出单的机会。请领一套、发一套、回填一套。

发了、回填了、词能持续出单，你才有资格把「领成片 → 发 → 出单 → 再领」做成循环。免费额度和次数包都是为了让你 **认真运营**，不是用来囤片。

## 发片注意事项（建议按这个做）

参考一线发片经验整理，具体平台规则以各平台当时审核为准。

### 一套怎么用够

- 一份完整图集通常张数充足，够你认真做一轮分发，不要拆碎乱发
- **一套素材可以发多个平台**：抖音、快手、小红书、视频号
- **视频号**需要先转成视频再发；快手、小红书可继续发图集
- 先垂直发、持续发同一类型，比今天换赛道明天换口令更稳

### 流量出来之后怎么处理

1. **发布后播放 / 阅读低于 100**  
   先自查这个号能不能正常推。若推不动，删掉本条，再领新稿重发。少部分账号发不了偏 AI 风格的内容，换号或换类型，不要死磕同一条。

2. **播放 / 阅读高于 5000**  
   尽快用小号做引流，把热度接到你的关键词转化上，否则只有曝光没有单。

3. **发布后盯评论区**  
   如果出现别人发的其它口令、别的项目名，**立刻删评**，防止被截流。

4. **显示限制传播 / 审核不通过**  
   同样删除内容，领取新稿重新发，不要在一条被限的作品上反复改。

5. **先垂直、再放量**  
   同一类型连续发，账号权重更稳；不要领了图集发两张就弃、也不要一套稿件改到认不出来。

### 价格底线

- 外面自制一套 70～100 张漫画素材，成本大约 3～10 元。你领到的是现成片，价格已经压在成本附近。
- 现在新人特惠 1 元 5 次，主打鼓励用心运营，不是让你囤、也不是让你拿去浪费。
- 如果用废号批量乱发、糟蹋素材，之后单次购买 3 元一次，也是成本价。

### 回填与出单

- 发出去之后，必须回填。不回填 = 这次领取作废，次数不退，稿件会回到广场给别人
- 回填越及时，这个词后续订单才按代发规则拆账，你和剪辑手才能对上
- 出单靠的是：对的词 + 认真发 + 会引流，不是领得越多越好

## 常见问题

**Q1. 领取后收益是不是全给我？**  
不是。领取稿件之后，该关键词产生的收益按约定分成分给剪辑手，你拿到的是扣完分成后的部分。

**Q2. 我可以领完再换一个词吗？**  
领取时选定的词会锁定。回填也不能改词。要换词，只能等这次结束（回填完成或超时释放）后，用新的词重新领取（再扣次）。

**Q3. 预览了算领取吗？**  
不算。只有选词确认成功才扣次、才占用。

**Q4. 为什么点了领取却领不了？**  
常见原因：被停权、次数不够、没选已通过的词、词和稿件不是同一本书、稿件已被别人占用。按提示处理即可，失败不会扣次。

**Q5. 24 小时内没回填会怎样？**  
稿件释放回广场，次数不退，记 1 次未回填。终身未回填超过 3 次（第 4 次超时），账号停权，不能再领任何稿，只能等平台处理。

**Q6. 下载只有 3 天吗？**  
是。领取后约 3 天内可官方再下。超时未回填则下载失效。过期后不要默认还能找回原片。

**Q7. 图集和视频发布有什么不同？**  
图集可加水印后再下；视频暂不支持加水印。下载并发布默认拉起抖音相册。视频号需自行转视频；快手、小红书可发图集。

**Q8. 平台会替我发抖音吗？**  
不会。平台提供成片、发布技巧、下载后拉起相册，**发布、评论区维护、引流转化都是你来做**。

**Q9. 广场上看不到金额？**  
是的。列表不展示收益；详情只出分成比例。具体到账看项目收益明细。

**Q10. 领了不发可以吗？**  
技术上你能领走，但 24 小时不回填会释放、次数不退，还可能累计停权。更重要的是：你占着别人也能拿去出单的成片。请不要囤稿。
