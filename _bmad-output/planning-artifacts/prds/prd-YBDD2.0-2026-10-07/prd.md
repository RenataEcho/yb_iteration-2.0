# PRD: 2.0优化（创作者首页与学院）

本文件只覆盖 **FR-021** 这一刀增量：C 端创作者 App（V125 交互真源）与 **学院中心管理后台**。不并入其它迭代 PRD，也不改写历史 FR 页。

## 0. Document Purpose

给产品、UX、架构与后续 SPEC / Epic 使用。词汇以 §3 为准。本文 **FR-n** 表示本增量内第 n 条能力；迭代需求页全局编号为 **FR-021**（`demo/iteration/fr-creator-home-2-opt.html`）。

交互与验收以 `demo/iteration/creator-home-2-opt-demo.html` 为准；UX 工作区为 `_bmad-output/planning-artifacts/ux-designs/ux-YBDD2.0-2026-10-07/`。**Demo 与已定 spines 冲突时 spines 优先**；冲突项记入 §8 并在 UX Finalize 时对齐。

## 1. Vision

创作者打开右豹，首页同时承担「学」与「赚」：学院教方法，找项目与榜单指向收益。2.0 之前信息堆叠、工具抢项目主角、动态与榜单抢注意力，新手难以判断「先学什么、再做什么」。

这一刀把首页收成清晰层级：**新手学院 vs 活动中心** 角色分离；**找项目** 以赛道与收益为主、关联工具退一级；**今日路径** 用可拖拽气泡把「今天该完成的 3 步」挂在首页而不占整屏；**学院中心** 与后台课程/分类/新人推荐/学习数据打通，完课口径简单可统计。

交付沿用增量：新开 FR-021 迭代页与 Demo，不回改历史迭代页。后台「项目管理」「工具管理」仅占位，不在本刀范围。

## 2. Target User

### 2.1 Jobs To Be Done

- **新手创作者**：在首页分清学习与活动，从学院入门，再按推荐项目跑通领取→发布→回填→结算。
- **成熟创作者**：快速切换国内/国外赛道，看项目收益与关联工具，少点一层就能「去使用」。
- **学院运营**：在后台维护课程（图文/视频）、分类、新人推荐位，查看基础学习效果。
- **产品/研发**：以 Demo 为可点击验收真源，双端（C 端 / 学院后台）可一键切换演示。

### 2.2 Non-Users (v1)

- 需要完整教务（排课、考试、证书、复杂报表）的运营——本刀只做基础学习数据。
- 要在本增量里实现后台「项目管理」「工具管理」菜单对应能力的人。
- 依赖 Demo 内示例收益数字做真实结算或对账的人（数据 Tab 示例数据明确不计入账户）。

### 2.3 Key User Journeys

- **UJ-1. 小周首日打开 App，先学院再找项目。**
  - **Persona + context:** 小周，刚注册，被社群推荐右豹。
  - **Entry state:** 已登录 C 端，默认首页 Tab。
  - **Path:** 看到「新手学院」与「活动中心」双卡轮播 → 点学院卡进入学院中心（非活动轮播帧）→ 选「项目教学」频道 → 打开图文课 → 按标题、正文、通栏图读完正文 → 在文末看到推荐课程 → 返回首页 → 在找项目选国内赛道 → 点项目关联工具 chip → 在 Bottom Sheet 看推荐原因 → 去使用。
  - **Climax:** 学院与活动视觉/文案角色清晰；找项目以项目和收益为主，工具含「为什么推荐」。
  - **Resolution:** 底栏可切变现/工具/数据；今日路径气泡仅在首页可见。
  - **Edge case:** 从学院子页返回后，底栏恢复；课程详情页强制隐藏底栏。

- **UJ-2. 小周用今日路径安排当天三件事。**
  - **Entry state:** 首页 Tab，路径气泡默认收起。
  - **Path:** 短按气泡展开「今日为你规划的路径」→ 查看 1/3 进度与三个推荐项目 → 拖气泡到不挡找项目区域 → 再点收起。
  - **Climax:** 拖拽 ≥4px 视为移动，移动时自动收起展开层；位置限制在手机画布内并留出底栏安全区。
  - **Resolution:** 切到变现 Tab 时气泡隐藏。

- **UJ-3. 运营李姐维护一门视频课并看完成率。**
  - **Entry state:** Demo 切到「学院管理后台」（或 `Alt+B`）。
  - **Path:** 课程管理 → 新建 → 填标题/分类/封面/类型视频/单视频 → 保存并上架 → 学习数据 → 按规则理解完成率（视频 ≥90% 播放进度）。
  - **Climax:** 图文完课 = 浏览至正文最后一块；视频完课 = 进度 ≥90%；页面声明不建设复杂教务。
  - **Resolution:** 后台从编辑/详情触发预览时，打开 **C 端学院课程详情页** 播放；课程列表行只展示封面，无列表级预览按钮。

## 3. Glossary

- **本迭代页** — FR-021 需求记录页 `fr-creator-home-2-opt.html` 及其嵌入 Demo。
- **产品 Demo** — `creator-home-2-opt-demo.html`；标注 **V125**；C 端与学院后台交互真源。
- **C 端 App** — 手机画布内五 Tab：首页、变现、工具、数据、我的；含学院中心/课程详情等全屏子页。
- **学院管理后台** — Demo 内 B 端：课程管理、分类管理、新人推荐、学习数据。
- **新手学院卡 / 活动中心卡** — 首页双卡轮播：前者入口学院中心（学习），后者活动营销（收益/活动）。
- **找项目** — 首页模块：国内/国外赛道 Tab + 项目列表；项目为主、关联工具为次级 chips。
- **项目关联工具** — 项目行上展示的工具 chips；可打开 **工具 Bottom Sheet**。
- **工具 Bottom Sheet** — 半屏层：工具名、描述、适用范围、**推荐原因**（「为什么推荐：…」）。
- **今日路径** — 首页悬浮 **路径气泡** + 可展开的路径说明与推荐项目按钮。
- **路径气泡** — 可拖拽、点击展开/收起的浮标；仅首页 Tab 显示。
- **学院中心** — C 端全屏页：频道（项目教学、案例拆解、进阶技巧、我的学习）+ 课程列表。
- **我的学习** — C 端用户资产入口（最近学习、我的收藏）；**不是**后台可配置的课程分类。
- **完课（图文）** — 用户浏览至该图文课程**正文最后一块**。文末推荐课程区不计入完课。
- **图文课程** — 详情为纵向文图混排：标题、正文段落、通栏配图可交替；不是横滑图集，也不是步骤蒙层卡。正文文案以后台配置为准。
- **完课（视频）** — 该视频播放进度 **≥ 90%**。
- **示例数据（数据 Tab）** — Demo 内演示用收益展示；**不代表真实收益、不计入账户**。

## 4. Features

### 4.1 C 端 · 首页信息层级与减噪

**Description:** 首页模块顺序与视觉权重按 V10+ 减噪原则落地：学院/活动分角色、榜单 TOP3 强化、动态条数收敛、找项目主角化。实现 UJ-1。

**Functional Requirements:**

#### FR-1: 首页模块顺序与顶栏

创作者在首页 Tab 可按固定顺序浏览：顶栏（头像/标签、消息角标、搜索）→ Banner → 三格数据（今日预计收益、任务数、可提现）→ 新手学院/活动中心双卡 → 设置工作台入口 → 榜单 → 找项目 → 右豹动态 → OPC 服务机构。实现 UJ-1。

**Consequences (testable):**
- 五 Tab 底栏在首页/变现/工具/数据可用；「我的」无独立页时行为与现网/Demo 一致（如 toast 占位）。
- **设置工作台**入口保留在首页模块序中；**交互与字段沿用现网**，本 FR 不改造（D-5）。
- 学院中心页、课程详情页打开时隐藏底栏；返回后恢复。

#### FR-2: 新手学院与活动中心双卡

系统以双卡轮播区分「学习」与「活动」角色；各卡 2 帧内容，支持点击切帧与约 **4.2s** 自动轮播。实现 UJ-1。

**Consequences (testable):**
- 学院中心入口卡点击时 **进入学院中心页**，该点击不被同卡轮播逻辑吞掉（capture 优先级高于轮播）。
- 活动中心卡仍走轮播切换，不误开学院中心。

#### FR-3: 榜单展示与 TOP 权重

首页展示横滑两榜（如平台项目榜、OPC 经营数据榜）；每榜最多 **5** 条；第 **1–3** 名视觉强化，第 **4–5** 名降权；第二榜卡片露头暗示横滑。实现 UJ-1。

**Consequences (testable):**
- 点击榜单区域可进入完整榜（或等价导航）；字段含名次、名称、指标文案、金额/人数等，与 Demo 一致。
- V32–V33 榜宽规则：项目榜与 OPC 榜宽度比例与 Demo 一致（OPC 榜可完整露出头像）。

#### FR-4: 右豹动态条数收敛

首页动态区默认最多展示 **2** 条 feed；「查看全部」跳转 **现网已实现的完整动态/列表页**（本 FR 不新建该页）。实现 UJ-1。

**Consequences (testable):**
- 列表第 3 条及以后不在首页露出。
- 「查看全部」路由与交互复用现网已有页面，仅保证首页仍只露 2 条。
- `[ASSUMPTION: 实现时 DOM 与选择器统一为 feed 结构，避免 Demo 内 #dynamicList 与 .feed 不一致导致验收歧义。]`

### 4.2 C 端 · 找项目与关联工具

**Description:** 找项目以赛道 Tab + 项目列表为主；每个项目可挂关联工具 chips，打开带推荐原因的 Bottom Sheet。实现 UJ-1。

**Functional Requirements:**

#### FR-5: 国内/国外赛道 Tab

创作者可切换国内（默认）、国外赛道；切换后项目列表刷新为该赛道数据。实现 UJ-1。

**Consequences (testable):**
- 国内 Tab 默认选中；Tab 文案与 badge（如「默认」）不污染赛道名称解析逻辑。
- 项目行展示图标、名称、副文案（项目数·顶尖月入等）；**收益金额右置**（V32 营销感）；大额 ≥1 万可格式化为「¥x.xx万」。

#### FR-6: 项目关联工具 chips 与 Bottom Sheet

每个项目行展示关联工具 chips 与「更多」；点击 chip 或更多打开 **工具 Bottom Sheet**。实现 UJ-1。

**Consequences (testable):**
- Sheet 标题为单工具名或「项目名 · 推荐工具」；每项含图标、名称、描述、适用范围、**tool-reason**（「为什么推荐：…减少重复操作，提高完成效率」类文案）。
- 点击遮罩关闭；「去使用」关闭 Sheet 并进入使用流程（或 toast/跳转，与 Demo 一致）。
- V34–V35：推荐工具作为**卡片底部分割行**整行展示，不参与主信息横排挤占。
- 首页项目 chips 样式不受变现页 `.project-tools` grid 污染（V26–V27 隔离要求）。

#### FR-7: 项目与工具数据映射

系统按项目维护 **关联关系**（`projectId`、`toolId`、排序、`recommendReason`）；工具 **名称、描述、适用范围** 等元数据 **同步「工具市场」主数据（ToolCatalog）**，不在本 FR 重复维护工具主档。本刀不要求「项目管理/工具管理」占位菜单。实现 UJ-1。

**Consequences (testable):**
- 至少覆盖 Demo 示例项目的关联与 Sheet 行为可验收。
- 工具市场侧更新工具信息后，找项目 Sheet 展示随主数据刷新（允许最终一致）。
- 运营仅配置「某项目关联哪些 toolId + 推荐原因」，不得在本 FR 后台新建平行工具库。

### 4.3 C 端 · 今日路径气泡

**Description:** 首页提供可拖拽、可展开/收起的今日路径浮标，承载当日推荐项目与路径说明。实现 UJ-2。

**Functional Requirements:**

#### FR-8: 路径气泡展示与文案

首页 Tab 显示路径气泡；默认收起；展开层含标题「今日为你规划的路径」、说明（领取→发布→回填→结算）、进度示意（如 1/3）、三个推荐项目按钮与「查看路径」。实现 UJ-2。

**Consequences (testable):**
- 非首页 Tab 不显示气泡。
- 展开/收起通过点击气泡 toggle；独立「收起」控件可用。

#### FR-9: 路径气泡拖拽

创作者可拖拽气泡；移动 **≥4px** 视为拖拽，拖拽过程中收起展开层；释放后位置 clamp 在手机画布内，底部留出底栏安全区（约 90px）。实现 UJ-2。

**Consequences (testable):**
- 支持 pointer 与 touch；拖拽与点击互斥（未达阈值视为点击展开）。
- 浮层 z-index 与 Bottom Sheet 共存不遮挡异常（V17/V29 行为）。

### 4.4 C 端 · 学院中心与学习流

**Description:** 学院中心与首页学院卡联动；频道过滤、图文/视频详情、收藏与最近学习。实现 UJ-1。

**Functional Requirements:**

#### FR-10: 学院中心结构与频道

学院中心含可关闭的新人条、频道 Tab：**项目教学 | 案例拆解 | 进阶技巧 | 我的学习**；列表按 `data-kind`（或等价字段）过滤。实现 UJ-1。

**Consequences (testable):**
- 「我的学习」下分最近学习、我的收藏；展示进度（百分比、继续学习）。
- C 端频道与后台分类（项目教学、案例拆解、进阶技巧）一致；「我的学习」不出现在后台分类配置。

#### FR-11: 课程详情（图文 / 视频）

创作者打开课程详情：图文与视频共用同一套顶部（标题、分类、类型、简介）。视频区为单视频播放器 + 进度条 + 继续观看文案；图文则把该区域换成不限高的正文（段落与通栏图交替），页面向下滚动阅读。支持收藏 toggle。**推荐课程** 在图文或视频正文之后、详情最底部。实现 UJ-1。

**Consequences (testable):**
- 返回栈：详情 → 学院中心 → 首页；详情页无底栏。
- 图文详情不使用横滑图集、张数角标、步骤蒙层卡，也不把正文卡在视频播放器的固定高度里。推荐课程在滚动到底之后出现；无推荐时保留空态，不把推荐区算进完课。
- C 端展示学习进度 UI；**完课判定**与 FR-15 口径一致，由服务端或客户端进度上报实现（Demo 可无完整 JS 校验）。
- 续播与离线：再次进入详情应恢复上次阅读位置或视频进度；上报失败时允许重试，不以单次失败永久丢失完课进度。

### 4.5 C 端 · 变现、工具、数据（Demo 完整面）

**Description:** V125 Demo 含变现/工具/数据 Tab 的完整交互（V20–V39 等迭代）。本增量 **交付与验收包含** 这些面，与 FR-021 页「完整产品 Demo」描述一致；规则抽屉未逐条展开的细则以 Demo 行为为准。实现 UJ-1 扩展路径。

**Functional Requirements:**

#### FR-12: 变现页赛道与视图

变现 Tab 提供赛道 grid、decision-chips（综合推荐/收益高/门槛低/新人可做/日结等）、列表/宫格切换；宫格模式 **不展示** 推荐工具行（V32）。实现 UJ-1。

**Consequences (testable):**
- 列表模式项目卡可含推荐工具行；点击推荐工具 **直接打开工具详情 Sheet**（V30）。
- V22：变现/工具职责拆分；**首页结构不因变现迭代而改动**。

#### FR-13: 工具页

工具 Tab 提供场景 grid、工具市场列表与「提工具需求」。工具市场卡片只展示工具信息，**不展示推荐项目或适用项目组件**，也不从该列表打开项目详情。实现 UJ-1。

**Consequences (testable):**
- 支持「提工具需求」表单：需求描述（如 120 字限制）、场景多选、选填联系方式。

#### FR-14: 数据 Tab 与示例数据

数据 Tab 提供黑金 Hero、数据分析入口；无真实收益时展示空态；示例数据 Sheet 明确 **不代表真实收益、不计入账户**；可「退出演示」回空态。实现 UJ-1。

**Consequences (testable):**
- 空态下拦截或引导分析入口，与 Demo 一致。
- V31+ 视觉规范仅作用于 `#dataPage`，不影响首页。

**Out of Scope（本 Feature 内）**
- 真实账户收益计算、对账、报表导出——沿用现网能力或另开 FR。

### 4.6 学院管理后台

**Description:** B 端四模块：课程、分类、新人推荐、学习数据；菜单占位项不在本刀。实现 UJ-3。

**Functional Requirements:**

#### FR-15: 学习完课统计口径

系统在「学习数据」模块按统一口径统计完成率：**图文** = 浏览至正文最后一块（推荐课程区不计）；**视频** = 播放进度 ≥ **90%**。实现 UJ-3。

**Consequences (testable):**
- 页面说明含「查看基础学习效果，不建设复杂教务体系」。
- 指标含详情 UV、学习人数、完成率、收藏等；支持课程维度表与时间/排序筛选（能力级别与 Demo 静态表一致，生产接真实数仓）。

#### FR-16: 课程管理 CRUD

运营可新建/编辑/上架/下架课程；必填：标题、分类、封面（16:9）、类型（图文|视频）；选填：关联项目、简介、适合人群、排序。实现 UJ-3。

**Consequences (testable):**
- 图文：正文块为段落与通栏图，可增删、可交替；**一课程多段**。不再按「多图 + 每图一句说明」的图集编辑。
- 视频：**一课程仅一视频**。
- 列表筛选：标题或 ID、分类、类型、状态；统计卡片：全部/已上架/图文数/视频数。
- 无标题时保存拦截并提示；列表行 **课程列仅展示封面+标题**，无列表级「预览」按钮；操作含编辑、上/下架。
- 在 **编辑/详情** 触发预览时，打开 C 端 **学院课程详情页**（图文纵向阅读 / 视频播放），不复刻 Demo 260ms 自动切屏。

#### FR-17: 分类管理

运营可查看分类行（图标、名称、课程数、排序、启用开关）；可新建、编辑名称/图标/排序，并用开关启用或停用。保存后列表立即更新。实现 UJ-3。

**Consequences (testable):**
- 明示：「我的学习」为用户资产入口，**不在此配置**。
- Demo 中新建与编辑写入当前会话的分类列表；已启用分类按排序出现在 C 端学院频道，停用后频道隐藏。重开页面恢复初始三条。

#### FR-18: 新人推荐配置

运营可配置新人板块标题、引导文案、推荐课程列表（排序、移除、添加）；保存成功有反馈。实现 UJ-3。

**Consequences (testable):**
- 配置与 C 端学院新人条展示联动。

## 7. Success Metrics

**Primary**
- **SM-1**: 首页减噪验收通过率 — 产品/UI 按 Demo 走查清单（学院/活动、TOP3、动态 2 条、找项目布局）一次通过率 ≥ 90%。 Validates FR-1–FR-4, FR-5–FR-6。
- **SM-2**: 学院完课口径一致 — 图文正文末块、视频 90% 在 C 端进度与后台学习数据对齐，抽样课程零口径冲突。 Validates FR-11, FR-15。

**Secondary**
- **SM-3**: 找项目工具 Sheet 使用率 — 进入找项目模块的用户中，打开 Bottom Sheet 占比相对 2.0 前基线提升（基线 TBD）。 Validates FR-6。

**Counter-metrics (do not optimize)**
- **SM-C1**: 首页轮播点击率 — 不应为拉高活动轮播点击而弱化学院入口清晰度。 Counterbalances SM-1。
