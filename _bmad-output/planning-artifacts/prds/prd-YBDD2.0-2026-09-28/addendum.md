## 2026-10-10 比例分开与收费方式

同日用户看过编辑弹窗后改口。代运营合作模式仍是多选，每个选中的模式单独设置 0 到 100 的比例。未勾选的模式不出现比例。上面「选中后不展开比例」不再采用。

新增字段「稿件收费方式」，选项是跟随平台、定制。定制时出现单次积分，写成单次 x 积分，须是大于 0 的整数。跟随平台不填积分。

入账快照改为这条稿件所属模式的那一份比例。上面「结算仍读那一个分成比例」不再采用。
