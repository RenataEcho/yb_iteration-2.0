## Gaps（信号有、FR 结构丢掉 / 收窄 / 倒置的点）

1. **「可以领一本书」的定性（能力/领取单位）被收成硬上限「只领取一本书 / 不能再领另一本书」。** 信号是「可以」；§2.1、UJ-2 Resolution、FR-4 写成终身式独占一书。把用户句当成硬 cap = **inference（writer 加硬）**；真正缺口是软「可以」未在 FR 里保留为可再领/上限未定的定性。
2. **「领一本书」被扩成整书已下发词一次全部归他、不逐条另领。** 信号只说领书 + 一书多词 + 一词一任务；未说领书 = 整包任务瞬时归属。FR-4 「全部领取成功，不逐条另领」是 **inference（整书一次领完）**，不是用户原句缺口的“漏记”，而是加码。
3. **领取单位 vs 数量上限被绑死。** 信号可只表达“领取粒度是书”；FR 把粒度与「一名只能一书」绑在同一条后果里，丢掉“粒度是书、数量另议”的定性空间。
4. **「每个关键词一个任务」被接到「一条稿件 / 无稿件包」等下游合同。** 一词一任务在信号内；FR-5/帐号代发路径再钉「一个任务一个关键词一条稿件」——扩展而非信号句；若把“用户要求一词一稿”当漏句 = **inference**。
5. **他人可见不可领、一词只一名剪辑手等排他规则。** 信号未写；FR-4 「领走之后其他人仍能看见这本书，但不能再领」「一个平台关键词只被这一名剪辑手领走」为 PRD 加码。当成用户原句遗漏 = **inference**。
