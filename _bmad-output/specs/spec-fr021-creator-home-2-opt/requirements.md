# FR-021 功能需求（稳定编号）

PRD 内 FR-1…FR-19 与此文件 **FR-021-01…FR-021-19** 一一对应。验收以本文件 + Demo V125 为准。

## FR-021-01 首页模块顺序与顶栏

- 模块顺序：顶栏 → Banner → 三格数据 → 学院/活动双卡 → 设置工作台 → 榜单 → 找项目 → 动态 → OPC。
- 学院/详情页隐藏底栏；返回恢复。
- 五 Tab 可用；「我的」与现网/Demo 一致。

## FR-021-02 新手学院与活动中心双卡

- 双卡各 2 帧；4.2s 自动轮播。
- 学院卡点击进入学院中心（capture 优先于轮播）；活动卡仅轮播。

## FR-021-03 榜单

- 横滑两榜；每榜 ≤5 条；TOP3 强化、4–5 降权；第二卡露头。
- OPC 榜头像完整露出（V33）。

## FR-021-04 右豹动态

- 首页最多 **2** 条；「查看全部」跳转 **现网已实现的完整列表页**（不新建）。

## FR-021-05 找项目赛道 Tab

- 国内默认 / 国外；列表随赛道刷新；收益右置；≥1 万可万元格式。

## FR-021-06 项目工具 chips 与 Sheet

- 底部分割行 chips + 更多；Sheet 含 recommendReason；V26–V27 样式隔离。

## FR-021-07 项目↔工具映射

- 维护 projectId–toolId–sort–recommendReason（ProjectToolLink）。
- 工具名称/描述/适用范围 **读取工具市场主数据（ToolCatalog）**，禁止平行工具库。

## FR-021-01 补充（设置工作台 D-5）

- 首页保留设置工作台入口；**行为与字段沿用现网**，本 FR 不验收改造。
