# 开发提示词模板（开工包）

一次会话一份故事。三层分开，禁止合成一份长文：

| 层 | 文件 | 写什么 |
|----|------|--------|
| WHAT | `requirements.md` | 唯一规则源。禁止复述全文 |
| 合同 | `impl-prompts.md` | 节点表保持瘦。禁止把 Tasks / Code Map 写回来 |
| 开工 | `stories/STORY-NNN.md` | 本切片一次会话包（按下面 8 块） |

节点名必须与该端 SVG / `impl-prompts.md` 一致。合同与图冲突以 FR 为准，并在 Always 标明。

新会话把「故事头 + 粘贴开工 + 本故事 8 块」整份交给实现者，不要再拼第三份长文。

## 粘贴开工（故事里写满，可直接复制）

你只做本故事这一刀。先读本文件，再按「2. 指向」打开 FR / 合同节点行，再打开 Code Map 标行号的函数。然后 §6 红→绿。禁止另写规则，禁止改范围外文件。

## 故事头（写死，不可混）

- **闭环：** `Demo 闭环` 或 `真后端`（二选一）
- **端 / 切片：** 只改哪一端、哪一刀；一次一个切片
- **身份：** Demo 写 `YJD.KEY`（以代码为准，禁止手填旧 key）；真后端写基路径

## 1. 角色

你只实现「{端} / {切片}」。不要动其它端、其它刀、其它 FR。

## 2. 指向

- WHAT：`requirements.md` → FR-{id}（只列号，不抄 Consequences）
- 合同：`impl-prompts.md` → 节点「{与 SVG 一致的名字}」行 {n}
- 禁止另写规则、禁止扩写判定/写/回/文案

## 3. Always / Never / Ask First

**Always**
- 凡本切片含领取门禁，顺序不可颠倒：停权 → 次数 → 选词 → 资格/占用
- 不改 FR-001 / FR-002 / FR-012 / FR-013
- 复用 `demo/iteration/ITERATION-FR-GUIDE.md` §九 class，不新造按钮/浮层/toast

**Never**
- 不改业务规则；不重写 WHAT；不改范围外文件
- Demo 切片禁止 `fetch` / 新 HTTP
- 不删已有 e2e，只追加

**Ask First**
- 必须 bump store `VER`、改 seed 形状、或改节点表时先问
- 能用 `page.evaluate` 临时挂字段写 e2e 的，不升级 Ask First；写进 Always
