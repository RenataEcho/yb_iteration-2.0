# 后台配置字段表

运营「配置 → 保存」；校验失败不保存。C 端不读未下发字段，视为未配置。

新增/编辑两步：

1. 基础信息 + 活动介绍 + 案例 + 榜单
2. 活动规则（活动领取 + 奖励规则）

## 1. 第 1 步 · 基础信息与详情内容

### 1.1 基础信息

| 字段键 | 名称 | 必填 | 约束 | C 端用途 |
|---|---|---|---|---|
| `title` | 标题 | 是 | ≤64 | 卡片/Banner/详情标题 |
| `description` | 活动描述 | 否 | ≤40；与标签分开 | 列表卡片标题下灰字；未填不展示 |
| `cover` | 封面 | 否 | 图片 | 详情顶栏左侧；未下发不展示 |
| `tags[]` | 标签 | 否 | 回车添加；可空；**不是描述** | 详情标签行 |
| `platform` | 所属平台 | 否 | 下拉；空=未选 | 后台筛 |
| `track` | 所属赛道 | 否 | **现有赛道 list** | 后台筛 |
| `projects[]` | 项目 | 否 | **现有项目 list，多选**；不依赖先选赛道 | 卡片/详情「项目·」 |
| `startAt` | 活动周期开始 | 是 | datetime | 角标、筛选、领取可否点 |
| `endAt` | 活动周期结束 | 否 | 空=长期；有值不得早于开始 | 角标、筛选、领取可否点 |
| `initialViews` | 浏览量 | 否 | 默认 0，≥0 | 必下发「x人浏览」 |
| `enrolledCount` | 参加人数 | 否 | 虚拟整数；空=未配置 | 仅配置了才下发 |
| `visible` | 活动状态 | 是 | 显示 / 隐藏 | 显示才进显示池 |
| `pinned` | 是否置顶 | 否 | 默认否；显示池内最多 1 条 | Banner |

置顶冲突：不得同时存在两条显示中的置顶。冲突时 **拒绝保存**，提示先取消原置顶，不自动置换。

### 1.2 活动介绍 / 案例

| 字段键 | 名称 | 必填 | 约束 | C 端 |
|---|---|---|---|---|
| `introContent` | 活动介绍 | 否 | 富文本 | 有则介绍 Tab |
| `cases[]` | 活动案例 | 否 | 多条；每条 **案例名称 + 案例组成** | 至少 1 条完整案例才出案例 Tab |
| `cases[].name` | 案例名称 | 该条已配置时是 | 非空 | 案例块标题 |
| `cases[].assets[]` | 案例组成 | 该条已配置时是 | 图片或视频，≥1 | 该案例媒体 |

一条完整案例 = 名称非空 **且** 组成附件 ≥1。半填不下发。案例不出现在第 2 步。

### 1.3 榜单

| 字段键 | 名称 | 必填 | 约束 | C 端 |
|---|---|---|---|---|
| `leaderboardVisible` | 榜单 | 是 | 开启 / 隐藏 | 隐藏 → 无榜单 Tab、不下发名单 |
| `leaderboardLimit` | TOP 名单数 | 开启时是 | 整数 ≥1；界面文案「前 x 名」 | 截断能力「活动榜单」返回行数 |
| `leaderboardLineDesc` | 行描述 | 否 | ≤20；开启榜单时配置 | 昵称下方灰色小字；未填不展示 |
| `leaderboardPeriodDesc` | 周期描述 | 否 | ≤20；开启榜单时配置 | 金额/奖品下方及本人底栏灰色小字；未填不展示 |

开启才显示 TOP 与两个描述字段；TOP 名单数与行描述同一行，周期描述接下一列。隐藏时不验收条数与描述。后台案例卡片两列平铺。

能力「活动榜单」出参（禁止发明 HTTP 路径）：

| 字段键 | 说明 |
|---|---|
| `rows[].rank` | TOP 名次，从 1 起 |
| `rows[].avatarUrl` | 用户头像；Demo 可用头像初文 |
| `rows[].nicknameMasked` | 脱敏昵称；禁止明文全名；昵称旁无标签 |
| `rows[].value` | 展示串。金额、奖品、或奖品+金额 |
| `self` | 榜单底栏本人：脱敏 `nicknameMasked`、`rankLabel`、`avatarUrl`、`value` |

行描述 / 周期描述不走能力出参，走后台 `leaderboardLineDesc` / `leaderboardPeriodDesc`。C 端为列表：排名列宽固定，TOP 1–3 与第 4 名起同一列对齐；无颁奖台。不投影奖励管理五列。

能力「活动详情」按 `showUserAward` 下发本人结果（非后台编辑字段，**不**要求已开榜单）：

| 字段键 | 说明 |
|---|---|
| `awardStatus` | `won` / `not_won`；仅 `showUserAward=true` 时下发 |
| `awardPrize` | 已获奖时的奖品/金额展示串，可选 |

## 1.4 活动列表与行内操作

列：ID、标题、平台、赛道、项目（多选用顿号拼接）、状态、浏览人数、参加人数（未配显示 `-`；已配数字可点进参与详情）、活动时间、排序、操作「编辑 / 达标用户 / 删除」。

参与详情：用户 ID、用户昵称、手机号、作品数。

达标用户：用户 ID、用户昵称、手机号、达标锚定数据、排名、奖品/奖励金额、奖励计算（按该活动已下发 `rewardRules` 计算）。不建设奖励管理录入页。

筛选项：标题、平台、赛道、活动状态。重置只清空条件，不自动查询。

「排序」列为展示；本 FR 不新增独立排序写入字段，沿用既有列表序。

## 2. 第 2 步 · 活动规则

同一页配置活动领取与奖励规则。

### 2.1 活动领取

| 字段键 | 名称 | 必填 | 约束 | C 端 |
|---|---|---|---|---|
| `needClaimButtons` | 是否需要领取按钮 | 是 | 开关；默认否 | 否 → 无底栏，且不配 `claimButtons` |

开关在「活动领取」标题旁。关闭时前端不显示领取按钮，后台隐藏按钮配置。

开启后最多 **2** 个按钮。空文案 = 未配置、不下发。

| 字段键 | 名称 | 必填 | 约束 | C 端 |
|---|---|---|---|---|
| `claimButtons[].label` | 按钮文案 | 该条已配置时是 | 非空 | 底栏按钮 |
| `claimButtons[].needJump` | 是否需要跳转 | 该条已配置时是 | 是 / 否 | 决定点击行为 |
| `claimButtons[].url` | 跳转地址 | 需要跳转时是 | URL 或小程序路径 | 跳转成功才记已参与 |
| `claimButtons[].clickedLabel` | 点击后按钮变更文案 | 不需要跳转时是 | 非空 | 进行中点击后替换文案并记已参与 |

半填不下发。开关关或 0 条已配置 → 无底栏。无表单字段。无获奖字段。

### 2.2 奖励规则

| 字段键 | 名称 | 必填 | 约束 | C 端 |
|---|---|---|---|---|
| `showUserAward` | 显示用户获奖/未获奖信息 | 是 | 开关；默认否 | 否 → 详情不展示本人展位 |

支持添加 0–N 条。添加入口是「奖励规则」标题旁的文字按钮「添加规则」。规则类型：

**播放奖 `play`**：按播放阶梯配置奖品。每档标「阶梯一 / 二 / …」；`playsFrom`~`playsTo`（区间，均 ≥1 且 to≥from）；`prizeKind` 奖金 `cash` / 实物礼品 `goods`，选定后出现 `prizeValue` 输入框。阶梯标题、区间、奖品类型、奖品值、删除在同一行，不换行。

**全勤奖 `attendance`**：`dailyWorks` 每日有效稿件、`streakDays` 连续打卡天数、`bonus` 全勤奖金。

**累计项目收益奖 `revenue`**：`brandProjects[]` 品牌项目（现有品牌项目 list，下拉多选并支持搜索；含番茄小说、知乎故事及全部品牌项目）+ `otherBizProjects[]` 其他业务项目（商单、版权、融合短剧、融合小说、融合漫剧、海外小说、海外短剧、快手零粉、快手星火，多选）+ `rankLadders[]`：每档标「阶梯1 / 2 / …」；`rankFrom`~`rankTo` 名次区间；奖品类型同播放奖；阶梯同一行不换行。禁止排除项目。两类参与范围至少填一类才算完整。

不完整的规则不下发。完整条件、区间重叠命中顺序、`cash`/`goods` 展示口径见 `fe-be-contract.md` §4。

## 3. 下发组装

- 浏览人数：必带 `initialViews`（缺省 0）。
- `enrolledCount`：仅已配置才下发。
- `description`：仅已配置才下发；列表卡片标题下灰字。
- `cover`：仅已配置才下发。
- 介绍 Tab：有 `introContent` 才下发。
- 案例 Tab：完整 `cases[]` 长度 ≥ 1 才下发。
- 榜单 Tab：仅 `leaderboardVisible=开启` 且 `leaderboardLimit≥1` 才下发开关与条数；`leaderboardLineDesc` / `leaderboardPeriodDesc` 仅已填才下发；名单走能力「活动榜单」。
- 本人结果：仅 `showUserAward=true` 且已算出时下发 `awardStatus`（及可选 `awardPrize`）；与榜单开关无关；详情内容不配置该展位样式。不下发 `isReward`、审核中。
- 开启榜单但未填 TOP 或 TOP 小于 1：保存拒绝（见 `fe-be-contract.md` §8）。
- `needClaimButtons=false`：不下发领取按钮，C 端无底栏。
- `claimButtons`：仅开关开时；最多 2 条；文案 +（跳转地址或变更文案）齐全才下发。
- `rewardRules`：仅完整规则下发。项目收益奖名次阶梯与播放阶梯相同：阈值 + 奖品。C 端不展示该字段正文。
