## 剪辑手（仅 PC）

```
打开已有 PC 创作者中心 → 单一菜单「剪辑供稿」（顶部招募 BN + 下方看板）
  → 点 BN 侧栏抽屉看海报详情（客服二维码）→ 联系客服
  → 后台「剪辑手管理」录入（必填右豹 ID / 分成比例 / 备注）
       ├─ 未录入 / 已停用：不能上传/发布 → 回 PC 招募
       └─ 已录入 → 看板（已授权项目 / 上传 / 已被领取 / 已产生收益）
            → 选择授权且启用的项目
                 ├─ 未授权或项目禁用：拦截上传 → 回选项目
                 └─ 可传 → 弹窗选文件夹或压缩包 → 填齐后台同款字段（必选素材类型）→ 提交平台审核
                      → 上传 list 可见该稿（审核中 / 已通过 / 已驳回）
                           ├─ 审核中 / 已驳回：不进广场；驳回出示原因
                           └─ 后台通过 → 空闲稿进入用户广场
```

## 用户领取

```
看项目 / 作品广场（宫格；仅启用项目；项目图标直选；搜索在项目下；下拉筛剪辑师/素材/稿件类型；Banner 复用已有；不展示金额）
  → 稿件详情（素材铺满；图集张数且可预览≤3 张 / 视频试看 5 秒；预览不扣次不下载；分成比例；领取步骤；次数旁显示）
  → 发起领取
  → 校验剩余次数（免费+已购）
       ├─ 不足：详情浮层选档并兑换（最多 4 档；下架不可兑）→ 回到次数校验
       └─ 足够 → 浮层选择该项目已通过的关键关键词
            ├─ 无/未选：拦截领取 → 回选词
            └─ 已选 → 稿件是否空闲未占用
                 ├─ 否：领取失败 → 回广场
                 └─ 是：下载并保存相册（loading 三态）→ 领取成功（扣次不退 + 占用 + 对他人隐藏）→ 停在详情
                      ├─ 详情改为作品发布技巧（标题/描述可复制）；底栏：添加水印 / 下载稿件
                      ├─ 回填从「我的领取 → 立即回填」进入该项目已有回填页
                      ├─ 下载窗口：领取后 7 天内可再下；超时未下载不可再下
                      │    └─ 添加水印：预览让位底部坞 + 四 Tab 锁最高高度 + 字色/背景上下分行 → 打水印 → 下载（图集张数 / 视频百分比）
                      ├─ 24h 内已回填：占用结束（不再出现在广场）→ 用户可回广场看其他
                      └─ 满 24h 未回填：记原领取人 1 次未回填 + 释放回广场（不退次）
                           ├─ 原领取人未进黑名单：可与他人一样再领该稿（再领再扣次）→ 回广场
                           └─ 原领取人终身未回填 > 3：写入黑名单，不可再领任何稿
                                └─ 后台黑名单手动恢复 → 回广场可再领
领取成功后用户将作品发布；广场与领取列表不展示收益金额，详情只出分成比例
```

## 门禁顺序

先次数，后浮层选词，后占用。次数不足不得打开选词浮层。不可跳过关键词只扣次。
