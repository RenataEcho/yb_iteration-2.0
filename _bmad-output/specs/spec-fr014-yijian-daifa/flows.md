# 一键代发 · 主路径

图在本文件；SPEC 内核只引不画。FR Demo「业务流程」Tab 按 ITERATION-FR-GUIDE 手写 SVG，不用本文件示意当交付物。

## 剪辑手

```
看招募海报（底部客服二维码）→ 联系客服
  → 后台「剪辑手管理」录入
       ├─ 未录入：不能上传/发布
       └─ 已录入 → 选择项目 → 上传图集或视频（必选素材类型）→ 发布到平台 → 进入用户广场
```

## 用户领取

```
看项目 / 作品广场（宫格；项目图标直选；搜索在项目下；下拉筛剪辑师/素材/稿件类型；招募 Banner；不展示金额）
  → 稿件详情（素材铺满；图集张数 / 视频试看 5 秒；分成比例；领取步骤；次数旁显示）
  → 发起领取
  → 校验剩余次数（免费+已购）
       ├─ 不足：详情浮层选档并兑换（最多 4 档；下架不可兑）→ 回到选词浮层
       └─ 足够 → 浮层选择该项目已通过的关键关键词
            ├─ 无/未选：领取失败
            └─ 已选 → 稿件是否已被占用且未满 24h
                 ├─ 是：他人广场不可见；若仍发起则领取失败
                 └─ 否：下载并保存相册（loading 三态）→ 领取成功（扣次不退 + 占用 + 对他人隐藏）→ 进入该项目已有回填页
                      ├─ 下载窗口：领取后 7 天内可再下；超时未下载不可再下
                      ├─ 24h 内已回填：占用结束（不再出现在广场）
                      └─ 满 24h 未回填：记原领取人 1 次未回填 + 释放回广场（不退次）
                           ├─ 原领取人未进黑名单：可与他人一样再领该稿（再领再扣次）
                           └─ 原领取人终身未回填 > 3：写入黑名单，不可再领任何稿
                                └─ 仅后台黑名单手动恢复后可再领
领取成功后用户将作品发布；广场与领取列表不展示收益金额，详情只出分成比例
```

## 门禁顺序

先次数，后浮层选词，后占用。次数不足不得打开选词浮层。不可跳过关键词只扣次。
