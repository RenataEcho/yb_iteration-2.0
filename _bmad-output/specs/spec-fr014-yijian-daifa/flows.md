## 剪辑手（仅 PC）

```
打开已有 PC 创作者中心 → 单一菜单「剪辑供稿」（顶部招募 BN + 下方看板）
  → 看板 / 上传清单「操作说明」页内看手册（未录入也可）
  → 点 BN 侧栏抽屉看海报详情（客服二维码）→ 联系客服
  → 后台「剪辑手管理」录入（必填右豹 ID / 分成比例 / 备注 / 发布平台）
       ├─ 未录入 / 已停用：不能上传/发布 → 回 PC 招募
       └─ 已录入 → 看板（已授权项目数字可点开名单弹窗 / 上传 / 已被领取 / 已产生收益；左收益数据仅右豹端，右最近上传）
            → 选择授权且启用的项目；list 先切右豹或站外
                 ├─ 未授权或项目禁用：拦截上传 → 回选项目
                 ├─ 站外 → 弹窗先填共享字段（无素材类型 / 无压缩包 / 无发布技巧）
                      → 选文件夹（整夹一条，assets=文件数）→ 确认表（ID / 标题 / 素材数 / 大小）→ 免审已通过
                           └─ 不进广场；生成分享链接 / 二维码 → 站外用户打开落地页
                                ├─ 剩余 > 0：点下载立即扣 1 个余量并删该份 OSS → 保存到相册
                                └─ 已领完：缺省态「素材已领完」，无下载（余量空，不是整夹清桶）
                 └─ 右豹 → 弹窗先填共享字段（含书籍链接；必选素材类型；不含标题与大小）
                      → 选批量文件夹或压缩包
                           ├─ 压缩包：先「解压中」→ 再按命名约定解析
                           └─ 文件夹：按命名约定解析
                      → 解析一次条数与总大小（文件名=标题；图集一夹一组；稿件ID 系统生成）
                      → 表格确认（共 x 条、大小 xxxG；列=稿件ID / 名称 / 大小 / 发布技巧；可整表「AI生产发布技巧」；空技巧可入队）
                      → 按条队列上传（稿件 + 发布技巧）
                           ├─ 上传中 / 上传失败：list 出示对应态；失败只重传失败文件
                           └─ 已上传 → list 可见该稿（审核中 / 已通过 / 已驳回）
                                ├─ 审核中 / 已驳回：不进广场；驳回出示原因
                                └─ 后台通过 → 空闲稿进入用户广场
```

## 用户领取

```
看项目 / 作品广场（宫格；仅启用项目；项目图标直选；搜索在项目下；下拉筛剪辑师/素材/稿件类型；Banner 复用已有；不展示金额）
  → 稿件详情（素材铺满；图集张数且可预览≤3 张 / 视频试看 5 秒；预览不扣次不下载；分成比例；领取步骤；次数旁显示）
  → 发起领取
  → 校验剩余次数（当日免费剩余+已购剩余；免费按工作日/节假日配置）
       ├─ 不足：详情浮层选档并兑换（最多 4 档；下架不可兑；原价 &gt; 现价出示划线价）→ 回到次数校验
       └─ 足够 → 浮层选择该用户在该项目下已申请并通过的关键词（C 端拉取现有申词；与项目管理无关；无默认带入）
            ├─ 无/未选：拦截领取 → 回选词
            └─ 已选 → 稿件是否空闲未占用
                 ├─ 否：领取失败 → 回广场
                 └─ 是：领取成功（扣次不退 + 占用 + 对他人隐藏）→ 停在详情
                      ├─ 详情出示「发布技巧」字段 + 一段（#pubTips 只读可复制）；底栏：添加水印 / 下载并发布到抖音（成功后拉起抖音相册）
                      ├─ 回填从「我的领取 → 立即回填」进入该项目已有回填页
                      ├─ 下载窗口：领取后 3 天内可再下；超时未下载不可再下。后台可恢复一次，系统满 7 天删 OSS
                      ├─ 一直未领取：上传起 15 天后系统删 OSS，稿件状态=已删除
                      ├─ 后台 / 剪辑手主动删除：阿里云同步删除，不可恢复
                      │    └─ 添加水印：预览让位底部坞 + 四 Tab 锁最高高度 + 字色/背景上下分行 → 打水印 → 下载（图集张数 / 视频百分比）
                      ├─ 24h 内已回填：占用结束（不再出现在广场）→ 用户可回广场看其他
                      └─ 满 24h 未回填：记原领取人 1 次未回填 + 释放回广场（不退次）
                           ├─ 原领取人未进黑名单：可与他人一样再领该稿（再领再扣次）→ 回广场
                           └─ 原领取人终身未回填 > 3：写入黑名单，不可再领任何稿
                                └─ 后台黑名单手动恢复 → 回广场可再领
领取成功后用户将作品发布；广场与领取列表不展示收益金额，详情只出分成比例
```

## 用户收益入账

```
关键词订单转为已结算
  → 校验该关键词是否绑定已回填的一键代发领取
       ├─ 否：既有全额用户入账（不写剪辑手分账，不用本页文案）
       └─ 是：按分成比例自动分账
            → 剪辑手分账 = 应结算 × 分成比例
            → 用户实结 = 应结算 − 剪辑手分账
            → 同时写入双方既有「项目收益明细」
                 ├─ 用户：标题「您的账户于[{时间}]{项目}结算收益到账{用户实结}元」
                 │        描述含关键词ID、应结算、代发分账、实际结算；状态=已结算
                 └─ 剪辑手：标题「您的账户于[{时间}]{项目}作品代发收益到账{分账}元」
                          描述含稿件ID、代发分账；状态=已结算
待结算只累计，不写明细。同一 orderId+keywordId 只落一次。
```

## 阿里云存储

交付图在 Demo「前后端数据交互 → 阿里云存储 → 业务流程」。站内与站外两条链互不汇合，分 Tab。本文件只收口口径。

```
全部成片上传 OSS（ossKey）
  ├─ 站内（右豹）
  │    未领取：uploadedAt+15 天删 OSS，稿件状态=已删除
  │    首次领取：expireAt=+3 天；ossExpireAt=+7 天（不再走 15 天钟）
  │         ├─ C 端 3 天内：签链可下
  │         └─ C 端过期
  │              ├─ 系统未满 7 天且未恢复过：后台「恢复C端下载」一次 → 重计 3 天（不超过 ossExpireAt）
  │              └─ 系统满 7 天：删对象 ossDeleted，不可下、不可恢复
  └─ 站外
       点下载：claimedAssets+1，立刻删该份 OSS（领一个删一个）
       夹内下一份再走同一条链；不判定整夹是否领完
```

## 门禁顺序

停权 → 次数 → 浮层选词 → 资格 / 占用。次数不足不得打开选词浮层。必须先选词再领取；无默认带入。词带书籍 ID 则须与稿件一致。无/未选不得领取。不可跳过关键词只扣次。领取词与项目新增无关。分成以领取快照为准。已超时后若稿被他人新领，原记录立即不可下。
