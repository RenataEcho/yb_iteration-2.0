# 一键代发 · 词汇

术语表。功能需求只以 `requirements.md` 的 FR-014-01 … FR-014-27 为准，本文件不另开条款。

- **一键代发** — 本增量：剪辑手供稿，用户领取后发布变现。不是 FR-001「代发分配」、不是 FR-002「代发收益」。
- **剪辑手** — 经客服接入、后台「剪辑手管理」录入后，可为项目上传并发布稿件的角色。录入必填右豹 ID、分成比例、备注、稿件需要审核（是 / 否）。
- **招募海报** — 剪辑手入口物料：海报主体 + 底部客服二维码。无站内申请表。
- **用户** — 无剪辑制作能力、靠领取稿件做项目变现的领取方。
- **稿件** — 剪辑手上传并发布到平台的内容单元；类型至少含图集、视频。PC 上传先填共享字段（含书籍链接，不含标题与大小）再选批量文件夹或压缩包；按命名约定解析后按条确认再队列上传。
- **书籍链接** — PC 上传共享填写字段；指向对应书籍。不是确认表列，本轮不写入后台稿件表。
- **稿件名称** — 与标题同一字段。由命名约定解析进确认表，不在共享区手填。文件名（去扩展名）作为作品标题；图集一个文件夹为一组，组名即标题。
- **命名约定** — 解析一条数据的规则：视频按文件名成条；图集按文件夹成组。标题取文件名或组名，不去手填。
- **批量确认表** — 解析后的 excel 格式表。出示共 x 条与总大小 xxxG。列：稿件ID（系统生成）、稿件名称、稿件大小、发布技巧（一段，未识别则空，每行可编；空也可入队）。供确认后再入队。
- **AI生产发布技巧** — 确认表上的整表一键按钮。先出示提示词、约束和规则，确认后按书籍与各条稿件生成一段发布技巧；取消不写表。Demo 不接真模型。
- **解压中** — 选压缩包后、解析前的处理态。文件夹无此态。不是 list 上传三态。
- **上传状态** — 剪辑手端队列态：上传中 / 已上传 / 上传失败。失败只重传失败文件，不重传发布技巧。与平台审核分立。
- **平台审核** — 稿件三态：审核中 / 已通过 / 已驳回。PC 已上传后看剪辑手「稿件需要审核」：是则审核中，否则默认已通过。已通过且空闲才进 C 端广场；已驳回须出示原因。后台可单条或批量审核 / 删除。这是稿件审核，不是剪辑手自助入驻审核。
- **稿件需要审核** — 剪辑手录入/编辑必填：是 / 否。否=该剪辑手后续 PC 上传默认已通过，不回溯已有审核中稿。
- **素材类型** — 剪辑手上传时必选的分类；feed「选择素材」只筛这个字段。后台「素材类型」页维护。
- **作品广场** — 用户浏览可领取稿件的宫格页；只展示平台已通过且未被占用的稿件；项目图标直选，搜索在项目下方；另有剪辑师/素材/稿件类型下拉与招募 Banner。
- **稿件详情** — 单条稿件页。素材区铺满（图集出示张数，视频试看 5 秒）；展示分成比例，不展示收益金额。未领取底栏含次数、快捷提词、领取；领取成功后停在详情，底栏改为添加水印、下载稿件。回填从「我的领取」进入。
- **用户领取页** — 用户查看自己已领取记录、并进入该项目回填页的页面。项目筛选只出现有记录的项目。领取后 7 天内可下载，超时未下载不可再下。
- **作品发布技巧** — 与稿件一并上传的一段发布正文。批量确认表按条出示且可编（未识别则空），可用「AI生产发布技巧」先看提示词再整表生成。领取成功后详情用 `#pubTips` 替换「领取步骤」：出示「发布技巧」字段名 + 只读一段，整段可复制。读写优先 `pubTips`，旧数据由标题+描述拼成一段。
- **添加水印** — 领取后从详情进入的水印页：在图集首张 / 视频首帧上拖动定位文字，字体字色背景沿用通用剪辑预设。
- **关键关键词** — 用户自主申请并通过的词。C 端领取时拉取现有申词结果，浮层先选词再领取；无默认带入。本 FR 不另建词库，也不在项目管理维护。未选词或无已通过词不得领取。快捷提词提示跳转该项目题词页。
- **领取次数** — 用户可成功领取稿件的剩余配额 = 免费剩余 + 已购剩余。
- **免费次数** — 平台在右豹后台配置的免费领取额度。
- **次数商品** — 运营在右豹后台配置的「x 次需要 y 积分」档位，同时最多 4 个；可改价、下架；列表出示只读购买人数（该档去重购买用户数）。
- **回填** — 领取成功后，在该项目已有回填页补上的作品信息。
- **占用** — 领取成功后、回填完成或超时释放前，该稿件只属于当前领取人；对他人 feed 隐藏。
- **释放** — 领取成功后 24 小时未完成回填，占用解除，稿件重新出现在 feed；原领取人与他人均可再领（再领再扣次）；已扣次数不退。
- **未回填** — 领取成功后满 24 小时仍未完成该项目回填页；记 1 次，终身累计。
- **停权** — 终身未回填超过 3 次（第 4 次超时，`strikes > 3`）后，用户失去继续领取稿件的权限。前 3 次超时仍可再领。
- **黑名单** — 后台停权用户记录表；仅运营可手动恢复。
- **分成快照** — 领取成功时写入该领取的剪辑手 ID 与当时分成比例。结算与已结算统计只读快照，不读剪辑手当前比例。
- **分成比例** — 剪辑手录入必填；稿件详情必展示（如 50%）。广场与领取列表禁止展示收益金额。
- **剪辑手收益** — 其稿被领取后，领取所用关键词产生的平台订单收益 × 该领取的分成快照。已结算 / 待结算沿用平台关键词订单已有结算态。不另建收益账本。
- **代发关键词** — 该 `keywordId` 存在至少一条已回填绑定 `(keywordId, claimId)`。未回填 / 已超时不构成绑定。一词多条已回填时，分账取 `filledAt` 最近的那条。
- **用户收益入账** — 关键词订单转为已结算时写入既有项目收益明细。代发则按该 claim 分成快照拆用户实结 + 剪辑手分账；非代发全额给用户。状态固定「已结算」，必须带秒级时间戳与金额。先结算后回填不回溯已落账。
- **代发作品分账** — 四舍五入（应结算 × 该 claim 分成快照），记到剪辑手项目收益明细。用户实结 = 应结算 − 代发作品分账。
- **项目状态** — 项目管理的启用 / 禁用。禁用项目不可上传，也不出现在作品广场。
- **品牌项目** — 平台已有的品牌项目主数据。一键代发「项目管理」新增从该库拉取全部项（已加入的仍列出），带出名称与 Logo；已添加则保存拦截。不在本页手填新建。
- **稿件信息** — 后台稿件表聚合：文件大小 + 括号数量（图集=张数，视频=1）+ 下载链接（仅后台出链接）。
- **剪辑手信息** — 后台领取记录聚合：右豹 ID + 剪辑手名称。
- **书籍信息** — 后台领取记录与稿件表：书籍名称 + 书籍 ID。PC 最近上传另含书籍链接。
- **剪辑手统计** — 剪辑手管理列表：稿件数据（已上传数、已被领取数）与收益数据（已结算、待结算，口径见剪辑手收益）。收益可开抽屉按日 / 按月表看。
