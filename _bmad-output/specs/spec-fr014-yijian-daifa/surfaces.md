# 一键代发 · 必做界面

下游 Demo / UX 不可把下表「必做」行推迟到后续版本。

## 用户侧（C 端）

| 页面 | 必做 | 必须具备 |
|------|------|----------|
| 作品广场 | 是 | 宫格；项目图标横滑直选；搜索框在项目下方；下拉筛剪辑师 / 素材类型 / 稿件类型。封面是本地图片，题材含小说 / 漫画 / 视频。下方 Banner 可配 0–5 条：≥2 自动轮播（指示点+循环），1 条静止，0 条隐藏；点招募帧进海报详情。只列平台已通过且未被占用的稿件。不展示收益金额。底栏切到我的领取。 |
| 稿件详情 | 是 | 素材区铺满：图集出示张数，视频可试看 5 秒。标题下方展示标签。字段：项目名称、书籍名称、书籍 ID、剪辑师、上传时间、分成比例。内容底部、底栏按钮上方展示注意事项。未领取展示领取步骤。领取后改为「作品发布技巧」（发布标题 / 发布描述，均可复制）。未领取底栏：剩余次数、快捷提词、领取。领取后底栏：添加水印、下载稿件。不展示收益金额。 |
| 添加水印 | 是 | 底部坞按四组功能最高高度锁死，预览吃剩余空间。文本输入框可点出键盘。字体 / 字色 / 背景 / 水印在底部浮层横向 Tab 切换；四组内容叠在同一高度，切 Tab 浮层不跳动。字色/背景的颜色与透明度上下分行，选项换行露出不全挤一行。字体字色背景复用通用剪辑预设。字号 0–10。水印设置：全部应用、每2张打1张、每3张打1张、每5张打1张、每2张打10张。水印文字可在图上拖动定位。下载水印稿件先「正在打水印」再「正在下载」；图集出示张数进度，视频出示百分比进度条。 |
| 用户领取页 | 是 | 底栏与广场切换。项目图标只展示有领取记录的项目。胶囊 Tab：未回填 / 已回填 / 已超时。卡片一整块：标题=关键词；信息=封面、作品标题、项目名称、稿件作者、领取时间、下载时间、7 天下载倒计时（超时不可再下）。操作：下载/复制链接为次级；立即回填始终高亮，按状态提示。点信息区（不含灰底三按钮）进该 mid 详情，底栏为已领取。「立即回填」仍只去回填页。不展示收益金额。 |
| 领取校验 | 是（详情浮层） | 先校验剩余次数（按钮旁可见），次数不足走购次；足够后浮层选该项目已通过关键词，不进下级页。确认后 loading：正在下载稿件 → 正在保存到相册 → 已保存到相册。占用中第二人领取失败。 |
| 积分购次 | 是（详情浮层） | 次数不足时浮层选档，按钮为「兑换」。展示在售次数商品（x 次 / y 积分），同时最多 4 档；下架不可兑。 |
| 项目回填页 | 是（复用） | 领取后调整对应项目已有回填页，不新造字段。 |

## 剪辑手侧（PC · 已有创作者中心增量）

| 页面 | 必做 | 必须具备 |
|------|------|----------|
| 剪辑供稿 | 是 | 已有 PC 创作者中心的单一菜单。顶部招募 BN，下方看板。点 BN 侧栏抽屉展开卖点 / 适合谁 / 客服二维码。无站内申请表。C 端不承载此页。 |
| 非剪辑手缺省 | 是 | 未进剪辑手管理（或已停用）时看板走缺省，招募 BN 仍在；不能上传。 |
| 剪辑手看板 | 是 | 仅已录入可见数据：已授权项目、上传的稿件、已被领取的稿件、已经产生的收益。最近上传出示书籍 ID、稿件信息（大小 + 稿件名称）。 |
| 上传入口 | 是 | 上传弹窗三步：选文件夹或压缩包 → 填齐后台同款字段（标题、项目、书名、书籍 ID、大小、稿件名称、发布标题/描述、图集或视频、素材类型；剪辑手=当前登录人）→ 提交平台审核。只列「授权 ∩ 启用」项目。 |
| 上传 list | 是 | 与后台稿件表同字段，不展示下载链接。出示占用态与平台审核（审核中 / 已通过 / 已驳回，驳回出示原因）。剪辑手仅可删除未占用稿件。 |

## 管理后台（右豹后台）

| 页面 | 必做 | 必须具备 |
|------|------|----------|
| 剪辑手管理 | 是 | 录入/维护剪辑手；必录右豹 ID、分成比例、备注；未录入者不能上传发布。 |
| 稿件管理 | 是 | 项目与书分列；书聚合书籍名称+书籍 ID；稿件信息聚合文件大小+下载链接；发布技巧聚合作品标题+作品描述；平台审核（审核中 / 已通过 / 已驳回，驳回出示原因）。审核中可「通过 / 驳回」，驳回原因必填。运营录入默认已通过；PC 新稿默认审核中。 |
| 领取记录 | 是 | 领取记录 + 回填信息；能看出占用中 / 已回填 / 24h 超时释放。「详情」看回填；「稿件详情」抽屉出示稿件字段。 |
| 黑名单 | 是 | 停权用户记录；支持手动恢复。 |
| 项目管理 | 是 | 支持添加/编辑。字段：项目名称、Logo 信息、状态（启用/禁用）、排序、更新时间。禁用项目不可上传、不进广场。 |
| 素材类型 | 是 | 维护上传与 feed 筛选用的素材类型。 |
| 次数商品 | 是 | 运营配置「x 次 / y 积分」，最多 4 档在售；改价、下架。免费次数挂本页。 |
| 广场 Banner | 否（复用） | 复用平台已有 Banner 能力；本 FR 后台不单独配置。C 端广场仍可展示已实现的 0–5 条轮播。 |
