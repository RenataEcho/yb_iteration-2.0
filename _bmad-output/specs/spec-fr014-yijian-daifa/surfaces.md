# 一键代发 · 必做界面

下游 Demo / UX 不可把下表「必做」行推迟到后续版本。WHAT 以 `requirements.md` 为准；本表只锁页面与落点，不复述规则全文。

## 用户侧（C 端）

| 页面 | 必做 | FR | 必须具备 |
|------|------|----|----------|
| 作品广场 | 是 | FR-014-08 | 宫格；项目图标横滑直选；搜索在项目下；下拉筛剪辑师 / 素材 / 稿件类型。封面是图。Banner 0–5 条，点招募帧进海报。只列 plazaEligible。不展示金额。底栏切我的领取。 |
| 招募海报 | 是 | FR-014-01 | 卖点 / 适合谁 / 客服二维码。无申请表、无上传。 |
| 稿件详情 | 是 | FR-014-09, FR-014-10, FR-014-11, FR-014-12 | 素材铺满；图集预览≤3；视频试看 5 秒。七字段 + 分成比例 + 注意事项。领取前后换区。已领中部=#pubTips 出示「发布技巧」字段 + 一段只读可复制。底栏未领=次数/提词/领取，已领=水印/下载。 |
| 添加水印 | 是 | FR-014-18 | 底部坞四 Tab 锁高；字体字色背景复用通用剪辑预设；下载先打水印再下载。 |
| 用户领取页 | 是 | FR-014-14, FR-014-19 | 有记录项目图标；胶囊三态；卡片字段含 7 天下载倒计时；已超时且稿被他人新领则不可下；立即回填始终高亮。 |
| 领取校验 | 是（详情浮层） | FR-014-11 | 停权 → 次数 → 选词 → 资格 / 占用。必须先选词。词带书籍 ID 则须与稿件一致。 |
| 积分购次 | 是（详情浮层） | FR-014-13 | 次数不足时浮层选档，「兑换」；最多 4 档。 |
| 项目回填页 | 是（复用） | FR-014-15 | 领取后接该项目已有回填页，不新造字段。 |
| 项目收益明细 | 是（复用） | FR-014-27 | 不新开页。代发已结算时写用户侧与剪辑手侧各一笔。 |

## 剪辑手侧（PC · 已有创作者中心增量）

| 页面 | 必做 | FR | 必须具备 |
|------|------|----|----------|
| 剪辑供稿 | 是 | FR-014-02 | 单一菜单。顶部招募 BN，下方看板。点 BN 侧栏抽屉展开海报。看板与上传清单有「操作说明」，页内展示手册；未录入也可看。C 端不承载此页。 |
| 非剪辑手缺省 | 是 | FR-014-02 | 未录入或已停用时看板缺省，不能上传；BN 仍在。 |
| 剪辑手看板 | 是 | FR-014-03 | 已授权项目 / 上传数 / 被领数 / 已产生收益。最近上传六列。 |
| 上传入口 | 是 | FR-014-04, FR-014-05 | 先字段后成片；压缩包先解压中；命名约定；确认表每行可编一段；AI 先出示提示词再整表写入；队列三态。 |
| 上传 list | 是 | FR-014-07 | 与后台稿件表同字段，无下载链接。仅空闲可删。 |
