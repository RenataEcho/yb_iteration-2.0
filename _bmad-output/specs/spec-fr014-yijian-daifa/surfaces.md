# 一键代发 · 必做界面

下游 Demo / UX 不可把下表「必做」行推迟到后续版本。

## 用户侧（C 端）

| 页面 | 必做 | 必须具备 |
|------|------|----------|
| 作品广场 | 是 | 宫格；项目图标横滑直选；搜索框在项目下方；下拉筛剪辑师 / 素材类型 / 稿件类型。封面是本地图片，题材含小说 / 漫画 / 视频。下方 Banner 可配 0–5 条：≥2 自动轮播（指示点+循环），1 条静止，0 条隐藏；点招募帧进海报详情。只列未被占用的稿件。不展示收益金额。底栏切到我的领取。 |
| 稿件详情 | 是 | 素材区铺满：图集出示张数，视频可试看 5 秒。字段：项目名称、书籍名称、标签、剪辑师、上传时间、分成比例。领取步骤提示。未领取底栏：剩余次数、快捷提词（跳转该项目题词页提示）、领取。领取后底栏：复制标题、编辑稿件。不展示收益金额。 |
| 用户领取页 | 是 | 底栏与广场切换。项目图标只展示有领取记录的项目。胶囊 Tab：未回填 / 已回填 / 已超时。卡片一整块：标题=关键词；信息=封面、作品标题、项目名称、稿件作者、领取时间、下载时间、7 天下载倒计时（超时不可再下）。操作：下载/复制链接为次级；立即回填始终高亮，按状态提示。点信息区（不含灰底三按钮）进该 mid 详情，底栏为已领取。「立即回填」仍只去回填页。不展示收益金额。 |
| 领取校验 | 是（详情浮层） | 先校验剩余次数（按钮旁可见），次数不足走购次；足够后浮层选该项目已通过关键词，不进下级页。确认后 loading：正在下载稿件 → 正在保存到相册 → 已保存到相册。占用中第二人领取失败。 |
| 积分购次 | 是（详情浮层） | 次数不足时浮层选档，按钮为「兑换」。展示在售次数商品（x 次 / y 积分），同时最多 4 档；下架不可兑。 |
| 项目回填页 | 是（复用） | 领取后调整对应项目已有回填页，不新造字段。 |

## 剪辑手侧

| 页面 | 必做 | 必须具备 |
|------|------|----------|
| 招募海报 | 是 | 招募氛围：卖点 / 适合谁 / 底部客服二维码。无站内申请表、无自助审核。 |
| 选项目并上传发布 | 是 | 已录入剪辑手可选项目；上传图集或视频；必须选择素材类型；发布到平台。 |

## 管理后台（右豹后台）

| 页面 | 必做 | 必须具备 |
|------|------|----------|
| 剪辑手管理 | 是 | 录入/维护剪辑手；未录入者不能上传发布。 |
| 稿件管理 | 是 | 查看/管理已发布稿件。 |
| 领取记录 | 是 | 领取记录 + 回填信息；能看出占用中 / 已回填 / 24h 超时释放。「详情」看回填；「稿件详情」抽屉出示稿件字段。 |
| 黑名单 | 是 | 停权用户记录；支持手动恢复。 |
| 项目管理 | 是 | 本模块项目侧配置（字段未锁）。 |
| 素材类型 | 是 | 维护上传与 feed 筛选用的素材类型。 |
| 次数商品 | 是 | 运营配置「x 次 / y 积分」，最多 4 档在售；改价、下架。免费次数可配置（挂哪级菜单未锁）。 |
| 广场 Banner | 是 | 可配 0–5 条；已满 5 条再新增须拦截并提示最多 5 条。 |
