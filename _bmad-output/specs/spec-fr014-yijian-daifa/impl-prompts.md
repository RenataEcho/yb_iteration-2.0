# 一键代发 · 开发提示词

技术开工包。WHAT 只以 `requirements.md` 为准。本文件把各端 / 接口提示词钉在对应「业务流程」节点上，禁止另开第三套规则。

Demo 可复制面：`fr-opc-yijian-daifa.html` 各端子 Tab「开发提示词」。节点名必须与该端 SVG 一致；合同与图冲突时以 FR 为准，并在步骤里标明。

## 用法

把对应切片整段复制给实现者（人或 AI）。一次只实现一个切片。改节点必须同步改本文件与 Demo 渲染源 `demo/iteration/yijian-daifa-impl-prompts.js`。

开工包（一次一刀；禁止把合同扩成实现手册）：

- 模板：`_bmad-output/specs/dev-prompt-template.md`
- 样例：`_bmad-output/specs/spec-fr014-yijian-daifa/stories/STORY-014-C3-claim-gates.md`（C3 = 领取门禁 + 兑换）
- C1：`_bmad-output/specs/spec-fr014-yijian-daifa/stories/STORY-014-C1-plaza-detail.md`（广场宫格 + 详情铺陈）
- Demo C 端「开发提示词」只渲染当前刀（C1 两节点），不展示整端节点表。
- 后续每刀按模板另开 `stories/STORY-….md`，不要把 Code Map / Tasks 写回本文件。

## 切片

| ID | 端 / 接口 | 节点来源 |
|----|-----------|----------|
| `c` | C 端 | 前端交互 → 业务流程 |

每份提示词固定六段：范围、非目标、依赖、按节点执行、跨端副作用、验收。

## 共享技术约束

- Demo store key=`fr014-yjd-v6`，函数在 `yijian-daifa-store.js` 的 `YJD.*`。联调不要把 localStorage 当接口。
- 拟 HTTP 以「前后端数据交互 → 接口契约」为准。写操作必须带幂等键；失败整单回滚。
- 广场资格只认 `YJD.plazaEligible`：非站外 + 已上传 + 已通过 + 空闲 + 稿件正常 + 项目启用 + 剪辑手已录入且开通右豹 + 素材启用。
- 领取门禁顺序不可颠倒：停权 → 次数 → 选词 → 资格/占用。页内 C 端 SVG 未画「停权」菱形，实现仍必须先判停权。
- 24h 超时只由后端任务写，前端倒计时不准自己释放。
- 列表响应不得带金额。分成只出比例。
- 不改 FR-001 / FR-002 / FR-012 / FR-013。

## C 端

**范围：** 作品广场、海报、详情、预览、领取门禁、兑换、我的领取、回填入口、图集水印、下载并发布到抖音。  
**非目标：** 上传、后台 CRUD、站外落地、入账拆账、真扣积分。  
**依赖：** `GET /api/yjd/feed|projects|works/:id|works/:id/preview|projects/:id/keywords`；`POST /api/yjd/claims`；`POST /api/yjd/skus/:id/redeem`；`POST /api/yjd/claims/:id/fill`；`GET /api/yjd/claims/:id/file`。读 `user.banned/free/bought/strikes`，`YJD.downloadBlockReason`。

|---|---|---|---|---|---|

| 详情铺满素材 · 发起领取 | 未领/已领换区 | 无 | — | 预览 `GET .../preview` 最多 3 张，不扣次；视频试看 5 秒 | 09, 10 |
| 剩余次数>0? | `free+bought>0`（先 `applyFreeDay`） | — | 积分买在售档 | 不足只开兑换，不打开选词 | 11, 13 |

| 领取成功 · 扣次不退 | 同一 `claimId` 原子 | `occ=占用中`；扣 free 后 bought；claim=未回填；分成快照；`expireAt=+3d`；首次领取写 `ossExpireAt=+7d` | 整单回滚 | `POST /claims` + idempotencyKey；loading 三态不拉抖音 | 12, 19, 32 |
| 24h 内已回填? | 任务或回填回调 | 是：`claim=已回填`，`occ=已完成`，写 `filledAt` | 否 → 记 1 次未回填 + 释放 | 回填 `POST /claims/:id/fill`，不得改项目/书/词；已回填/已超时拒绝 | 15, 16 |
| 记 1 次未回填 + 释放 | 满 24h 且未回填 | `claim=已超时`；`occ=空闲`；`strikes+1` 幂等 | — | `POST /claims/:id/timeout`；不退次 | 16 |
| 终身未回填>3? | `strikes>3` | 写黑名单停权中 | 可再领 | 前 3 次超时仍可再领 | 17 |
| 原领取人与他人均可再领 | 未停权 | 新 claim、再扣次、再选词、新快照 | 停权阻断 | 已完成稿永不回广场 | 16 |
| 添加水印 / 下载抖音 | `downloadBlockReason==''` | 先过 3 天窗再保存；成功后 `#dySheet`，禁止 `location.href` | toast，不打开相册 | 仅图集进水印；视频 toast「视频稿件暂不支持添加水印」 | 18, 19, 28 |

## 接口

后端切片。节点来自「用户收益入账」与「阿里云存储」两张图，加上领取占用任务。

### 领取 / 占用 / 超时

`POST /api/yjd/claims`：门禁五段（停权、次数、词、资格、占用）在同一事务重跑；通过后原子写占用+扣次+未回填+快照+OSS 钟。  
`POST /api/yjd/claims/:id/timeout`：满 24h 幂等：`strikes+1`、释放、`strikes>3` 写黑名单。  
`POST /api/yjd/claims/:id/fill`：仅 `未回填`；提交后 `已完成`，不入账。

### 用户收益入账（图：ix-payout-flow）

| 节点 | 判定 | 写 | 失败 |
|---|---|---|---|
| 用户回填完成 | claim=已回填 | 不入账 | — |
| 关键词出单 | 待结算 | 只累计 | 不写明细 |
| 订单已结算? | 否 | — | 待结算不入账 |
| 结算回调 apply | 同一 `orderId+keywordId` 幂等 | — | 已落账不回溯 |
| 代发关键词? | 存在已回填 `(keywordId,claimId)`；多条取 `filledAt` 最近 | 否：全额用户入账，不写剪辑手 | 未回填/已超时不是代发 |
| 按分成拆账 | `editorShare=round(gross×快照)`；`userNet=gross−share`；两边之和=gross | 不读当前分成 | — |
| 原子写入成功? | 双方明细同一秒 | 状态=已结算 | 整笔回滚，回到 apply |
| 双方项目收益明细 | 标题/描述模板见 FR-014-27 | 复用既有明细，不改 FR-002 | — |

`POST /api/yjd/settlements/apply` `{keywordId,orderId,settledAt,amount}`。

### 阿里云存储

**站内：** 上传入桶 → 已有首次领取? 否则未领满 15 天删且不可恢复 → 是则签发 3/7 → C端 3 天内? 是则 `GET /claims/:id/file` 签链 → 否则系统满 7 天? 是则删不可恢复 → 否则已恢复过一次? 是则不可再恢复 → 后台恢复重计 `min(now+3d, ossExpireAt)`，不重置系统钟。主动删除即时清桶，不可恢复。  
**站外：** 文件夹入桶 → H5 点下载 → 领一个删一个 → 该素材云端已删除 → 虚线回下一份。不走 3/7，不能 restore-dl。

`PUT /api/yjd/oss/works/:id` · `POST /api/yjd/oss/purge` · `POST /api/yjd/admin/works/:id/restore-dl`。

**验收：** FR-014-11、12、16、17、27、32；同一结算不得落两笔；OSS 两条链互不汇合。
