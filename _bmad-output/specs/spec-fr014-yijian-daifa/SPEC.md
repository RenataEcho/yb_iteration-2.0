# 一键代发（FR-014）

完整且唯一的功能需求见 `requirements.md`（FR-014-01 … FR-014-32）。下列 CAP 是稳定聚合门，不另写一套平行条款。

## Why

**痛点 + 机会。** 没有剪辑制作能力的用户想靠项目变现，但做不出内容就进不了项目。平台招募剪辑手（客服接入）生产图集、视频并发布到站内，用户领取后再走该项目回填页，发布并靠关键词收益变现。本增量把「供稿 → 发现 → 独占领用 → 24h 回填或释放 → 停权/恢复 → 代发入账」做成可验收闭环。

## Capabilities

- **CAP-1**
  - **intent:** 有制作能力的人经海报联系客服，后台录入后才能在已有 PC 创作者中心上传；C 端只看海报，不做上传。
  - **success:** FR-014-01、FR-014-02 同时成立。

- **CAP-2**
  - **intent:** 已录入剪辑手为授权且启用的项目批量上传图集或视频；右豹提交后进入平台审核，通过且空闲才进广场；站外走独立 Tab，免审且不进广场。
  - **success:** FR-014-03 … FR-014-07 同时成立。站外 Tab 细则验 CAP-13。

- **CAP-3**
  - **intent:** 用户按项目、剪辑师、素材、稿件类型浏览可领取稿件。
  - **success:** FR-014-08 成立。

- **CAP-4**
  - **intent:** 用户在稿件详情看到决定是否领取所需的信息，并可预览素材。
  - **success:** FR-014-09、FR-014-10 同时成立。

- **CAP-5**
  - **intent:** 用户领取前必须过停权、次数、选词、占用四道门；成功后占用并扣次。
  - **success:** FR-014-11、FR-014-12 同时成立。

- **CAP-6**
  - **intent:** 平台可按工作日 / 节假日配置免费领取次数；用户可用积分兑换「x 次 / y 积分」档位（同时最多 4 档）；原价 &gt; 现价时兑换浮层出示划线价。
  - **success:** FR-014-13、FR-014-26 同时成立。次数产品规则只在此验收，CAP-9 不再复验。

- **CAP-7**
  - **intent:** 用户必须在 24 小时内回填；终身未回填超过 3 次（第 4 次超时）则停权，仅后台可恢复。
  - **success:** FR-014-15、FR-014-17 同时成立。

- **CAP-8**
  - **intent:** 用户有独立页查看已领取稿件，并按 FR-014-19 的 3 天窗下载或跳转该项目回填页；官方下载成功后拉起抖音相册。稿件资源在阿里云 OSS，系统 7 天内可后台恢复一次。
  - **success:** FR-014-14、FR-014-19、FR-014-28、FR-014-32 同时成立。

- **CAP-9**
  - **intent:** 运营在右豹后台管理剪辑手（含发布平台）、稿件（右豹/站外 Tab）、领取、黑名单、项目、素材；次数商品页只作配置落点。
  - **success:** FR-014-20 … FR-014-25 与 `surfaces.md` 后台七页齐备。次数商品规则只验 CAP-6。广场 Banner 复用已有能力，不单开配置页。站外细则验 CAP-13。

- **CAP-10**
  - **intent:** 一份稿件同一时刻只被一人占用；超时释放且不退次；释放后可再领。
  - **success:** FR-014-16 成立。

- **CAP-11**
  - **intent:** 关键词订单已结算入账时必须先判定该词是否为代发，代发则按分成拆到用户侧与剪辑手侧。
  - **success:** FR-014-27 成立。

- **CAP-12**
  - **intent:** 已领取用户可以在一屏内给图集成片加水印再下载；视频稿 toast 阻断。
  - **success:** FR-014-18 成立。

- **CAP-13**
  - **intent:** 剪辑手可开通站外发布；站外稿不进右豹广场，经链接或二维码给站外用户无登录下载；文件夹内领一个删一个 OSS。
  - **success:** FR-014-29、FR-014-30、FR-014-31 同时成立。站外删对象细则与 FR-014-32 对齐。

## Constraints

- 领取门禁顺序不可颠倒：停权 → 次数 → 选词 → 资格/占用。次数不足不得打开选词浮层。必须先选词；无默认带入。
- 同一时刻一份稿件只能被 1 人占用；24 小时未回填必须释放，不得无限锁死；已扣次数不退。
- 次数商品同时在售最多 4 个。未回填按终身累计，超过 3 次（第 4 次超时，`strikes > 3`）即停权，恢复只能后台手动。
- 分成以领取成功时写入的快照为准，结算不读剪辑手当前比例。
- 代发绑定主键为 `(keywordId, claimId)` 且已回填；一词多条取最近回填。已超时记录失去官方下载权，卡片出示「回填已超时」，不再因他人新领改文案。
- 项目新增必须从现有品牌项目带出名称+Logo，不得本页手填新建；已添加则拦截。项目管理不得维护已通过关键词。
- 独立 FR-014：不改 FR-001、FR-002、FR-012、FR-013 已有文件。边界见 `brownfield.md`。
- 交付按 `ITERATION-FR-GUIDE.md`：顶层 Tab = 业务解释 / 前端交互 / H5端 / PC端 / 管理后台 / 前后端数据交互；前端/PC 为「场景 | 业务流程 | 开发提示词」，后台七菜单各为「列表 | 业务流程 | 开发提示词」。开发提示词按节点闭环，见 `impl-prompts.md`。本 FR Demo 用 localStorage 闭环，不做真实接口。
- PC 看板已授权项目只出统计+弹窗，不得再加中间项目栏。看板收益数据只含右豹端稿，不改已有收益中心。
- 站外 H5 点下载必须立即扣 1 个素材余量并删除该份 OSS 副本（领一个删一个）。下载链路不判定整夹是否领完。已领完扫码进入只能看出缺省态，不得再给下载按钮。
- 所有稿件资源上阿里云 OSS。站内已领取：C 端下载 3 天、系统对象 7 天、每稿仅可恢复一次；满 7 天删对象后不可恢复。站内一直未领取：从上传起只留 15 天。后台或剪辑手主动删除：阿里云同步删除，不支持恢复。站外文件夹内领一个删一个，未领整夹满 15 天同样删。

## Non-goals

- 不把本需求并入或改造 FR-001 代发分配、FR-002 代发收益。
- 不覆盖用户自制剪辑上传；本增量只领取剪辑手已发布稿件。
- 不做站内剪辑手申请表单或自助审批流。
- 不在本 FR 重定义现有申词审核状态机，也不新造一套回填字段。
- Demo 不做真实积分扣减、支付或权限落库。

## Success signal

FR-014-01 … FR-014-32 在 FR-014 Demo 上按 `flows.md` 点通，且 e2e `tests/e2e/test_yijian_daifa.py` 全绿，即视为达标。

## Assumptions

- 原文「改项目」=「该项目」；「全音」=「权限」。
- 领取页是用户侧「我的领取」，不是剪辑手工作台。
- 「选择剪辑师」筛的是稿件的上传剪辑手。
- 领取词 = 用户自主申请且状态为审核通过待发布或审核通过已回填的词；C 端拉取现有申词，本 FR 不另建词库。
- 书籍信息口径：书籍名称 + 书籍 ID。稿件数量：图集 = 张数，视频 = 1。
- 购买人数 = 该档去重购买用户数，只读。
- 回填视频链接 = 现有回填页已有字段，本 FR 不新造。
- 已结算 / 待结算 = 平台关键词订单已有结算态。剪辑手分账 = 订单收益 × 分成；用户实结 = 订单收益 − 剪辑手分账。
- 代发关键词 = 该 `keywordId` 存在至少一条已回填绑定 `(keywordId, claimId)`；一词多条取 `filledAt` 最近。
- 「超过 3 次」= 第 4 次未回填（`strikes > 3`）。
- 分成快照 = 领取成功时的剪辑手 ID + 分成比例；后续改比例不回溯。
- 已添加 = 该品牌项目已出现在一键代发项目表。
- PC 收益自定义范围 = 结算日起止闭区间；空=全部已结算。明细导出为 CSV。
- 「excel 格式」= 上传弹窗内表格确认，不是另下 .xlsx。
- 「解压中」是选压缩包后的处理态，不是 list 上传三态。
- 确认后 loading 三态（下载 → 保存相册 → 已保存）是领取成功的展示，不是下载保存业务状态机；真正 C 端下载窗是领取后 3 天；未领取对象从上传起留 15 天。
