# 一键代发（FR-014）

## Why

**痛点 + 机会。** 没有剪辑制作能力的用户想靠项目变现，但做不出内容就进不了项目。平台招募剪辑手（客服接入）生产图集、视频并发布到站内，用户领取后再走该项目回填页，发布并靠关键词收益变现。本增量把「供稿 → 发现 → 独占领用 → 24h 回填或释放 → 停权/恢复」做成可验收闭环。

## Capabilities

- **CAP-1**
  - **intent:** 有制作能力的人在已有 PC 创作者中心看到招募海报（客服二维码），联系客服成为剪辑手；后台录入后才能用电脑上传。C 端广场可点招募帧进海报，但不做上传或工作台。
  - **success:** PC「剪辑供稿」为单一菜单：顶部招募 BN，下方看板。点 BN 侧栏抽屉展开海报详情（客服二维码）；无站内申请表。未录入时看板走缺省且不能上传；已录入可看看板并选授权项目 → 弹窗上传 → 提交平台审核。

- **CAP-2**
  - **intent:** 已录入的剪辑手在已有 PC 业务线为授权且启用的项目上传图集或视频（必须选择素材类型），并发布到平台供 C 端用户领取。
  - **success:** 已录入剪辑手用上传弹窗：必须选文件夹或压缩包，填齐后台同款字段后提交。PC 新稿默认审核中，不进广场；后台通过后空闲稿出现在用户可见作品广场，带上传时所选素材类型，且详情七字段可展示。已驳回在 PC list 出示原因。运营在后台「录入稿件」视为已审，默认已通过（空闲即进广场）。PC 看板出示已授权项目、上传的稿件、已被领取的稿件、已经产生的收益（仅已回填完成稿件上已记收益）。最近上传出示书籍 ID 与稿件信息（大小 + 稿件名称）。上传 list 与后台稿件表同字段但不展示下载链接；剪辑手仅可删除未占用（空闲）稿件。

- **CAP-3**
  - **intent:** 用户可以浏览可领取稿件，并按项目、剪辑师、素材类型、稿件类型筛选。
  - **success:** 作品广场用宫格展示平台已通过且未被占用的稿件；只列启用项目。审核中与已驳回不进广场。项目图标横滑直选；搜索框在项目下方；剪辑师 / 素材类型 / 稿件类型为下拉；封面是本地图片且题材含小说 / 漫画 / 视频。广场 Banner 复用平台已有能力（C 端已实现 0–5 条轮播）；点招募帧进海报详情。占用中的稿件对他人隐藏。广场不展示任何收益金额。

- **CAP-4**
  - **intent:** 用户在稿件详情看到决定是否领取所需的信息，并可以发起领取。
  - **success:** 详情素材区铺满；图集显示张数，视频可试看 5 秒。标题下方展示标签。同时具备项目名称、书籍名称、书籍 ID、剪辑师、上传时间、分成比例。内容底部、底栏按钮上方展示注意事项。未领取时展示领取步骤。领取后该区域改为「作品发布技巧」：短视频推荐发布标题、发布描述，均可复制。未领取底栏：剩余次数、快捷提词（提示跳转该项目题词页）、领取。领取后底栏改为添加水印、下载稿件。不展示收益金额。

- **CAP-5**
  - **intent:** 用户领取前必须选定该项目已通过的关键关键词，并且剩余领取次数足够。
  - **success:** 领取先校验剩余次数（详情按钮旁可见），次数不足进入 CAP-6；次数足够后用浮层选择该项目已通过关键词，不进入下级页。未选词、次数不足、或稿件已被占用时领取失败。确认选词后依次展示：正在下载稿件 → 正在保存到相册 → 已保存到相册。占用见 CAP-10。

- **CAP-6**
  - **intent:** 平台可配置免费领取次数；用户也可用积分购买「x 次需要 y 积分」商品（同时最多 4 档）。运营在右豹后台改价或下架。
  - **success:** 剩余次数 = 免费剩余 + 已购剩余。次数不足时在详情用浮层选档并「兑换」，不进下级页。兑换成功后已购次数按该档增加。前台同时展示的在售商品不超过 4 个；下架商品不可新购。

- **CAP-7**
  - **intent:** 领取成功后用户必须在 24 小时内于该项目已有回填页补作品信息；超时记 1 次未回填。终身未回填超过 3 次则失去领取权限，仅后台可手动恢复。
  - **success:** 领取成功后满 24 小时仍未回填，记原领取人 1 次未回填并触发 CAP-10 释放。终身未回填次数 > 3 进入黑名单且无法再领；运营可手动恢复。回填打开对应项目的回填页，不另造字段。

- **CAP-8**
  - **intent:** 用户有独立页面查看自己已领取的稿件，并跳转到该项目回填页完成回填。
  - **success:** 底部导航在「作品广场 / 我的领取」间切换。领取页只展示「有领取记录」的项目图标。状态用胶囊 Tab 区分：未回填 / 已回填 / 已超时。卡片是一整块：标题为关键词；信息为封面、作品标题、项目名称、稿件作者、领取时间、下载时间、7 天下载倒计时。领取后 7 天内可下载，超时未下载则不可再下。灰底操作：下载、复制链接为次级；立即回填始终高亮，已回填/已超时点击提示不可回填。点卡片信息区（封面/标题，不含灰底三按钮）进入该 mid 稿件详情，底栏为已领取。「立即回填」仍只去回填页。不展示收益金额。占用中的稿件仍出现在领取人自己的领取页，不出现在他人广场。

- **CAP-9**
  - **intent:** 运营在右豹后台管理剪辑手、稿件、领取/回填、停权黑名单、项目、素材类型，并配置次数商品与免费次数。
  - **success:** 必做页齐备（见 `surfaces.md`）。剪辑手必录右豹 ID / 分成比例 / 备注。稿件项目与书分列，书聚合名称+ID，并出示稿件信息（大小+下载链接）、发布技巧（作品标题+描述）与平台审核（审核中 / 已通过 / 已驳回，驳回出示原因）。PC 新上传默认审核中；后台「录入稿件」视为运营已审，默认已通过。后台可对审核中稿件通过或驳回（驳回原因必填）；已通过不可再驳回。项目可添加/编辑（名称 / Logo / 启用禁用 / 排序 / 更新时间）；禁用项目不可上传、不进广场。广场 Banner 复用平台已有能力，本 FR 不单开配置页。次数商品可改价/下架；免费次数挂次数商品页；黑名单可手动恢复；领取记录可开稿件详情抽屉。剪辑手 / 稿件 / 项目 / 素材 / 次数均可增删改，删除受占用与引用约束。回填完成的稿件记为已完成，不再回广场。

- **CAP-10**
  - **intent:** 一份稿件同一时刻只被一人占用；占用期间对他人隐藏；占用方 24 小时未回填则释放并重新出现在 feed。已扣次数不退。释放后原领取人与他人均可再领。
  - **success:** 占用期内他人 feed 看不到该稿，领取也失败。满 24 小时未回填后稿件重新出现；他人与原领取人（未进黑名单）均可再领成功，且须再次扣次并过关键词门禁。原领取人该次超时已记入未回填次数，已扣次数不退。

## Constraints

- 领取门禁顺序不可颠倒：先校验剩余次数，再浮层选择该项目已通过的关键关键词，再校验稿件未被占用。次数不足不得打开选词浮层。
- 同一时刻一份稿件只能被 1 人占用；占用中对他人 feed 隐藏。24 小时未回填必须释放并重新可见，不得无限锁死。
- 领取成功即扣次（免费或已购）。超时释放不退回已扣次数。释放后原领取人可再领同一稿，再领再扣次。
- 次数商品形态为「x 次需要 y 积分」，同时在售最多 4 个；运营可改价、下架。
- 「未回填」= 领取成功后 24 小时未完成该项目回填页。按终身累计；超过 3 次即停权。恢复只能后台手动，必须有黑名单记录表。
- 稿件类型至少覆盖图集与视频。上传必须选择素材类型；feed「素材」只筛该字段。
- 无站内剪辑手自助申请或自助审核。
- 回填复用并调整该项目已有回填页，本 FR 不另定义回填字段。
- 独立 FR-014：不改 FR-001、FR-002、FR-012、FR-013 已有文件。边界见 `brownfield.md`。
- 作品广场与用户领取页不可延期；广场为宫格 + 项目图标直选 + 搜索在项目下 + 其余下拉；封面必须是图，禁止纯色块；详情素材铺满、分成比例、领取步骤、次数与快捷提词；任何列表不展示金额。后台七页（剪辑手 / 稿件 / 领取 / 黑名单 / 项目 / 素材 / 次数商品）不可缺。广场 Banner 复用已有能力，本 FR 不单开配置页。清单见 `surfaces.md`。
- 领取后稿件下载仅 7 天有效；超时未下载则不可再下。用户领取页项目筛选只出现有领取记录的项目。
- 领取成功后详情「领取步骤」改为「作品发布技巧」；底栏改为添加水印、下载稿件。水印字体/字色/背景复用通用剪辑预设。
- 交付按 `ITERATION-FR-GUIDE.md`：页内 Tab 为前端交互 / PC端 / 管理后台 / 业务流程 + 规则抽屉；C 端橙色；PC 用桌面框；Mockup 仅 iframe；本 FR Demo 用 localStorage 做 C/PC/后台逻辑闭环，不做真实接口；流程图手写 SVG。
- C 端不做剪辑手上传或工作台；广场招募帧可进海报。剪辑手只走已有 PC 创作者中心。

## Non-goals

- 不把本需求并入或改造 FR-001 代发分配、FR-002 代发收益。
- 不覆盖用户自制剪辑上传；本增量只领取剪辑手已发布稿件。
- 不做站内剪辑手申请表单或自助审批流。
- 不在本 FR 重定义现有申词审核状态机，也不新造一套回填字段。
- Demo 不做真实积分扣减、支付或权限落库。

## Success signal

未录入剪辑手不能在 PC 发稿；已录入者在电脑用文件夹或压缩包上传并填齐字段，提交后进入平台审核，通过后空闲稿才进广场。运营后台录入可直接已通过。C 端只领取；广场招募帧进海报，上传仍只在 PC。用户在作品广场用宫格 + 项目图标直选 + 搜索找到已通过且未被占用的稿件（广场不展示收益金额）、在详情看到分成比例与铺满素材（不展示金额）、先校验次数后点击领取即成功并留在详情；回填从「我的领取」进入。占用中他人广场看不到。24 小时内回填则占用保持；超时记 1 次未回填、不退次数、稿件重新出现；原领取人与他人均可再领（再领再扣次）。终身未回填超过 3 次进入黑名单无法再领，后台可手动恢复。FR-014 Demo 按 `flows.md` 点通即视为达标。

## Assumptions

- 原文「改项目」=「该项目」；「全音」=「权限」。
- 领取页是用户侧「我的领取」，不是剪辑手工作台。
- 「选择剪辑师」筛的是稿件的上传剪辑手。
- 「该项目已通过的关键关键词」复用现有项目申词审核结果，本 FR 不另建词库。
- 「调整对应项目的回填页面」= 复用该项目已有回填表单与字段，本 FR 只接入口、不重列字段。
- 次数商品与免费次数都在右豹后台「次数商品」页配置。
