# 一键代发 · 唯一 FR

本文件是 FR-014 的**完整且唯一**功能需求清单。SPEC 的 CAP 是聚合门；字段落点见 `surfaces.md`；主路径见 `flows.md`。下游只以本表验收 WHAT，不另开平行 FR。

编号稳定：`FR-014-nn`。不复用已删除号。

## A. 剪辑手入驻与 PC 供稿

#### FR-014-01: 招募入口

有制作能力的人通过海报联系客服，由运营录入后成为剪辑手。

**Consequences:**
- PC 顶部招募 BN、C 端广场招募帧都进入同一海报：卖点 / 适合谁 / 客服二维码。
- 无站内申请表、无自助审批、无 C 端上传或工作台。

#### FR-014-02: PC 剪辑供稿菜单

已有 PC 创作者中心增加单一菜单「剪辑供稿」：顶部招募 BN + 下方看板。

**Consequences:**
- 不新造 PC 产品；不改项目中心 / 作品管理 / 收益中心。
- 未录入或已停用：看板缺省，不能上传；招募 BN 仍可打开。
- 已录入：可看看板并进入上传。
- 看板与上传清单提供「操作说明」入口，页内展示剪辑手手册；未录入 / 已停用也可打开。

#### FR-014-03: PC 看板

已录入剪辑手看到授权与业绩摘要。

**Consequences:**
- 出示：已授权项目、上传的稿件数、已被领取的稿件数、已经产生的收益。
- 已授权项目只出统计数字；点击数字弹窗查看授权名单。不在统计与「最近上传」之间再加项目标签栏。
- 收益 = 已回填完成稿上、领取所用关键词的平台订单收益 × 分成；结算态沿用平台关键词订单。
- 「最近上传」左侧增加「收益数据」列表，仅统计 `channel=右豹` 的稿件；站外稿不进本表。默认按日，可切按月或自定义日期范围。列：日期、已结算收益、操作（明细）。
- 收益数据「查看全部」进入下一页完整表。点「明细」开抽屉：日期、稿件ID、书信息、结算收益；支持导出。
- 最近上传列：项目名称、书籍信息（ID / 标题 / 链接）、稿件信息、稿件类型、审核状态、上传时间。

#### FR-014-04: PC 批量上传

已录入剪辑手为授权且启用的项目批量交稿。

**Consequences:**
- 顺序不可颠倒：先填共享字段，再选批量文件夹或压缩包。
- 共享字段：项目（授权 ∩ 启用）、书籍名称、书籍 ID、书籍链接、图集或视频、素材类型；剪辑手只读。不含标题、不含大小。
- 选压缩包必须先「解压中」再解析；文件夹直接解析。
- 命名约定：文件名（去扩展名）= 作品标题；图集一个文件夹为一组，组名即标题。
- 解析一次后表格确认：共 x 条、大小 xxxG；列 = 稿件ID（系统生成）/ 稿件名称 / 稿件大小 / 发布技巧（未识别则空）。
- 「AI生产发布技巧」整表一键：先出示提示词、约束和规则，确认后再写入；取消不写表。确认表每行一段可编。空技巧可入队。

#### FR-014-05: 上传队列

确认后按条队列上传稿件与发布技巧。

**Consequences:**
- list 出示上传中 / 已上传 / 上传失败。
- 失败只重传失败文件，不重传发布技巧。
- 「已上传」= 该条文件 + 发布技巧已提交平台；其后走平台审核三态。

#### FR-014-06: 平台审核落态

已上传稿件进入平台审核，通过且空闲才进广场。

**Consequences:**
- PC 新稿看剪辑手「稿件需要审核」：是 = 审核中，否 = 已通过。改「否」不回溯已有审核中稿。
- 后台「录入稿件」视为运营已审，默认已通过。
- 审核中 / 已驳回不进广场；已驳回必须出示原因；已通过不可再驳回。
- 审核中可单条或批量通过或驳回（驳回原因必填）；批量删除跳过占用中或仍有未超时领取的行。

#### FR-014-07: PC 上传 list

剪辑手查看自己交过的稿。

**Consequences:**
- 顶部分「右豹稿件 / 站外稿件」。未开通对应平台则看不到该 Tab。
- 右豹字段与后台稿件表对齐，不展示下载链接；另列上传状态与稿件状态（正常 / 已删除）。仅可删除未占用且稿件状态=正常的稿件。删除后阿里云同步删除，不可恢复，行保留为已删除。
- 站外以文件夹呈现。列：ID、标题、项目、书、稿件信息（x个素材(已领x个)、大小）、类型、状态、稿件状态、上传、上传时间、操作（删除、分享链接、二维码）。无发布技巧、无素材类型、无审核。已删除不再给出删除/分享。

## B. C 端发现与领取

#### FR-014-08: 作品广场

用户浏览可领取成片。

**Consequences:**
- 宫格；启用项目图标横滑直选；搜索在项目下方；下拉筛剪辑师 / 启用素材 / 图集或视频。
- 封面必须是本地图片，禁止纯色块；题材含小说 / 漫画 / 视频。图集出示张数角标，视频不出张数。
- Banner 复用平台已有 0–5 条能力；≥2 轮播，1 条静止，0 条隐藏；点招募帧进海报。本 FR 不单开 Banner 配置页。
- 只列 `plazaEligible` 为真的稿：已通过 + 空闲 + 稿件状态正常 + 项目启用 + 剪辑手已录入且开通右豹 + 素材启用 + 非站外。缺一即藏。
- 任何列表不展示收益金额、分成或积分。

#### FR-014-09: 稿件详情

用户在同一页看齐决定是否领取所需信息；领取前后换区，不跳下级页。

**Consequences:**
- 素材区铺满。必出：标题、标签、项目名称、书籍名称、书籍 ID、剪辑师、上传时间、分成比例。不展示金额。
- 内容底、底栏上方出示注意事项（24h 发布、超时失效、终身未回填超过 3 次停权）。
- 未领取：中部 = 领取步骤；底栏 = 剩余次数 + 快捷提词 + 领取。
- 已领取：中部 = 「发布技巧」字段名 + 一段正文（`#pubTips` 只读框 + 复制）；底栏 = 添加水印 + 下载并发布到抖音。无「作品发布技巧」分区标题，不拆发布标题 / 发布描述。下载成功后拉起抖音相册，见 FR-014-28。
- 快捷提词只提示跳转该项目题词页，不领取、不扣次。

#### FR-014-10: 图集预览与视频试看

未领取也可预览，但不等于领取。

**Consequences:**
- 图集可点开浮层，最多 3 张，角标仍为真实张数；缺 preview 用封面补齐。
- 预览不扣次、不占用、不下载；禁右键/长按保存；带用户水印；切后台回来模糊。规则写明真机系统截屏禁不掉。
- 视频不进浮层，可试看 5 秒。

#### FR-014-11: 领取门禁

点领取后按固定顺序校验，不可颠倒、不可跳过选词。

**Consequences:**
- 顺序：停权 → 剩余次数 → 浮层选词 → 资格 / 占用。
- 已停权：按钮「已被停权，无法领取」，不打开任何浮层。
- 次数不足：打开兑换浮层，不打开选词，不扣次。
- 次数足够才打开选词浮层。只列该用户在该项目已申请并通过的词（C 端拉取现有申词，不读项目管理）。必须先选词再确认；无默认带入。
- 确认时：若该词带书籍 ID 且与稿件书籍 ID 不一致 → toast「请选择与该稿件书籍一致的已通过关键词」，不扣次。词不带书籍 ID 则只按项目（不重定义 FR-013）。
- 未选词 / 无已通过词：toast「请先选择该项目已通过的关键关键词」，不扣次。
- 资格失败：toast「稿件当前不可领」，不扣次。占用：toast「稿件已被占用」，不扣次。
- 确认瞬间重跑停权、次数、词仍已通过、资格、占用；任一项失败不扣次、不占用。

#### FR-014-12: 领取成功

门禁通过后占用稿件并扣次。

**Consequences:**
- 同一 `claimId` 原子写入：占用中 + 扣次（先免费后已购，不退）+ 领取记录「未回填」+ 分成快照（剪辑手 ID + 当时分成比例）。失败整单回滚。
- 确认后 loading：正在下载稿件 → 正在保存到相册 → 已保存到相册；成功停在详情已领取态。
- 对他人广场隐藏。原领取人超时释放后可再领同一稿，再领再扣次、再选词、再写新快照。

#### FR-014-13: 积分购次

次数不足时在详情浮层兑换，不进下级页。

**Consequences:**
- 剩余次数 = 当日免费剩余 + 已购剩余。当日免费额度按工作日 / 节假日平台配置取。
- 商品形态「x 次需要 y 积分」；档位含原价（积分）。原价 &gt; 现价时兑换浮层出示划线价；原价 ≤ 现价不划线。同时在售最多 4 档；下架不可新兑；已购次数保留。
- 按钮文案「兑换」。Demo 不真扣积分。
- 兑换成功关浮层、刷新剩余次数，不自动打开选词。

#### FR-014-14: 我的领取

用户查看自己的领取记录并进入回填。

**Consequences:**
- 底栏与广场切换。项目图标只展示有领取记录的项目。
- 胶囊：未回填 / 已回填 / 已超时（后台对应 待回填 / 已回填 / 已超时释放）。
- 卡片标题 = 领取关键词。信息 = 封面、作品标题、项目名称、稿件作者、领取时间、下载时间、3 天下载倒计时。
- 下载 / 复制链接为次级；立即回填始终高亮。已回填 / 已超时点立即回填分别 toast「该稿件已回填」「已超时，无法回填」。
- 点信息区（不含灰底三按钮）进该稿已领取详情。「立即回填」只去回填页。
- 不展示收益金额。占用中稿件只出现在领取人自己的领取页。

#### FR-014-15: 回填

领取后 24 小时内在该项目已有回填页补作品信息。

**Consequences:**
- 本 FR 不新造回填字段，复用该项目已有表单。入口带 `claimId`：提交不得改领取时的项目 / 书籍 / 关键词。
- 提交成功：领取 → 已回填；稿件占用 → 已完成；写下 `filledAt`；不再回广场；不退次数。
- 已回填 / 已超时不得再进回填页。

#### FR-014-16: 24 小时占用释放

一份稿件同一时刻只被一人占用；超时必须释放。

**Consequences:**
- 占用中他人广场看不到，领取也失败。
- 满 24 小时未回填：按该 `claimId` 幂等记 1 次未回填（重试不叠加）；稿件回空闲并重新可见；已扣次数不退。
- 释放后原领取人（未停权）与他人均可再领，须再次过门禁并扣次。
- 回填完成的稿件永不回广场。
- 官方下载权见 FR-014-19：已超时后若稿被他人新领，原记录立即不可下。

#### FR-014-17: 停权与恢复

终身未回填超过 3 次（第 4 次超时）失去领取权限。

**Consequences:**
- 「超过 3 次」= 第 4 次未回填触发。`strikes` 从 0 起，每次超时 +1；`strikes > 3`（即 ≥ 4）写入黑名单。前 3 次超时后仍可再领。
- 未回填按终身累计，不是滚动窗口。超时记次与写黑名单同一笔。
- 停权中无法再领任何稿；不影响已占用稿的下载 / 回填窗口。
- 恢复只能后台手动；行保留为「已恢复」，无自助解禁。

#### FR-014-18: 添加水印

已领取用户在一屏内给成片加水印再下载。

**Consequences:**
- 未领取不能进。底部坞按四组功能最高高度锁死；Tab = 字体 / 字色 / 背景 / 水印，切 Tab 不跳动。
- 字体 / 字色 / 背景复用通用剪辑预设。字号 0–10。字色/背景颜色与透明度上下分行。
- 应用范围：全部应用 / 每2张打1张 / 每3张打1张 / 每5张打1张 / 每2张打10张。文字可拖动定位。
- 主按钮文案「下载水印稿件并发布到抖音」。下载先「正在打水印」再「正在下载」；图集出示张数，视频出示百分比。保存成功后拉起抖音相册，见 FR-014-28。

#### FR-014-19: C 端 3 天下载窗

官方下载权：未回填与已回填在领取后 3 天内可下；已超时以是否仍空闲为准。系统对象另保留 7 天，后台可恢复一次，见 FR-014-22 / FR-014-32。

**Consequences:**
- 详情「下载并发布到抖音」与水印下载共用同一规则。保存成功后的抖音跳转见 FR-014-28。
- 未回填（占用中）、已回填：领取后 3 天内可下；超过 3 天 toast「领取已超过 3 天，无法再下载」。
- 已超时：不可回填。稿件仍空闲时，该次领取在 3 天窗内仍可下（次数已扣，给宽限）。该稿被他人新领成功后，原超时记录立即不可下、不可加水印，toast「稿件已被他人领取，无法再下载」。
- 云端对象已删（系统满 7 天）时同样不可下，toast「云端资源已失效，无法再下载」。
- 不回收用户已保存到本地的文件。

## C. 运营后台

#### FR-014-20: 剪辑手管理

运营录入后剪辑手才能上传。

**Consequences:**
- 必录：右豹 ID（唯一）、分成比例、备注、稿件需要审核（是/否，默认是）、发布平台（右豹 / 站外，多选，至少一个）。可上传项目只能勾选项目表；零勾选 = —，PC 不能传。
- 未开通右豹：其右豹稿不进广场。未开通站外：不能上传或管理站外稿。
- 列表另出示稿件数据（已上传 X，已被领取 X = 占用中 + 已完成，累计大小 = 名下全部稿件 size 之和）。备注、来源不在列表，只进详情抽屉。
- 数据统计在筛选上方。四格：剪辑手数量、累计稿件数量、累计稿件大小、累计结算收益（站内+站外），按当前筛选汇总。
- 收益数据拆站内稿件收益 / 站外稿件收益，各自点开抽屉。列表不出示待结算。站内=用户领取后结算分账；站外=剪辑手以右豹 ID × 项目-书籍 ID 自产关键词收益。改当前分成不重算历史。
- 两套抽屉都有累计收益 / 收益明细 + 日期范围。站内累计：日期、项目名称、累计已结算收益；站内明细含关键词（领取人）。站外累计比站内多书籍信息；站外明细关键词列不含领取人。
- 停用不看占用、也不看名下是否有稿，可直接停用。停用后 PC 上传入口点开弹窗「剪辑供稿权限已被收回，不能上传稿件」。名下仍有稿件不能删除。停用后其已通过空闲稿不进广场。

#### FR-014-21: 稿件管理

运营审 PC 新稿、直接录入，并看占用。

**Consequences:**
- 顶部分「右豹稿件 / 站外稿件」。
- 右豹：项目与书分列；书 = 名称 + ID；稿件信息 = 大小 + 括号数量（图集=张数，视频=1）+ 下载链接；发布技巧 = 一段正文。占用：空闲 / 占用中 / 已完成。稿件状态：正常 / 已删除。审核三态见 FR-014-06。
- 站外：大体同右豹，但无发布技巧、无素材类型、无审核。稿件信息 = x个素材(已领x个) + 大小；状态 = 空闲 / 部分领取 / 已领完。另列稿件状态。操作含分享链接与二维码。
- 新建门禁：右豹无启用剪辑手 / 项目 / 素材则不打开弹窗。站外不要素材类型。占用中、未超时领取或已删除不可删（仅右豹占用口径）。后台或剪辑手主动删除：阿里云同步删除，稿件状态=已删除，不支持恢复；行保留。

#### FR-014-22: 领取记录

排查谁领了哪份稿、选了什么词、回填了没有。

**Consequences:**
- 必出：项目名称、书籍信息、剪辑手信息（右豹 ID + 名称）、回填信息（含视频链接；未回填为 —）。
- 操作栏只留「稿件详情」抽屉，打开时带上该 `claimId`。下载链接旁文字操作「恢复C端下载」：恢复后该领取重新计时 3 天。每条稿件只能恢复一次。系统满 7 天 OSS 已删则不可恢复。不提供改状态、删记录。

#### FR-014-23: 黑名单

停权台账。

**Consequences:**
- 状态：停权中 / 已恢复。仅「恢复」操作。行不删。

#### FR-014-24: 项目管理

维护可上传、可进广场的项目。

**Consequences:**
- 新增从现有品牌项目库拉取全部项（已加入的仍列出），带出名称与 Logo，不手填新建。已添加则保存拦截。
- 可编启用 / 禁用 / 排序 / 更新时间。无已通过关键词字段，不读写申词。
- 禁用：不可上传、不进广场。仍有稿件不可删。

#### FR-014-25: 素材类型

上传必选、广场「素材」只筛这个字段。

**Consequences:**
- 启用才出现在 PC 上传与广场筛选。禁用后对应空闲已通过稿即时藏。
- 仍有稿件使用该名称则不能删，改为停用。

#### FR-014-26: 次数商品

运营配置工作日 / 节假日免费次数与积分档位。

**Consequences:**
- 工作日免费次数、节假日免费次数挂本页，均须 ≥ 0。保存「今日类型」对应字段后，当前用户免费剩余立刻改成该值。跨本地自然日按当日类型重置免费剩余，已购不重置。
- 档位「x 次 / y 积分 + 原价」；原价须为正数且 ≥ 积分；同时在售最多 4 档；可改价、下架。
- 出示只读购买人数（该档去重用户数）。新增默认下架。

## D. 收益入账

#### FR-014-27: 代发入账

关键词订单转为已结算时，先判定该词是否为代发，再入账。

**Consequences:**
- 绑定主键 = `(keywordId, claimId)`，且该领取 `status=已回填`。未回填 / 已超时不构成代发绑定。允许一词领多份不同稿。
- 判定：该 `keywordId` 存在至少一条已回填绑定即为代发。一词多条已回填时，分账对象取 `filledAt` 最近的那条（稿件 ID、剪辑手、分成快照都取它）。
- 代发则：剪辑手分账 = 四舍五入（应结算 × 该 claim 领取时的分成快照）；用户实结 = 应结算 − 分账（两边之和必须等于应结算）。不读剪辑手当前比例。
- 非代发：既有全额用户入账，不写剪辑手分账。先结算后回填：该 `orderId+keywordId` 已落账则不回溯；回填只影响之后的结算。
- 只在已结算时写明细；待结算只累计。状态 = 已结算；必须带秒级时间戳与金额。同一 `orderId + keywordId` 只落一次。失败整笔回滚。
- 写入既有项目收益明细，作为对入账拆账的显式增量；不改 FR-002 代发收益页（主子协议页）。广场 / 详情 / 领取列表仍不展示金额。
- 用户标题「您的账户于[{时间}]{项目名称}结算收益到账{用户实结}元」，描述含关键词 ID、应结算、代发分账、实际结算。
- 剪辑手标题「您的账户于[{时间}]{项目名称}作品代发收益到账{分账}元」，描述含稿件 ID。

## E. 抖音发布与站外渠道

#### FR-014-28: 下载并发布到抖音

已领取用户下载成片后，跳转抖音并拉起相册选片。

**Consequences:**
- 详情底栏按钮文案为「下载并发布到抖音」；水印页为「下载水印稿件并发布到抖音」。
- 仍先走 FR-014-19 的 3 天 C 端下载窗与保存到相册；成功后再拉起抖音相册。
- Demo：页内 `#dySheet` 模拟相册；scheme 只用隐藏 iframe 尝试，不得 `location.href` 带走宿主页。
- 领取成功时的 loading 三态不拉起抖音。过期或不可下时只 toast，不打开相册。

#### FR-014-29: 剪辑手发布平台

运营为剪辑手开通发布渠道。

**Consequences:**
- 剪辑手管理列表与表单增加「发布平台」多选：右豹、站外。至少选一个。
- 发布到站外的稿件不进右豹作品广场。
- 未开通右豹：其右豹空闲已通过稿也不进广场。未开通站外：不能上传或看到站外 Tab。

#### FR-014-30: 站外稿件

后台与 PC 用独立 Tab 管理站外文件夹稿件。

**Consequences:**
- 后台稿件管理、PC 上传 list 均分「右豹稿件 / 站外稿件」。
- 站外：无发布技巧、无素材类型、无审核；ID 前缀 `X-`；以文件夹呈现。
- 站外字段见 FR-014-07 / FR-014-21。分享链接与二维码指向 FR-014-31。
- 看板「上传的稿件」含站外；「已被领取」与 PC 收益数据不含站外。

#### FR-014-31: 站外下载落地页

站外用户扫码或打开链接即可下载，无登录。

**Consequences:**
- 只出示稿件基础信息（封面、标题、项目、书、类型）与「下载稿件」。可有一句「无需登录」说明，不得出现登录/注册。落地页不展示副标题、稿件信息、状态。
- 无登录/注册、无选词、无次数、无回填、无水印、不进广场。
- 点下载立即 `claimedAssets + 1`（先扣余量再播保存动效），不超过素材数，并立刻删除该素材的阿里云副本。PC / 后台「x个素材(已领x个)」即时同步。
- 已领完（`claimedAssets >= assets`）扫码或打开链接：缺省态「素材已领完」，无下载按钮。最后一次下载成功后本页切到同一缺省态。这是余量空，不是整夹清桶。
- 稿删除后链接失效，缺省态「链接已失效」。
- 站外不走 3/7 天窗，不能「恢复C端下载」。

#### FR-014-32: 阿里云存储

所有稿件资源上传到阿里云 OSS。C 端下载时效与系统对象生命周期分开。

**Consequences:**
- 上传即写入 `ossKey` 与 `uploadedAt`。稿件状态默认正常。
- 站内若存在领取：走 3 天 / 7 天。领取成功写 `claim.expireAt = claimedAt + 3 天`；`work.ossExpireAt = 该稿首次领取 + 7 天`。C 端只认 3 天窗。后台「恢复C端下载」每稿一次，用户重新计时 3 天且不得超过系统 7 天；恢复不重置 `ossExpireAt`。满 7 天删对象，稿件状态=已删除，不可恢复。
- 站内若从上传起一直未被领取：阿里云只保留 15 天。满 15 天系统删除，稿件状态=已删除，不可恢复。不再「一直留着等领取」。
- 后台或剪辑手主动删除：阿里云同步删除，稿件状态=已删除，<strong>不支持恢复</strong>。行保留在稿件管理 / PC list。
- 站外：文件夹内领完一个删一个。每次下载成功立即删除<strong>该份</strong> OSS 副本。下载链路不判定整夹是否领完。未领过的整夹同样满 15 天删。不走已领取的 3/7 天窗。
- Demo 不连真实阿里云，C / PC / 后台 / H5 共一份 store 字段模拟。落地契约见 Demo「前后端数据交互 → 阿里云存储」。删除规则须写进业务解释与 PC 剪辑手操作说明。
