FR-014 · 一键代发

不会剪辑也能做项目：剪辑手供稿，用户领取后回填变现

没有制作能力的用户进不了项目。平台用客服招募剪辑手，在已有 PC 创作者中心上传图集/视频；用户只在 C 端领取，再走该项目已有回填页发布。本手册给研发和运营对齐口径，不写迭代平台通用规范。

这一句怎么对外讲

对象口径不要讲
用户广场领成片，选词后下载，24 小时内回填。FR 编号、审核队列、分成金额。
剪辑手加客服录入后，在电脑「剪辑供稿」传文件夹或压缩包。App 里上传、站内申请表。
客服 / 运营先问卡在上传、领取、回填还是停权，再对状态。让用户自己去 PC 传，或承诺截不了屏。

做 / 不做

做

  • C 端广场 / 详情 / 选词领取 / 购次 / 我的领取 / 回填 / 水印。
  • PC 已有创作者中心加「剪辑供稿」：招募、看板、上传、list。
  • 后台七页：剪辑手、稿件、领取、黑名单、项目、素材、次数。
  • 图集预览最多 3 张；视频仍试看 5 秒。

不做

  • 不新造 PC 产品，不改项目中心 / 作品管理 / 收益中心。
  • C 端不做剪辑手工作台或上传。
  • 广场 Banner 复用平台已有能力，本 FR 不另开配置页。
  • Demo 无真实 HTTP、不真扣积分、不落权限库。

30 秒故事

  1. 有制作能力的人扫 PC / 广场招募海报的客服二维码，后台录入后才是剪辑手。
  2. 已录入剪辑手在电脑选授权且启用的项目上传。右豹稿看「稿件需要审核」；站外整夹一条、免审、不进广场。对照见「右豹与站外」。
  3. 右豹：审核通过且空闲才进作品广场。站外只走分享链接 / 二维码。
  4. 用户先看剩余次数，再浮层选该项目已通过关键词，才能领取；成功即扣次、占用、对他人隐藏。
  5. 24 小时内从「我的领取」回填则占用结束；超时记 1 次未回填、不退次、稿件回广场。终身未回填超过 3 次进黑名单，仅后台可恢复。
C 端不做剪辑手上传。广场招募帧只进海报。列表不展示收益金额，详情只出分成比例。
角色

三方各走各的入口，不要让用户去 PC 上传，也不要让剪辑手走 C 端工作台

剪辑手只在已有 PC 创作者中心；用户只在 C 端广场 / 详情 / 领取页；运营只在右豹后台七页。

用户

浏览已通过且空闲的稿件，先校验次数再选词领取，24h 内回填。无剪辑能力，不做上传。

剪辑手

客服接入、后台录入（右豹 ID / 分成 / 备注 / 稿件需要审核）。电脑上传：需审则审核中，免审默认已通过。仅可删空闲稿。

管剪辑手、稿件审核、领取、黑名单、项目、素材、次数商品。后台录入稿件视为已审通过。

客服

海报二维码接入剪辑手，不提供站内申请表或自助审核。

渠道对照 · 给运营

右豹稿给站内用户领，站外稿只走链接，两套规则不要混着答客诉

剪辑手在 PC「剪辑供稿」按当前 Tab 交稿：右豹进广场、要登录、要次数；站外整夹一条，扫码就能下，不进广场。后台「稿件管理」也是这两个 Tab。先看渠道，再对审核、占用、删除和收益。

一句话

  • 右豹稿件：右豹 App 用户在作品广场领取，选词、扣次、24 小时回填。一条稿同时只给一个人占。
  • 站外稿件：剪辑手把链接或二维码发给站外的人。对方打开 H5 就能下，不用登录，不占右豹次数。一个文件夹里有多份素材，领完一份删一份。
剪辑手必须开通对应发布平台，才能看到该 Tab、传到该渠道。只开通右豹的人交不了站外稿，只开通站外的稿永远不进广场。

客诉时先问渠道

  • 用户说「广场没有」：只查右豹稿。站外稿本来就不在广场。
  • 用户说「链接打不开 / 下不了」：查站外。已领完说「素材已领完」；稿被删或满 15 天说「链接已失效」。
  • 用户说「次数被扣了但没下到」：只会发生在右豹。站外下载不扣右豹次数。
  • 剪辑手说「我想恢复下载」：只有右豹、且对象还在、且没恢复过。站外没有这个按钮。
边界

门禁顺序、占用和停权不能改口

先停权，再次数，再资格，再占用，最后选词。次数不足不得打开选词浮层。一稿同时一人占用。超时不退次。终身未回填超过 3 次停权，只能后台恢复。

领取门禁（按这个顺序拦）

1 停权黑名单停权中：按钮「已被停权，无法领取」。
2 次数免费+已购=0：只开兑换浮层，不开选词。
3 资格审核/项目/剪辑手/素材任一不合格：当前不可领，不扣次。
4 占用占用中或已完成：领取失败，回广场。
5 选词必须点该项目已通过关键词，才能确认领取。
  • 禁用项目不可上传、不进广场。停用剪辑手或禁用素材的已通过空闲稿也不进广场。
  • 审核中 / 已驳回不进广场。已通过不可再驳回。
  • 右豹：领取后走 3 天 C 端下载 + 7 天系统对象；后台可恢复 C 端下载一次。满 7 天删 OSS，稿件状态=已删除，不可再恢复。
  • 右豹：上传后一直没人领取，阿里云只留 15 天。站外整夹一直没人领，同样满 15 天删。对照见「右豹与站外」。
  • 站外：不走 3/7 天，领一份删一份；不能恢复 C 端下载。已领完和链接失效不是一回事。
  • 后台或剪辑手主动删除（两个渠道一样）：阿里云同步删除，稿件状态=已删除，不支持恢复。右豹占用中或仍有未超时领取不能删。
  • 图集预览最多 3 张；角标仍显示真实张数。防截屏=禁右键/长按保存 + 用户水印 + 切后台模糊；真机系统截屏禁不掉。
  • 任何列表不展示金额。Demo 无真实 HTTP，数据在 localStorage 闭环。
不要对用户承诺「截不了屏」。规则只保证 Demo 级禁保存，真机截屏拦不住。
FAQ

先问卡在上传、领取、回填还是停权，再对状态

对用户不要讲 FR 编号。对研发指到对应端的「业务流程」「开发提示词」和「前后端数据交互」。

Q1. 为什么广场看不到刚传的稿？
先确认是不是站外稿：站外永不进广场，只走链接 / 二维码。右豹稿在剪辑手「稿件需要审核=是」时默认审核中，后台通过且空闲才进。免审剪辑手上传后空闲即可进。占用中、已完成、已驳回、已删除、禁用项目、停用剪辑手、禁用素材都不可见。
Q2. 次数够了为什么还领不了？
还要选该项目已通过关键词，且稿件当时空闲。未选词、已被占用、未审核通过、项目禁用、已停权都会失败。
Q3. 超时了次数能退吗？
不退。记 1 次未回填，稿件回广场。原领取人未进黑名单可再领，再领再扣次。
Q4. 停权了怎么办？
终身未回填超过 3 次。只能后台黑名单手动恢复，没有自助解禁。
Q5. 图集详情为什么只能看 3 张？
预览上限 3 张，角标仍是真实张数。领取前预览不扣次、不能保存。完整稿领取后再下。演示预览用现有封面凑 3 张，不是书内页。
Q6. 用户能在 App 里当剪辑手上传吗？
不能。C 端只领取。上传只在 PC 创作者中心。广场招募帧只看海报。
Q7. 领取后怎么下载？水印必做吗？
底栏「下载并发布到抖音」C 端 3 天内有效。点完先保存到相册，再拉起抖音相册选片。加水印可选，且本版仅图集；视频点「添加水印」toast「视频稿件暂不支持添加水印」。未回填/已回填倒计时结束出示「下载已失效」，toast「当前稿件下载时效已过期」。已超时只收录超时未回填，文案「回填已超时」。C 端过期后，运营可在领取记录稿件详情点「恢复C端下载」（每稿仅一次），用户重新计时 3 天。系统满 7 天删除阿里云对象后不可再恢复。回填只受 24h 窗影响。
Q8. 非剪辑手打开 PC「剪辑供稿」会怎样？
不跳走。招募 BN 仍在，点开抽屉可看海报。看板走缺省，上传入口不可用。「操作说明」仍可打开。
Q9. 用剪辑手稿件回填后，关键词收益怎么入账？
订单已结算时先判该词是不是代发。是则按分成拆成用户实结和剪辑手分账，两边都进项目收益明细，状态「已结算」。不是则全额给用户。对账看「前后端数据交互 → 用户收益入账」。
Q10. 成片在阿里云会留多久？删了还能恢复吗？
先分渠道。右豹有人领过：C 端 3 天可下，对象再留到首次领取后 7 天。右豹或站外一直没人领：从上传起只留 15 天。站外是领一份删一份，不走 3/7。后台或剪辑手点删除，云端立刻一起删。系统到期或主动删除后稿件状态都是「已删除」，都不能恢复。
Q11. 右豹稿和站外稿有什么不一样？
右豹进广场，要登录、扣次、选词、24 小时回填，一条同时一人占。站外不进广场，扫码就能下，不扣右豹次数，文件夹里领一份删一份。站外免审、没有发布技巧和「恢复C端下载」。详细对照看业务解释「右豹与站外」。

重要规则：关键词结算入账必须先判代发
  • 用户用剪辑手稿件完成作品回填后，领取时所选关键词产生的订单收益，在入账时必须校验该词是否为代发关键词。
  • 代发关键词：按该领取的分成快照自动拆成用户侧实结 + 剪辑手侧分账，两笔同时写入既有「项目收益明细」。
  • 非代发关键词：走既有全额用户入账，不写剪辑手分账，不套用本页文案。
  • 只在平台关键词订单已结算时落账；待结算只累计，不写明细。状态固定为「已结算」。必须带秒级时间戳与金额。

1. 背景与触发

1
回填完成用户领取剪辑手稿件并走该项目回填页提交。领取记录 → 已回填，稿件 → 已完成。此时还不入账。
2
关键词出单回填所用关键词产生平台订单收益。结算态沿用既有关键词订单：待结算 / 已结算。
3
入账前回检订单转为已结算时，后端先查该关键词是否绑定一条已回填的一键代发领取（claim.status=已回填，且 mid 为剪辑手稿件）。
4
按快照分账判定为代发后：应结算 × 该 claim 分成快照（四舍五入）= 剪辑手分账；用户实结 = 应结算 − 分账。同一结算事件原子写入用户账 + 剪辑手账。

2. 代发判定

条件结果入账
该 keywordId 存在已回填绑定 (keywordId, claimId)；一词多条取 filledAt 最近代发关键词按该 claim 分成快照拆用户实结 + 剪辑手分账；文案用本页模板
无已回填绑定，或领取未回填 / 已超时非代发既有全额用户入账；不写剪辑手分账
订单仍为待结算不入账只累计；明细不出现「已结算」记录

3. 分账口径

  • 应结算总额 = 该关键词本笔已结算订单收益。
  • 分成比例 = 该领取写入的分成快照（领取成功时的剪辑手比例），不读事后改过的当前值。
  • 剪辑手分账 = 应结算总额 × 分成比例（代发作品分账）。
  • 用户实结 = 应结算总额 − 剪辑手分账。
  • 用户实结 + 剪辑手分账必须等于应结算总额。复用既有项目收益明细，不另建账本，不改 FR-002。
