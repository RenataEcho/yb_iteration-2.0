研发 / 运营手册
FR-014 · 一键代发

不会剪辑也能做项目：剪辑手供稿，用户领取后回填变现

没有制作能力的用户进不了项目。平台用客服招募剪辑手，在已有 PC 创作者中心上传图集/视频；用户只在 C 端领取，再走该项目已有回填页发布。本手册给研发和运营对齐口径，不写迭代平台通用规范。

30 秒故事

  1. 有制作能力的人扫 PC / 广场招募海报的客服二维码，后台录入后才是剪辑手。
  2. 已录入剪辑手在电脑选授权且启用的项目，用文件夹或压缩包上传，提交平台审核。
  3. 审核通过且空闲的稿件出现在作品广场；审核中、已驳回、占用中、已完成都不进广场。
  4. 用户先看剩余次数，再浮层选该项目已通过关键词，才能领取；成功即扣次、占用、对他人隐藏。
  5. 24 小时内从「我的领取」回填则占用结束；超时记 1 次未回填、不退次、稿件回广场。终身未回填超过 3 次进黑名单，仅后台可恢复。
C 端不做剪辑手上传。广场招募帧只进海报。列表不展示收益金额，详情只出分成比例。
角色

三方各走各的入口，不要让用户去 PC 上传，也不要让剪辑手走 C 端工作台

剪辑手只在已有 PC 创作者中心；用户只在 C 端广场 / 详情 / 领取页；运营只在右豹后台七页。

用户

浏览已通过且空闲的稿件，先校验次数再选词领取，24h 内回填。无剪辑能力，不做上传。

剪辑手

客服接入、后台录入（右豹 ID / 分成 / 备注）。电脑上传，默认审核中。仅可删空闲稿。

运营

管剪辑手、稿件审核、领取、黑名单、项目、素材、次数商品。后台录入稿件视为已审通过。

客服

海报二维码接入剪辑手，不提供站内申请表或自助审核。

主路径

PC 供稿与 C 端领取是两条闭环，在「已通过且空闲」汇合

流程图挂在各端「业务流程」子 Tab：前端=用户领取；PC=剪辑手上传；后台七菜单各一张。旧顶层「业务流程」已取消。

剪辑手（仅 PC）

  1. 打开已有创作者中心 → 单一菜单「剪辑供稿」（招募 BN + 看板）。
  2. 未录入 / 已停用：看板缺省，不能上传。
  3. 已录入：选授权∩启用项目 → 文件夹或压缩包 → 填齐字段 → 提交审核。
  4. 后台通过后，空闲稿进广场；驳回 list 出示原因。

用户领取

  1. 广场宫格（项目图标直选，搜索在项目下）→ 详情铺满素材。
  2. 图集可点开放大，最多预览 3 张，不扣次、不占用、不能保存；视频仍试看 5 秒。
  3. 领取：次数 → 选词 → 空闲。成功后停在详情，底栏改为加水印 / 下载。
  4. 回填只从「我的领取」。超时释放可再领，再领再扣次。
边界

门禁顺序、占用和停权不能改口

先次数，后浮层选词，后占用。次数不足不得打开选词浮层。一稿同时一人占用。超时不退次。终身未回填超过 3 次停权，只能后台恢复。

  • 禁用项目不可上传、不进广场。停用剪辑手或禁用素材的已通过空闲稿也不进广场。
  • 审核中 / 已驳回不进广场。已通过不可再驳回。
  • 领取后 7 天内可下载，超时未下不可再下。
  • 图集预览最多 3 张；角标仍显示真实张数。防截屏=禁右键/长按保存 + 用户水印 + 切后台模糊；真机系统截屏禁不掉。
  • 任何列表不展示金额。Demo 无真实 HTTP，数据在 localStorage 闭环。
不要对用户承诺「截不了屏」。规则只保证 Demo 级禁保存，真机截屏拦不住。
FAQ

先问卡在上传、领取、回填还是停权，再对状态

对用户不要讲 FR 编号。对研发指到对应端的「业务流程」和「前后端数据交互」。

Q1. 为什么广场看不到刚传的稿？
PC 新稿默认审核中。后台通过且空闲才进广场。占用中、已完成、已驳回、禁用项目、停用剪辑手、禁用素材都不可见。
Q2. 次数够了为什么还领不了？
还要选该项目已通过关键词，且稿件当时空闲。未选词、已被占用、未审核通过、项目禁用、已停权都会失败。
Q3. 超时了次数能退吗？
不退。记 1 次未回填，稿件回广场。原领取人未进黑名单可再领，再领再扣次。
Q4. 停权了怎么办？
终身未回填超过 3 次。只能后台黑名单手动恢复，没有自助解禁。
Q5. 图集详情为什么只能看 3 张？
预览上限 3 张，角标仍是真实张数。领取前预览不扣次、不能保存。完整稿领取后再下。演示预览用现有封面凑 3 张，不是书内页。
Q6. 用户能在 App 里当剪辑手上传吗？
不能。C 端只领取。上传只在 PC 创作者中心。广场招募帧只看海报。

FR-014 · v7 需求规则

1业务目标

没有剪辑能力的用户，通过领取剪辑手已发布的图集/视频稿件做项目变现；剪辑手只走客服招募，不走站内申请。

2页面与入口

  • 作品广场：宫格；项目图标横滑直选；搜索在项目下方；下拉筛剪辑师 / 素材类型 / 稿件类型；封面为本地图片（小说/漫画/视频题材）。广场 Banner 复用平台已有能力（0–5 条轮播已实现），本 FR 不另做后台配置。只列启用项目、已录入剪辑手、启用素材、平台已通过且空闲的稿件；审核中 / 已驳回 / 占用中 / 已回填完成均不回广场。不展示收益金额。底栏切「已领」。
  • 稿件详情：素材铺满。标题下展示标签；书籍名称下为书籍 ID。内容底、按钮上展示注意事项。未领取展示领取步骤；领取后改为作品发布技巧（发布标题 / 发布描述可复制）。未领取底栏：剩余次数、快捷提词、领取。领取后底栏：添加水印、下载稿件。不展示收益金额。
  • 添加水印：底部坞按四组功能最高高度锁死，预览吃剩余空间。文本可点出键盘。字体 / 字色 / 背景 / 水印横向 Tab；四组叠同一高度，切 Tab 浮层不跳动。字色/背景的颜色与透明度上下分行，选项换行露出。水印文字可拖动。下载先打水印再下载。
  • 我的领取：项目图标只展示有领取记录的项目。胶囊 Tab：未回填 / 已回填 / 已超时。卡片：关键词标题；封面、作品标题、项目名称、作者、领取时间、下载时间、7 天下载倒计时（超时不可再下）。下载/复制链接为次级；立即回填始终高亮，已回填/已超时点按提示。点信息区（不含灰底三按钮）进该 mid 稿件详情，底栏为已领取；返回回到领取页。「立即回填」仍只去回填页。
  • C 端不承载剪辑手上传或工作台。广场招募帧进海报详情；上传只在 PC。

3交互规则

  • 领取门禁：先校验剩余次数（按钮旁可见），次数足够后浮层选该项目已通过关键词，不进下级页。确认后 loading：正在下载稿件 → 正在保存到相册 → 已保存到相册。
  • 次数不足弹出兑换浮层，选档后点「兑换」；在售最多 4 档，下架不可兑。
  • 领取成功即扣次，超时释放不退。原领取人未停权可再领同一稿，再领再扣次。

4边界规则

  • 一稿同时一人占用；占用中对他人 feed 隐藏。
  • 领取成功后 24h 未完成回填 = 1 次未回填，并释放回 feed。
  • 终身未回填超过 3 次停权，仅后台黑名单手动恢复。
  • 禁用项目不出现在作品广场。
  • 广场只列启用项目、已录入剪辑手、启用素材、已通过且空闲的稿。

5业务流程

见本页「前端交互 → 业务流程」。

1业务目标

剪辑手用电脑在已有右豹创作者中心供稿。本 FR 不新造 PC 产品，只在现有业务线增加剪辑供稿闭环。

2页面与入口

  • 已有导航：项目中心 / 作品管理 / 收益中心保持原样，本 FR 不改。
  • 剪辑供稿（单一菜单）：顶部招募 BN，下方剪辑手看板。点 BN 用侧栏抽屉展开招募详情（卖点 / 适合谁 / 客服二维码），无站内申请表。
  • 剪辑手看板：已录入才出数。已授权项目、上传的稿件、已被领取的稿件、已经产生的收益。非剪辑手（未录入 / 已停用）看板走缺省，不跳走。
  • 最近上传：出示书籍 ID、稿件信息（稿件大小 + 稿件名称）。
  • 上传入口：弹窗三步。① 选文件夹或压缩包；② 填齐后台同款字段（标题、项目、书名、书籍 ID、大小、稿件名称、发布标题/描述、图集或视频、素材类型；剪辑手=当前登录人）；③ 确认后提交平台审核。
  • 上传 list：与后台稿件表同字段，不展示稿件下载链接。出示平台审核：审核中 / 已通过 / 已驳回（驳回出示原因）。

3边界

  • 未录入或已停用：看板缺省；不能上传。招募 BN 仍可点开抽屉。
  • 只可传到录入时的可上传项目，且项目须启用。
  • 必须用文件夹或压缩包上传，不能只选单文件。
  • 提交后为审核中，不进广场；后台通过后才可见。已驳回 list 出示原因。
  • 剪辑手个人删除仅支持未占用（空闲）稿件；占用中与已完成不能删。
  • 发布写入与 C 端 / 后台同一份演示数据。

1业务目标

运营在右豹后台管剪辑手、稿件、领取/回填、停权恢复、项目、素材类型和次数商品。广场 Banner 复用平台已有能力，本 FR 不单开配置页。

2数据表与字段

  • 剪辑手：录入必填右豹 ID、分成比例、备注；可上传项目只能勾选项目表；另有昵称、客服来源、状态、录入时间。未录右豹 ID 不能上传发布。
  • 稿件：项目与书分列。书聚合书籍名称 + 书籍 ID。稿件信息聚合文件大小 + 下载链接。发布技巧聚合作品标题 + 作品描述。另有剪辑手、图集或视频、素材类型、占用态、平台审核（审核中 / 已通过 / 已驳回，驳回出示原因）、上传时间。PC 端 list 同字段但不展示下载链接。
  • 领取记录：用户、稿件、关键词、回填信息、待回填/已回填/已超时释放。操作列「详情」看出回填；「稿件详情」抽屉出示稿件字段。
  • 项目：支持添加 / 编辑。字段：项目名称、Logo 信息、状态（启用 / 禁用）、排序、更新时间、已通过关键词（至少 1 条）。禁用项目不可上传、不进广场。
  • 黑名单：用户、未回填次数、停权时间；支持手动恢复。
  • 次数商品：x 次 / y 积分，最多 4 档在售，可改价、下架。免费次数挂本页。

3列表与筛选

  • 详情用 Drawer，录入/编辑/改价用 Modal，恢复/下架用 Confirm。
  • 领取记录必须能看出回填信息与三种状态。
  • 剪辑手列表可按右豹 ID / 昵称筛选；项目列表可按名称 / 启用禁用筛选。

4边界规则

  • 停权恢复只能后台手动，没有自助解禁。恢复后回广场，可再领。
  • 禁用项目不可上传、不出现在作品广场。
  • 下架商品立即不可新购；已购次数保留。
  • 剪辑手停用后不能上传；有占用中稿件不能停用；有稿件不能硬删只能停用。
  • 占用中稿件不能删；有未超时领取不能删；回填后稿件为已完成，不回广场。
  • PC 新上传稿件默认审核中；后台通过后进广场，驳回须填原因且不进广场。
  • 前后端共用同一份演示数据：后台启用/停用/改次即时影响广场、上传与领取次数。本 Demo 是逻辑闭环，不是真实接口闭环。
  • 本 Demo 不做真实积分扣减或权限落库。
