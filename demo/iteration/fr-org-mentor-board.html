FR-011 · 需求规则 · v1

后台需求 · 机构导师看板

1业务目标

运营以机构为主要对象，查看该机构下的导师、导师团与社群聚合数据，并下钻到具体导师。本 FR 无 C 端呈现。

2数据表与字段

机构看板（主表）

  • 机构名称：机构主对象。
  • 社群数量：该机构下去重后的社群数，只读展示，不可点击。
  • 导师团数量：该机构下去重后的导师团数，只读展示，不可点击。
  • 导师数量：该机构下导师数；大于 0 时可点击，进入该机构导师明细。
  • 会员数量：该机构下会员去重人数。
  • 会员累计收益：该机构下会员累计收益（会员去重后汇总）。按会员加入该机构的时间窗口统计：仅计入加入时刻起（含）至解绑时刻止（不含）产生的收益；加入之前与解绑之后的收益不计入。
  • 更新时间：本行看板数据最近一次聚合刷新时间。

导师明细（下钻表）

  • 导师名称：导师在机构内的展示名。
  • 导师身份：导师在机构内的角色。本 Demo 枚举：主导师 / 协同导师 / 见习导师。
  • 右豹ID：导师的右豹帐号 ID，等宽展示。
  • 关联导师团数量：该导师关联的导师团数；大于 0 时可点击，弹窗列出导师团名称。
  • 社群数量：该导师关联的社群数；大于 0 时可点击，弹窗列出社群名称。
  • 会员数量：该导师名下会员数。
  • 会员收益：该导师名下会员收益合计。口径与机构「会员累计收益」相同，窗口按会员加入该导师的时间计算：加入之前与解绑之后不计入。

3列表与筛选

  • 机构列表筛选项：机构名称（模糊匹配）。查询刷新列表，页码重置至第 1 页。
  • 重置：清空筛选值，不自动触发查询，Toast 提示「筛选条件已重置」。
  • 导师列表示选项：导师名称（模糊）、导师身份（枚举）、右豹ID（精确或前缀）。规则同机构列表。
  • 下钻导师列表时，导师筛选项重置为空。
  • 机构列表顶部汇总：当前查询结果的机构数、导师合计、会员合计、会员累计收益合计。

4下钻与弹窗

  • 点击机构行导师数量：进入该机构导师明细页，页头展示机构名称，可返回机构列表。
  • 点击导师行关联导师团数量：弹窗标题「关联导师团」，列出该导师的导师团名称。
  • 点击导师行社群数量：弹窗标题「关联社群」，列出该导师的社群名称。
  • 弹窗仅展示名称，不提供跳转与编辑。点击遮罩或「关闭」、按 ESC 关闭。

5边界规则

  • 数量为 0 的导师数量 / 关联导师团数量 / 社群数量：灰色数字，不可点击。
  • 机构侧「社群数量」「导师团数量」即使大于 0 也不可点击；名称弹窗只出现在导师明细。
  • 机构「会员数量」按机构会员去重；导师「会员数量」按该导师名下统计。同一会员可关联多名导师，故各导师会员数之和可以大于机构会员数。
  • 会员累计收益 / 会员收益统计窗口：
    • 以会员与对应对象（机构 / 导师）的加入时间、解绑时间为准，不按会员全生命周期收益。
    • 一笔收益的发生时间满足 加入时间 ≤ 发生时间 < 解绑时间 才计入对应对象；未解绑则右端为统计截止（看板更新时间）。
    • 加入之前的历史收益、解绑之后产生的收益，均不作为对应对象的收益。
    • 同一会员多次加入 / 解绑：各绑定期分别计算后加总；间隙期不计入。
    • 同一会员同时挂在多名导师下：各导师只计该会员挂在自己名下期间的收益，互不挪用。
  • 机构「社群数量 / 导师团数量」为机构下去重；导师侧为该导师关联数，不做机构级去重展示。
  • 更新时间以数据聚合刷新为准，不随页面打开时间变化；未解绑会员的收益窗口右端对齐该更新时间。
  • 本 FR 不提供新增 / 编辑 / 删除机构或导师；Demo 数据不持久化。
