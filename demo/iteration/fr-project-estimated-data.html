FR-004 · 需求规则 · v1

1业务目标

为已开启「预估数据=显示」的项目，在 C 端提供数据查询能力：用户可按条件查询运营导入/维护的预估数据，查看聚合统计与明细列表。查询结果仅供参考，实际结算以平台结算数据为准。

2页面与入口

  • 入口：项目详情 / 数据工具区「数据查询」（复用既有 C 端项目页，本 FR 不重定义导航）。仅「预估数据=显示」且已配置展示字段时可见。
  • 顶栏：返回按钮 + 右上角「筛选」。
  • 当前项目：项目 icon（名称前两字）/ 名称；点击展开项目选择器（底部浮层），切换后刷新本页。
  • 筛选弹窗：底部弹出；固定「时间范围」（今日/近7天/近15天/近30天/本月/自定义，自定义时展示起止日期）+「关键词」；点「查询」后收起并刷新统计与明细。时间范围必填，关键词选填。
  • 数据统计：按后台「数据统计」配置渲染；排序第 1 项为大卡（文案「当前筛选下的总数据 · {统计项名}」），其余为三列小卡（值上标签下）。
  • 数据明细：标题「明细 · N 条」；首字段（关键词）为卡片标题；其余入灰色三列信息域（值上标签下，关联字段合并：主值 + 副值）；底部「最近出单：{日期}」。

3交互规则

  • 点筛选「查询」→ 按条件聚合统计 + 返回明细分页；完成后弹窗收起。统计与明细须来自同一次查询。
  • 明细卡片只读，不提供编辑/删除。
  • 链接类字段（字段名/标识含 link、url、链接、主页，或值为 http 开头）以链接色展示，点击复用 C 端外链规范。
  • 无匹配：明细空态「暂无数据，请调整查询条件」；统计区 0 或空值（口径由后端定义）。
  • 字段集合、顺序、统计项名称均读后台配置，C 端不可自定义列。明细建议分页，首屏 N 条由研发约定。

4边界规则

  • 项目「预估数据=隐藏」时入口不可见；已有数据保留，再次显示后恢复。
  • C 端仅展示当前用户有权限查看的项目预估数据（口径与既有项目数据可见性一致）。

5业务流程

见页内 Tab 「业务流程」。

1业务目标

为项目提供可配置的预估数据维护与展示：运营按项目开关入口，用展示配置定义列与统计指标，并维护明细（Excel 批量导入 / 批量删除）。

2数据表与字段

项目编辑弹窗（扩展现有 · 仅规则，本 FR 不做 UI）：新增 预估数据 = 显示 / 隐藏（建议默认隐藏）。显示后出现预估数据入口与 Tab；隐藏后入口不可见，数据保留不物理删除。

本字段仅写入需求规则，不在本 FR Demo 中设计项目编辑弹窗 UI；研发对照既有项目编辑弹窗扩展。

① 列表展示字段（项目级，可多条、可排序）：

  • 展示字段：列头名称。字段标识：唯一 key（存储 / 导入映射 / API）。创建后不建议改，必须改须有迁移。
  • 关联展示字段（可选）：如 user_id 关联 user_nickname；列表/C 端合并展示，导入后系统反查填充。
  • 是否支持导入：仅「是」进入 Excel 模版列与导入校验。排序同时决定列表列序与模版列序。

② 数据统计（可多条、可排序）：

  • 来源字段从「列表展示字段」下拉选择，同一列表字段不可重复添加。
  • 统计字段名与标识由系统生成（如「预估曝光量」→「预估曝光合计」/sum_est_exposure）；后端按配置聚合（sum / count）。
  • 排序决定 C 端统计区与后台表头统计区顺序。系统固定项「数据条数」（row_count）可保留，不关联列表字段。

预估数据表：列与表头统计均按展示配置动态渲染（含关联字段合并列）。系统字段建议：数据 ID、所属项目 ID、数据更新时间；操作：删除。

3列表与交互

展示配置：列表字段与统计项可增删改；排序即时影响预估数据表列、C 端明细与统计区。右侧「前端预览」与配置实时联动（Demo 用途）。

预估数据表：

  • 批量删除：勾选 → 确认 → 删除后统计区重算。
  • 批量导入 / 下载模版：列与「支持导入=是」的字段一一对应，顺序跟字段排序；模版按当前配置动态生成。配置变更后再次下载须反映最新列。
  • 导入失败须反馈原因与行号（整批或逐行由研发约定）。关联展示字段不进模版列。

筛选项：可与可检索的列表展示字段对齐（Demo：关键词、用户信息）。

4边界规则

  • 删除列表展示字段后，已存储的扩展字段数据建议保留，仅不再展示。
  • 同一项目下预估数据表与展示配置一一绑定；不同项目可独立配置。
  • 导入模版、列表列、导入校验必须以同一套「列表展示字段 + 支持导入」为单一数据源。
