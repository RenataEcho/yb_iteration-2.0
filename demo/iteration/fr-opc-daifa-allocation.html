FR-001 · 需求规则 · v1

1业务目标

在 OPC 协作结算 C 端增加「代发分配」能力：关键词出单后，系统按成员岗位比例自动分配收益，与负责人主动分配区分展示与权限。

2页面与入口

  • 我的工作室：分配记录增加「代发」标签；代发记录不可撤回。
  • 成员详情：仅代发成员展示「授权帐号:x」；点击进入代发成员详情。
  • 分配详情（负责人）：成员汇总（名称、金额、预扣税额、关键词数、帐号数）；点击行出底部浮层明细；支持导出（关键词、出单金额、分配金额、发布帐号、分配时间）。
  • 成员视角：新增「分配详情」「发布帐号」入口；发布帐号列表含平台、昵称、ID、编辑，右上角「添加」复用右豹现有流程。
  • 成员分配详情：代发累计收益（仅统计代发）、授权帐号数、关联关键词；明细 list 含关键词、分配金额、发布帐号、分配时间。
  • 代发成员详情（负责人下级）：昵称、岗位、绑定时间、分配比例、累计已分配/已提现；Tab：分配记录 / 分配详情 / 授权帐号。

3交互规则

  • 分配详情浮层、导出等为 overlay 浮层，不挤压列表页布局。
  • 「代发」标签仅用于系统自动分配产生的记录；主动分配无此标签。
  • 成员「代发累计收益」仅汇总代发分配，不含负责人主动分配。
  • 发布帐号「添加」跳转/复用右豹既有添加帐号流程，本需求不重新定义添加步骤。

4边界规则

  • 代发分配记录不可撤回；主动分配记录可撤回（沿用现有逻辑）。
  • 「授权帐号」入口与计数仅代发成员展示。
  • 成员侧分配明细需包含分配时间字段（负责人浮层/export 同步）。

5业务流程

前后端交互与校验逻辑见页内 Tab 「业务流程」（流程图，含校验节点）。

涉及：代发自动分配、发布帐号授权、出单→结算→分配明细、代发 vs 主动撤回差异。

1业务目标

为代发分配提供运营/研发可查的数据面：发布帐号归属、代发关键词收益与分配明细，支撑问题排查与对账。

2数据表与字段

发布帐号表：ID、帐号昵称、帐号ID、主页链接、成员信息（ID+昵称）、工作室（负责人ID+名称）、帐号平台、状态、添加时间；操作：编辑、日志。

代发关键词表：关键词、项目方、工作室、发布帐号、所属成员、累计产生收益、累计分配、数据更新时间；操作：详情。

关键词详情 list（详情抽屉 · 合并 6 列）：收益金额、收益产生时间、收益结算时间、分配金额、分配时间、分配批次。

分配记录表（扩展字段 · 本需求仅定规则）：分配行为 = 系统自动 / 负责人主动；不在 C 端原型体现。

3列表与筛选

发布帐号筛选：发布帐号 ID、帐号昵称、帐号 ID（平台唯一）、成员 ID/昵称、负责人 ID、工作室名称、帐号平台、状态、添加时间范围。

代发关键词筛选：关键词、项目方、负责人 ID、工作室、发布帐号 ID/昵称、成员 ID/昵称、更新时间范围。

关键词「详情」以 overlay 抽屉展示合并 list，不挤压列表页宽度。

4边界规则

  • 已删除发布帐号保留历史记录，状态标记为已删除。
  • 关键词累计产生收益、累计分配以数据更新时间为准展示。
  • 代发自动分配写入时 分配行为=系统自动；负责人主动分配为 负责人主动。
