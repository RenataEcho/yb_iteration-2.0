一键代发业务说明

本文说明「一键代发」是什么、怎么走、有哪些必须遵守的规则。分成比例、授权项目、是否免审以商务与运营书面确认为准。页内流程图与产品「业务流程」同规范：正交折线、失败/驳回接到起点顶边。点「复制 Markdown」后，流程图是带回环的 Mermaid。

一、业务是什么

一键代发把「做片」和「发片变现」拆开：有制作能力的人把图集、视频成片供到平台；没有制作能力、但有项目资格和关键词的人领取成片去发布。关键词产生的订单收益，按事先约定的分成结算。

一句话：把会做片的人和会发片的人接在同一条项目链上，按关键词订单分成。

它不替代现有的项目、申词、回填、结算中台，也不做成「人人上传自制剪辑」，更不是代运营整号或平台替用户发抖音。平台提供成片、发布技巧，以及下载成功后拉起抖音相册；发布动作仍在领取人侧。

三、三类角色

  • 剪辑手：经客服接入、后台录入后，在电脑端为授权项目供图集或视频，按领取后的关键词订单分成。
  • 领取用户：在 App 领取成片、限时回填发布；列表不展示金额，详情只展示分成比例。
  • 运营：录入剪辑手、审稿、配项目与次数、处理停权恢复；不在 C 端给剪辑手开上传口。

四、剪辑手规则

入驻

  • 没有线上申请表，没有 App 上传。海报（PC 招募位、C 端广场招募帧）只有卖点和客服码。
  • 扫码不等于入驻。运营必须录入：右豹 ID、分成比例、是否需要审核、发布平台（右豹 / 站外，至少选一个）、可上传项目。
  • 未录入或已停用：不能上传；招募说明仍可看。停用后点上传会提示权限已收回。
  • 停用不因「名下还有稿 / 有人占用」而拦截；但名下仍有稿时不能删除该剪辑手账号。

交稿

  • 只在电脑「创作者中心 → 剪辑供稿」。一次只能：一个项目 + 一本书 + 一种类型（图集或视频）。
  • 顺序不可颠倒：先填项目、书名 / 书 ID / 链接、类型、素材类型，再选文件夹或压缩包。不要先选文件再回头补字段。
  • 视频：文件名（去后缀）= 标题。图集：一个文件夹一条，文件夹名 = 标题；不要把所有图平铺在一个大文件夹。
  • 压缩包会先「解压中」再解析；文件夹直接解析。确认表可改发布技巧，也可用 AI 整表生成；空技巧也可以上传。
  • 上传失败只重传失败文件，不重传发布技巧。解压中、上传中不要关窗。

审核（仅右豹）

  • 录入时「稿件需要审核 = 是」：新稿默认审核中；「否」：新稿默认已通过。改成否，不回溯已经在审的稿。
  • 审核中、已驳回不进广场。驳回必须写原因。已通过不能再驳回。
  • 运营直接录入的稿视为已审，默认已通过。

站外稿

  • 不进广场、不审核、无发布技巧、无素材类型。以文件夹分享链接或二维码。
  • 对方不用登录。点一次下载立刻扣 1 个余量。已领完只出示「素材已领完」，不再给下载按钮。

五、领取流程图与门禁规则

必须同时满足

  • 门禁顺序固定：停权 → 次数 → 选词 → 资格 / 占用。次数不够不得打开选词浮层。不可跳过选词只扣次。
  • 停权中：按钮文案「已被停权，无法领取」，不打开兑换、不打开选词。
  • 可选的词只有两种状态：审核通过待发布、审核通过已回填。待审核、已驳回不出、不可领。无默认带入任何一条。
  • 词上带书籍 ID 且与稿件书籍不一致：提示选与该书一致的词，不扣次。词不带书 ID 则只按项目校验。
  • 未选词或没有已通过词：提示先选该项目已通过关键词，不扣次。
  • 稿件被他人占用、项目禁用、未通过审核等：不扣次、不占用。
  • 领取成功一次写入：占用中、扣次（先扣当天免费、再扣已购，不退）、领取记录为未回填、锁定当时的剪辑手 ID 与分成比例。

次数

  • 剩余次数 = 当日免费剩余 + 已购剩余。免费按工作日 / 节假日两套配置，跨自然日重置免费，已购不重置。
  • 积分兑换形态为「x 次需要 y 积分」，同时在售最多 4 档，可改价、下架。下架后不能新兑，已买次数保留。原价高于现价时出示划线价。
  • 兑换成功只刷新次数，不自动弹出选词。

广场里能看见什么

  • 必须同时成立才出现：已通过审核、当前空闲、稿件状态正常、项目启用、剪辑手已录入且开通右豹、素材类型启用、不是站外稿。缺一条就看不见。
  • 任何列表不展示收益金额、分成、积分。详情展示分成比例，不展示金额。
  • 未领取也可预览：图集最多看 3 张（角标仍是真实张数），视频试看 5 秒。预览不扣次、不占用、不能当下载。真机系统截屏拦不住，不要对外承诺「截不了屏」。

六、回填、占用与停权

  • 同一成片同一时刻只被一人占用。占用中他人广场看不到，领取也失败。
  • 领取后须在 24 小时内走该项目已有回填页。回填成功：记录变为已回填，稿件变为已完成，不再出现在广场，次数不退。
  • 满 24 小时未回填：记原领取人 1 次未回填，稿件释放回广场。已扣次数不退。未停权的原领取人与他人都可再领，再领再扣次、再选词。
  • 「超过 3 次」= 第 4 次超时才停权。前 3 次超时后仍可再领。按终身累计，不是滚动窗口。停权后不能再领任何稿，没有自助解禁，只能后台手动恢复。
  • 已回填、已超时的记录不能再进回填页。

七、下载、水印与文案

  • 未回填 / 已回填：领取后约 3 天内可官方下载；倒计时结束出示「下载已失效」。
  • 已超时 Tab 只收录超时未回填，卡片文案「回填已超时」，不可下载。不再对外说「已被他人领取」。
  • 点下载或复制链接时，提示优先顺序：时效已过 → 停权 → 24 小时未回填。
  • 已领取详情出示一段「发布技巧」，可整段复制。底栏：添加水印、下载并发布到抖音（保存到相册后拉起抖音相册）。
  • 水印仅图集。视频点「添加水印」提示暂不支持，不进页。未领取不能加水印。
  • 快捷提词只提示去该项目题词页，不领取、不扣次。

八、分成与入账

  • 领取时锁定分成快照。之后改剪辑手当前比例，不改已经领取的那一笔。
  • 构成代发绑定的条件：该关键词存在至少一条「已回填」的领取。未回填、已超时都不算。一词多条已回填时，按最近一次回填来分。
  • 待结算只累计，不写明细。已经按非代发落账的，后来才回填，不回溯改账。
  • 剪辑手看板里的收益数据只统计右豹端稿，不含站外稿。站外收益口径另行书面确认。

九、成片存储规则

  • 右豹一直没人领：从上传起约 15 天删除云端文件，状态变为已删除。
  • 右豹有人领过：领取人约 3 天可下；云端对象再留到首次领取后约 7 天。满 7 天删除后不可再恢复。7 天内运营可给用户恢复一次下载窗口，新的 3 天不能超过系统 7 天。
  • 站外不走 3 天 / 7 天：每成功下载一份就删该份。整夹一直没人领，同样满 15 天删。
  • 剪辑手或后台主动删除：云端立刻一起删，不能恢复。占用中、已完成不能删。已删除的行还在清单里，但不能再下、不能再分享。
  • 不回收用户已经存到本地的文件。请按项目节奏供稿，不要把云盘当长期片库。

十、可谈的合作与红线

可谈三类：剪辑产能（项目、分成、审核、渠道、月供稿量）；品牌扩供（是否接入供稿池、启用停用、领取方是否已有申词资格）；站外分发（无登录落地页、按份下载、不进广场）。

一次谈清：身份（个人 / 工作室、是否统一右豹 ID）、仅右豹 / 仅站外 / 都要、分成、是否审核、授权项目清单、命名规范、月度节奏（对齐 15 天未领清理）、对账周期、对接人与录入时间。

  • 不承诺保底领取量、保底收益。
  • 不承诺站内自助申请剪辑手，不承诺 App 内上传。
  • 不把产品说成代运营整号或平台替你发抖音。
  • 分成、免审、项目名单以录入为准，口头承诺无效。

十一、对外口述（约 30 秒）

右豹一键代发，让会剪辑的人给品牌项目供成片，让不会做片但有项目、有词的人直接领取去发。剪辑手加客服开通电脑端「剪辑供稿」，图集和视频都能传；用户在 App 里领、回填、发布。钱从关键词订单来，按入驻时谈好的分成，领取当时锁定，结算后两边都能对上账。也可以开通站外链接，给私域按份下载。要合作，先定项目、分成、审不审、走站内还是站外。

口径以产品规则为准。具体分成、项目授权、审核方式以书面确认为准。复制时如需改数字或项目名，请与运营对齐后再外发。
