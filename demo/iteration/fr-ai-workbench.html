如何使用

把要查的事用一句话说出来，答案在右侧表格。不会写时，照着下面的句子改赛道、项目或用户ID即可。

项目业务

看某个赛道里，每个项目今天谁题词最多

可以这样问：小说赛道下所有项目今日用户题词top3
你会看到：每个项目各一张表，有用户ID、昵称、项目名称、题词量

看整个赛道今天谁题词最多（不拆项目）

可以这样问：小说赛道今日用户题词top3
你会看到：整赛道前三名，同样是用户ID、昵称、项目名称、题词量

看某个赛道今天怎么分红

可以这样问：小说赛道今日分红数据
你会看到：每个项目的总分成、最高分成比例

看某个项目这几天的订单

可以这样问：星河小说按日订单数据
你会看到：每天的出单人数、出单关键词数量、订单量、累计收益（看不到具体关键词）

用户数据

看某个人邀请了多少人

可以这样问：用户 1001 邀请数据
你会看到：累计邀请、今日邀请、近7日邀请

看今天注册了多少人

可以这样问：今日注册人数
你会看到：累计注册、自然裂变注册、邀请注册

看今天新升上去的团长

可以这样问：今日升级团长数
你会看到：V2 多少人、V3 多少人

看现在有多少各等级团长

可以这样问：团长身份数据统计
你会看到：V1 / V2 / V3 各多少人

看某个人的项目收益

可以这样问：用户 1001 近7日项目收益；用户 1001 近30日项目收益；用户 1001 累计项目收益；用户 1001 2026年项目收益
你会看到：累计收益；按日会列出每天，按年会列出每月

用户关系

看两个人是不是一条线上的上下级

可以这样问：查询用户 1001 和 2001 的上下级关系
你会看到：直属还是间属、谁是谁的上级、团长等级和昵称

看某个人往上分红给了谁

可以这样问：用户 1001 向上分红关系数据
你会看到：关系类型、上级ID、累计分红

看某个人在指定项目上往上分了多少

可以这样问：用户 1001 在星河小说、夜话连载收益向上产生的分红数据
你会看到：项目名称、用户ID、关系、上级ID、累计 / 今日 / 昨日分红

需求规则 · FR-009

给研发对照实现。运营问法见「如何使用」，不要把本节文案直接给使用者。

产品边界

  • 独立工作台：左对话、右结果表；v1 只读，写指令必须拒绝。
  • 只执行已批准意图，禁止开放 NL2SQL / 模型口算排名与关系。
  • 缺赛道 / 项目 / 用户ID / 时间范围：先澄清，结果区不出假表。
  • 本页 Demo 为 Mock，题词量、赛道、时区未接真库。

项目业务 · 实现口径

FR-17 赛道 × 所有项目 × 今日题词 Top 3

按项目分组排名。零题词项目仍出组，单元格「暂无数据」。并列第 3 全留。列：用户ID、用户昵称、项目名称、题词量。

FR-18 赛道整榜 × 今日题词 Top 3

赛道内跨项目合并后再取 Top 3，不得拆成多张项目表。列同 FR-17。与 FR-17 靠「所有项目」槽位区分。

FR-19 赛道今日分红

按项目行：项目名称、总分成、最高分成比例。无分成出「暂无数据」。

FR-20 指定项目按日订单

按日一行：项目名称、出单人数、出单关键词数量、订单量、累计收益。关键词只出 count，禁止出词面。

用户数据 · 实现口径

FR-21 邀请数据

一次返回累计 / 今日 / 近7日。用户不存在不编造。

FR-22 今日注册

累计注册 = 自然裂变 + 邀请注册。未绑邀请码 = 自然裂变；已绑 = 邀请注册。

FR-23 / FR-24 团长

升级团长：仅今日升为 V2、V3 的人数，不含 V1。身份统计：当前存量 V1 / V2 / V3，与升级不是同一查询。

FR-25 项目收益

必出用户ID + 累计收益。近7/30/日期范围：按日明细。按年：按月明细。累计：可不出明细。

用户关系 · 实现口径

两人上下级

先判直属（默认上级）/ 间属（链上且隔层）。无关系：分别回退各自默认上级，不铺祖先链。

FR-26 向上分红关系

行：用户ID、关系（直属、间属、归级、直属团队、间属团队）、上级ID、累计分红。时间槽：按日 / 累计 / 日期。

FR-27 指定项目向上分红

槽位：用户ID + ≥1 项目名。行：项目名称、用户ID、关系、上级ID、累计分红、今日分红、昨日分红。无项目名走澄清，不要回退成 FR-26。
