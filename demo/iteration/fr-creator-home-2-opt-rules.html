工具关联（ProjectToolLink + ToolCatalog）

场景展示规则数据
首页 #projectList 行底 .project-tools：chip +「更多」 仅当该项目存在 ProjectToolLink 时展示；chip 按 sort 升序；点击 chip/更多 → Bottom Sheet 关联 projectId↔toolId；读 ToolCatalog 名称/描述/范围
变现 #cashList（列表模式） .project-tools 推荐工具行 点击 → 工具详情 Sheet（V30）；与首页 Sheet 同一套 ToolCatalog 同上 + Sheet 内 recommendReason（关联表字段）
Sheet 内「去使用」 — 关 Sheet → 进入工具使用流（跳转/toast 与现网一致） —
样式 — 首页 chips 与变现页 grid 布局隔离（#projectList 不受 .project-tools grid 污染） —

字段必填说明

toolId是指向工具市场 / ToolCatalog

Tab · 收益趋势（trend）

模块元素规则数据
分析周期#trendGlobalFilter 横向月份按钮 data-period=YYYY-MM最长近半年；切换刷新本 Tab 内所有周期文案与图表读 按月的日粒度收益序列
趋势图#trendLinePath / #trendAreaPath、Y 轴刻度、#trendXAxis单位元；随所选月份重绘同上
关键数据#metricTotal 周期收益、#metricAvg 日均、#metricMax / #metricMin 极值及环比 *Rate四宫格；环比相对上一可比周期（口径与现网一致）读 聚合统计
收益构成#incomeDonut + #incomeMixLegend按赛道占比；与所选月份联动读 赛道维度汇总；赛道名来自项目/赛道主数据

Tab · 收益日历（calendar）

模块元素规则数据

课程详情 · 结构与推荐

区域规则
顶栏 + Hero标题、课程分类 tag、类型/时长、简短导语；无底部「课程简介 / 适合谁看」等扩展基础信息块
内容区图集：横向滑动卡片（一屏约一张 + 步骤说明），非纵向铺满；视频：预览播放器
视频预览未播放态展示「预览」角标 + 居中播放；播放后露出控制条（暂停/进度/时长）
画面缩放支持放大/缩小（± 按钮、双指捏合、触控板 Ctrl+滚轮）；点击百分比还原 100%；放大后可拖拽平移；支持详情内全屏
推荐课程详情页底部展示；数据源 = 同一知识库内其他课程；排除当前课；优先相同「课程分类」（data-kind / 后台课程分类字段），再补其他分类；Demo 最多 4 条，可点击进入详情

课程管理 · 对接说明（开发真源）

项规则
内容维护继续在知识库管理上传/编辑/上下架；知识库已有大量课程
新增字段知识库列表列「课程分类」— 下拉，数据源 = 分类管理 API 返回的启用中分类 list
C 端学院按「课程分类」映射频道 Tab（项目教学 / 案例拆解 / 进阶技巧 等）；未分类策略与产品/知识库约定一致
预览 D-1若在知识库侧预览，仍打开 C 端学院详情播放；不在列表做预览按钮（若知识库已有则沿用现网）

后台配置 = 运营/教务在 Admin 或既有运营台写入，C 端只读展示。
关联数据 = 多实体关系表（如 ProjectToolLink），展示时读主数据补全。
读主数据/统计 = 项目、工具、订单、收益等既有域，本 FR 不新建平行库。
