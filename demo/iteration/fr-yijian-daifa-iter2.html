FR-018 · v1 需求规则

1范围

  • 新开迭代页，只覆盖本页列出的增量。FR-014 一键代发 1.0 历史页、FR-017 收益池与限时领次页都不改。
  • C 端视觉沿用 1.0：橙色主色、稿件详情、购买次数底部浮层、底栏「快捷提词 / 领取稿件」。剪辑供稿沿用现有 PC 列表。

2积分档位营销标签


  • 次数商品配置在本需求的管理后台，不改 1.0「次数商品」页。
  • 新增字段标签：按档位上传图标。C 端只展示这张图；未上传则不展示标签。
  • 兑换浮层不展示「在售 x 档」。
  • 点「立即兑换」：该档开启限制购买时提示「每人仅支持兑换 N 次」；未开启时提示「兑换成功」。
  • 后台“次数商品”需要增加字段:标签、限购(需要配置系数,每人累计可购买几次)

3详情页书籍链接

  • 稿件详情在书籍 ID 下展示书籍链接，并提供「复制」。书籍ID也支持复制
  • 领取前、领取后都展示。链接为空时不出现复制，快捷提词带过去的链接栏留空。

4快捷提词

  • 点「快捷提词」进入现有申请关键词页，不新建题词页。
  • 把该稿件的书籍 ID和书籍链接带到题词页，关键词仍由用户填写。字段可改。

5剪辑手回填信息

  • 剪辑手 PC「稿件上传」列表增加列回填信息。
  • 展示用户回填的作品链接。未回填显示「—」。
  • 有多条回填时，列表只显示最近一次已填写的作品链接。

编辑档位

上传图标。C 端按该图展示，不上传则不展示标签。
