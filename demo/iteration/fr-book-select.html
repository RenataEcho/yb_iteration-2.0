FR-012 · v1 需求规则

1业务目标

没有自有书库的项目，用户也能在平台抓取书库里把书找出来，选好推广类型后申请关键词，不用再口头问「这本书能不能推」。

2页面与入口

  • 入口：仅无自有书库的项目，从该项目申词入口进入选书中心。有书库的项目不展示本入口。
  • 列表：页头为「选书中心」；搜索书名；项目方 Tab（全部 / 番茄小说 / 番茄短剧 / 番茄漫剧）；三列封面 + 书名 +「完本/未完本 · 字数」。
  • 筛选：偏好、篇幅、状态、类型。点确定才生效，点 × / 蒙层关闭不改已生效条件。重置回到各维「全部」。
  • 详情：封面（可下载）独立在上。书名、作者·偏好·篇幅·状态·字数、类型标签与书籍ID / 书籍链接收在同一张「基础信息」卡内，ID/链接在卡底细线下方，均可一键复制。再下是作品简介（复制文案 / 阅读全文）。
  • 推广类型：在申请关键词区域上方，下拉必选。字段标题字号与「作品简介 / 申请关键词」对齐（15px / 700）。选项来自当前项目题词配置的类型。Demo mock：真人出镜、图文、解压TTS、解说混剪、AIGC。
  • 申词 Tab：申请关键词 | AI申词。原输入框内「AI换词」删除，不再出现。

3交互规则

  • 申请关键词：用户手输 4-10 个汉字；不可带标点 / 符号 / 字母 / 空格 / 涉黄涉政等敏感字眼。
  • AI申词：不标「申请数量」字段名。数字输入框做成圆角描边容器，右侧内嵌橙色描边按钮「申请」。Tab「AI申词」右侧是文字按钮「更换」，用来换一批。数量 1–10；未点「申请」出词不能题词。出词必须走第 5 节提示词，入参为当次书籍ID、作品简介、推广类型、申请数量。
  • 主按钮文案为立即题词，不再使用「立即提交」。
  • 推广类型对两个 Tab 共用，切换 Tab 不丢失已选类型。
  • 提交成功走现有申词审核，本 FR 不重定义审核态。

4边界规则

  • 未选推广类型不可提交。
  • 项目题词配置没有类型时，下拉为空，阻断申词并提示运营配置。
  • 下架书不出现在 C 端列表；已打开的详情若被下架，提交时后端再拒一次。
  • AI 申词数量 < 1 或 > 10 直接拦截；「申请」出词，「更换」只换词，都不改数量。
  • 模型输出后仍按「4–10 个汉字、无标点/符号/字母/数字/空格」过滤；过滤后不足申请数量则重试或提示失败，不得用不合格词凑数。

5AI 提示词

AI申词按书籍ID + 作品简介出词。服务端用下面模板，把花括号换成当次请求值。模型只允许输出词；前后端再按 4–10 汉字、无符号规则过滤。

你是短视频投放的关键词策划。只根据下面给定的「书籍ID」和「作品简介」申请关键词，不为其他书出词，也不用训练集里的同名作品补设定。

【输入】
书籍ID：{book_id}
作品简介：{intro}
推广类型：{promo_type}
申请条数：{count}

【目标】
围绕该书籍ID对应的这一本作品，从简介里的人物关系、冲突、世界观和可传播卖点，提炼恰好 {count} 个适合该推广类型检索、点击的关键词。

【必须遵守】
1. 每个词只能是 4 到 10 个连续汉字；禁止标点、符号、空格、字母、阿拉伯数字、英文。
2. 恰好输出 {count} 行，一行一词；不要序号、引号、冒号、解释或前后空行。
3. 每个词都必须能被简介直接解释；简介没写的人名、地名、身份、结局一律不准编。
4. 书籍ID只用来锚定是哪一本书，禁止把 ID 字符写进任何一个词；也不要把纯书名、作者名当词。
5. 不要「小说」「全集」「免费」「完结」「番茄」等平台无效词；词与词不要近义复读。
6. 禁止涉黄、涉政、暴力、歧视及平台敏感表述。
7. 可按推广类型微调语气（解压TTS偏情绪，解说混剪偏反转/冲突），但不要把类型名称写进词里。

【自检】
输出前逐条核对：汉字数 4–10、能指回简介、互不重复。任一不合格先改写，再一次性输出终稿。

6业务流程

见页内 Tab 「业务流程」。

1业务目标

运营能看见抓回来的书是否上架、从哪条源来，以及用户从选书中心交出的申词有没有进审核。

2数据表与字段

  • 书库：ID、书名、作者、项目方（番茄小说 / 番茄短剧 / 番茄漫剧）、偏好、篇幅、连载状态、字数、类型、简介、封面、上架、抓取时间。封面与简介只读，本 FR 不提供人工录入书。
  • 申词记录：用户、项目、书 ID/书名、推广类型、申词方式（手动 / AI申词）、关键词列表、审核状态、申请时间。推广类型落库当时值，不随后台改配置回溯改写。
  • 推广类型枚举不在本表维护，读取项目题词配置。
  • AI申词调用模型时，必须带上前端规则第 5 节的提示词模板，并传入当次书籍ID、作品简介、推广类型、申请数量。

3列表与筛选

  • 书库可按书名/ID、项目方、上架筛选；详情抽屉只读。
  • 申词记录可按用户/关键词、方式、审核状态筛选；详情看词列表。
  • 上架/下架立即影响 C 端可见池。下架不删除抓取底表。

4边界规则

  • 抓取任务与源站同步不在本 FR 重做，后台只消费已入库数据。
  • 删除书库记录不允许；只允许下架。已产生的申词记录保留。
  • 审核通过/驳回复用现有申词后台，本 Demo 不另做审批弹窗。
