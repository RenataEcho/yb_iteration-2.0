FR-005 · 需求规则 · v1

1业务目标

合作方原始订单导入后，平台按项目策略对参与结算字段批量优化，输出优化后 Excel 供内部使用。无 C 端呈现；原始订单保留对账。

2后台 Tab

  • 优化策略：策略列表，可新增；每条策略含名称、优化项目（多选）、结算字段比例与豁免权值、白名单隔离、ID 比例、前几名等共存生效的配置；支持查看详情、编辑。
  • 用户白名单：独立 Tab；字段含用户 ID、状态、添加时间（无所属项目）；支持新增、编辑、删除、批量导入。
  • 关键词白名单：独立 Tab；字段含所属项目、关键词、状态、添加时间；支持新增、编辑、删除、批量导入。
  • 优化记录：导入时选择优化策略 → 执行优化 → 列表展示汇总指标；支持下载、删除、查看对比。

3优化记录字段

  • 项目名称、选择优化策略、优化前/后订单量、优化前/后累计金额、优化时间。
  • 操作：下载优化后 Excel、删除（需确认）、查看对比（抽屉展示逐单原始 vs 优化）。

4策略口径

  • 优化校验顺序：整单级 ①→②→③ 顺序判定、命中即跳过后续整单校验；通过整单校验后进入逐字段 ④→⑤，④ 仅豁免当前字段、其余字段继续。
  • ① 用户白名单：策略勾选且用户 ID 命中 → 整单原样，不优化。
  • ② 关键词白名单：策略勾选且关键词命中 → 整单原样，不优化。
  • ③ 前几名不优化：在未被 ①② 整单豁免的订单池内按收益降序取 Top N → 整单原样，不优化。
  • ④ 特定单量：结算字段配置了豁免权值且订单该字段原值=豁免权值 → 该字段原样；未配置豁免权值则跳过此校验。
  • ⑤ 书籍ID：书籍ID/短剧ID 命中时使用专属比例（可 >100%），未命中用结算字段比例；计算 floor(原始值 × 比例%)，字段级独立截断取整。
