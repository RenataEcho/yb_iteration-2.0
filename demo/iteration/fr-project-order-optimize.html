订单优化 FR-005 v1 当前

纯管理后台能力：导入合作方原始订单 → 按项目已启用的共存策略批量优化 → 生成优化记录与可下载 Excel。无 C 端呈现；优化结果供内部结算/下发使用，原始数据保留对账。

以下配置项同时生效、共同开启，非互斥选项。保存后作用于下一次「导入原始数据并执行优化」。

默认结算比例

参与结算的每个字段独立计算：floor(原始值 × 比例%)，截断取整，不四舍五入；比例可超过 100%。

书籍 / 短剧 ID 差异化比例

命中匹配值时，该订单结算字段使用专属比例；未命中仍用默认比例。

FR-005 · 需求规则 · v1

1业务目标

合作方原始订单导入后，平台按项目策略对参与结算字段批量优化，输出优化后 Excel 供内部使用。无 C 端呈现；原始订单保留对账。

2后台 Tab

  • 优化策略配置：一整块配置面板，默认比例、ID 比例、前几名、特定单量豁免等共存生效。
  • 优化策略白名单：分「用户白名单」「关键词白名单」两张表；字段含所属项目、状态（启用/禁用）、添加时间；支持新增、编辑、删除、批量导入。
  • 优化记录：导入原始数据 → 执行优化 → 列表展示汇总指标；支持下载优化后 Excel、删除、查看对比。

3优化记录字段

  • 项目名称、优化前/后订单量、优化前/后累计金额、优化时间。
  • 操作：下载优化后 Excel、删除（需确认）、查看对比（抽屉展示逐单原始 vs 优化）。

4策略口径

  • 比例：floor(原始值 × 比例%)，字段级独立计算。
  • 整单豁免：用户白名单 / 关键词白名单 / Top N 前几名。
  • 字段豁免：特定结算字段=配置值时不优化该字段。
  • ID 比例：书籍ID/短剧ID 命中时使用专属比例，可 >100%。
