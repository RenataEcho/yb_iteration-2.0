# 剪辑供稿 · 操作说明

上传只在电脑「创作者中心 → 剪辑供稿」。手机 App 不能交稿。

---

## 操作步骤

### 1. 进页

1. 电脑打开创作者中心，点左侧 **剪辑供稿**。
2. 身份行应是 `昵称 · 右豹 ID · 分成 xx%`。若显示「未录入剪辑手」，先扫顶部招募图找客服，等后台录入后再传。
3. 点 **上传稿件**。

### 2. 传稿（三步，不能颠倒）

**第 1 步 · 填字段**  
选已授权且启用的项目、图集或视频、素材类型；填同一本书的名称 / ID / 链接。不要手填标题和大小。

**第 2 步 · 选成片**  
选文件夹或压缩包。图集：一个文件夹一条；视频：一个文件一条。压缩包会先「解压中」，解完再往下。

**第 3 步 · 核对后上传**  
看确认表条数和标题。发布技巧可手改，或点一次「AI生产发布技巧」。点 **开始上传**，去上传清单看结果。

### 3. 传完看清单

| 你看哪一列 | 正常结果 | 你要做什么 |
|------------|----------|------------|
| 上传 | 已上传 | 失败就点「重新上传」，只重失败文件 |
| 审核 | 已通过（或免审直接通过） | 审核中就等；已驳回先删再按原因重传 |
| 占用 | 空闲 | 占用中 / 已完成不能删 |
| 稿件状态 | 正常 | 已删除表示云端文件没了，不能再下、不能恢复 |

---

## 注意事项

**成片怎么放**

- 视频：文件名（去掉后缀）= 标题。只认 mp4 / mov / m4v / webm / mkv / avi。
- 图集：组文件夹名 = 标题，里面只放图片。不要把所有图平铺在一个大文件夹，也不要再套一层目录。
- 一次只传一个项目 + 一本书 + 一种类型。换书或换项目，重新走三步。
- 解压中、上传中不要关窗。

**云端会留多久、能不能删**

- 传上去一直没人领：**15 天后系统删除**阿里云文件，稿件状态变成「已删除」。
- 有人领过：领取人 **3 天内**可下载；文件再留到首次领取后 **7 天**，到期系统删除。
- 你自己点删除：阿里云**立刻一起删**，**不能恢复**。占用中、已完成不能删。
- 已删除的稿还在清单里，只是不能再下、不能再分享。

**不要做**

- 不要在 App 里找剪辑手上传口，没有。
- 不要先选文件再回头补项目 / 书。
- 不要把发布技巧写进文件名。
- 不要以为打开招募海报就等于已经录入。
