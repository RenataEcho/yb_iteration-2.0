# 剪辑供稿 · 剪辑手操作说明（PC）

> 给剪辑手看的上手手册。只讲电脑「剪辑供稿」怎么进、怎么传、传完怎么看。  
> 上传只在电脑；手机 App 里不能当剪辑手交稿。

---

## 1. 一句话

平台备好书和项目，你做成图集或视频交上去。用户领取后去发布；发布产生的关键词收益，按你的**分成比例**记到你这边。

---

## 2. 开始前先确认这三件事

| 必须满足 | 不满足时你会看到 |
|----------|------------------|
| 已加客服，后台已录入你的右豹 ID、分成比例、备注 | 看板是空的，点不了「上传稿件」 |
| 账号状态是「已录入」，不是「已停用」 | 和未录入一样，不能上传 |
| 至少有一个**已授权且启用**的项目 | 上传时选不到项目，或提示「该项目未授权或已禁用」 |

客服录入时还会登记「稿件是否需要审核」。你看不到、也改不了这个开关。默认要审：新稿先显示「审核中」。免审：新稿直接「已通过」。

**没有站内申请表。** 想入驻：打开「剪辑供稿」顶部招募图 → 扫客服二维码 → 等后台录入。录入完成、刷新页面后，看板才会出数。弹窗开着时如果账号被停用或项目被关掉，点「开始上传」会失败，先回看板看身份行和授权项目。

---

## 3. 从哪进

1. 用电脑打开右豹 **创作者中心**。
2. 左侧菜单点 **剪辑供稿**。
3. 右上角身份行应显示：`昵称 · 右豹 ID · 分成 xx%`。  
   若显示「未录入剪辑手」，先走招募，不要硬传。
4. 看板标题旁点 **操作说明**，页内打开这份手册。未录入也能看。上传清单同样有这个入口。

顶部招募图随时可点，侧栏展开海报（卖点 / 适合谁 / 客服二维码）。**打开海报不会开通上传权限。**

---

## 4. 最短路径（已录入剪辑手）

创作者中心 → **剪辑供稿** → **上传稿件** → 选项目 / 类型 / 素材 / 填书 → 选文件夹或压缩包（图集一夹一条，视频一文件一条）→ 核对确认表（可用 AI 补发布技巧）→ **开始上传** → 在上传清单看「已上传」和审核结果。

---

## 5. 成片怎么命名、怎么放（最容易传错的地方）

**成片** = 已经做好的图集文件夹或视频文件。系统按约定解析；约定不对会提示 `未按命名约定解析到数据`，一张表都出不来。标题用能看懂的中文，不要用 `IMG_0001`、`新建文件夹`。

第 1 步选定的类型必须和成片结构一致：选了视频就按视频放，选了图集就按图集放。对不上会解析出 0 条，或标题错乱。

### 传视频：一个文件 = 一条稿

文件名（去掉后缀）就是作品标题。只认这些后缀（大小写不限）：**mp4 / mov / m4v / webm / mkv / avi**。其它格式（如 wmv、flv）会被跳过，**不会单独报错**。选完后核对比一下条数和成片数。

```
我的这一批/
  第01集-女主觉醒.mp4
  第02集-反转来了.mp4
  第03集-真相揭晓.mp4
```

解析结果：3 条，标题分别是「第01集-女主觉醒」「第02集-反转来了」「第03集-真相揭晓」。

### 传图集：一个文件夹 = 一条稿

组文件夹的名字就是作品标题。组里只放该条图片（jpg / jpeg / png / webp）。不要混视频或说明文档。打包前清掉 Mac 的 `.DS_Store`、Windows 的 `Thumbs.db`，否则可能多出垃圾组。

```
我的这一批/
  第01集-女主觉醒/
    01.jpg
    02.jpg
    03.jpg
  第02集-反转来了/
    01.jpg
    02.jpg
```

解析结果：2 条。不要把所有图片平铺在一个大文件夹里——那样会被当成一组，只出一条。

**选中后的第一层必须是「一条稿一个文件夹」。** 不要再套一层，例如 `外层包/我的这一批/第01集/01.jpg`。多套一层时，多条可能收成 1 条，标题变成中间那层文件夹名。

### 用压缩包

把上面其中一种结构打成 **zip / rar / 7z**，再选「压缩包」。先出现「解压中」，解完再按同一套约定解析。解压未完成不要关窗；关掉须重新选包。

## 6. 上传：必须按这三步，不能颠倒

点 **上传稿件**，弹出窗口。顺序固定：**先填字段 → 再选成片 → 表格确认后上传**。不能先选文件再补字段。

**这一窗只能交「一个项目 + 一本书 + 图集或视频其一」。** 换书、换项目、改类型，必须重新走三步，不要把多本书塞进同一个文件夹或压缩包。

### 第 1 步 · 填字段

**投向**

- **选择项目**：只能选已授权且启用的项目。
- **稿件类型**：图集 或 视频。这一批只能选一种。
- **素材类型**：必选。只出现平台启用中的类型（以当下拉菜单为准）。
- **剪辑手**：当前登录人，不能改。

**书籍**（三个都要填，且必须是同一本）

向对接客服或项目对接人要这一本的 **书籍名称、书籍 ID、书籍链接**。本页没有选书器，不要自己编 ID，不要拿店铺页或搜索页链接凑数。

**这一步不要填标题、不要填大小。** 标题由文件名或图集文件夹名解析，大小由文件算出来。

填齐后点「下一步」。缺项会提示：`请填齐项目、书籍名称、书籍 ID、书籍链接、素材类型`。

### 第 2 步 · 选成片

1. 先点卡片，选 **文件夹** 或 **压缩包**。
2. 再点 **选择本地成片**，弹出系统选框。只点亮卡片、还没选出文件，下一步会提示：`请先选择文件夹或压缩包`。
3. 看摘要（条数、总大小）对不对，再点「下一步」。

| 选这个 | 系统会做什么 |
|--------|----------------|
| **文件夹** | 直接按上一节约定解析 |
| **压缩包** | 先「解压中」，解完再按同一套约定解析 |

压缩包还在解压时不能往下走。

### 第 3 步 · 确认表再上传

解析完成后出现一张表，顶部写 **共 x 条、大小 xxxG**。发布技巧列可以改成一段正文。

| 列 | 从哪来 |
|----|--------|
| 稿件 ID | 系统生成，你不用改 |
| 稿件名称 | 来自文件名或图集文件夹名 |
| 稿件大小 | 系统算出 |
| 发布技巧 | 一段正文，一般是空的，不会从文件名自动识别；可手改 |

需要发布技巧时，点一次 **AI生产发布技巧**：先弹出提示词、约束和规则，确认后整表各行生成一段；取消不写表。空着也能上传。用户领取成功后只看到这一段，可复制。不要把长文案写进文件名，指望它进「发布技巧」列。

核对条数和标题无误后点 **开始上传**。窗口关闭，跳到上传清单，稿件按条排队上传。

## 7. 传完看上传清单：三种状态别混

看板按钮「查看全部 list」打开的就是这张 **上传清单**（页标题仍可能写成「上传 list」）。关注三列。

### 上传状态（文件有没有交上去）

| 状态 | 你要做什么 |
|------|------------|
| 上传中 | 等。不要刷新或关页；上传中的稿不能删。关掉后若出现失败行，只重传失败的那几条。 |
| 已上传 | 文件和发布技巧已提交，接下来看审核。已成功的不要再传一遍，避免重复稿。 |
| 上传失败 | 点「重新上传」，**只重传失败的文件**，不会重推发布技巧。 |

### 平台审核（能不能进作品广场）

| 状态 | 含义 |
|------|------|
| 审核中 | 后台还没过。作品广场看不到。 |
| 已通过 | 且稿件仍空闲时，才会出现在作品广场。 |
| 已驳回 | 不进广场。清单写出原因（只读）。你不能把审核改成已通过。 |

已驳回的稿仍是「空闲」。按原因改成片后，**先删这条驳回稿，再传一版**。直接再传会留下旧驳回条和新稿两条。

「稿件是否需要审核」由运营改。要审则新稿先审核中，免审则直接已通过。你这边不能改审核结论。

### 占用（用户有没有领走）

**占用** = 已有用户领走，别人暂时看不到。  
**回填** = 领取的用户在 24 小时内把发布信息放到该项目回填页。这不是你改稿，也不是你去 App 填表。

| 状态 | 含义 | 能不能删 |
|------|------|----------|
| 空闲 | 还没人领，或超时释放回来了。已驳回也停在空闲。 | 可以删（会再确认一次），然后重传一版 |
| 占用中 | 已有人领走，对方应在 24 小时内回填 | 不能删 |
| 已完成 | 领取人已回填，不会再回广场 | 不能删 |
| 上传中 | 还在排队交文件 | 不能删 |

删占用中 / 已完成的稿，会提示：`仅未占用的稿件可删除`。空闲稿可以删掉再传；不能改审核结论，也不能动占用中的稿。

## 8. 看板数字怎么看

已录入后，看板四个数字：

| 数字 | 含义 |
|------|------|
| 已授权项目 | 后台给你勾过、且项目当前启用的数量 |
| 上传的稿件 | 你传到平台的全部条数 |
| 已被领取 | **占用中**（含 24 小时内尚未回填）+ **已完成**。超时释放回空闲的不再计入，不是「点过领取的历史总数」 |
| 已经产生的收益 | 只统计已完成、且已记到你名下的收益。审核中、占用中、未回填都不计 |

「已授权项目」只出数字，点开弹窗看名单，中间不再单开一栏标签。数字下面左侧是 **收益数据**（只含右豹端已结算稿，默认按日，可按月或自定义范围；查看全部进下一页，明细在抽屉里可导出），右侧是 **最近上传** 表。最近上传大约只留最近 4 条，列是项目 / 书籍 / 稿件信息 / 类型 / 审核 / 时间，**没有**上传状态、占用、删除。失败重传和删除都在完整上传清单里。

---

## 9. 传上去之后会发生什么（你这边不用操作）

1. 审核通过且空闲 → 用户在作品广场能看到。
2. 有人领取 → 稿件对其他人隐藏，占用中；你看板「已被领取」+1。
3. 领取人 24 小时内回填成功 → 占用结束，记已完成，不再回广场。
4. 满 24 小时没回填 → 稿件释放回作品广场，别人（以及原领取人）可以再领。
5. 领取所用关键词产生订单并结算后 → 按你的分成比例记一笔「作品代发收益」。待结算只累计，已结算才进明细。

你不需要去手机里帮用户领取或回填。

---

## 10. 请不要做这些

- 不要在 App 里找「剪辑手工作台」或上传入口，没有。
- 不要先选成片再回头补项目 / 书籍，弹窗不允许。
- 不要手填标题和大小，也不要把发布技巧写进文件名。
- 不要把多本书、多个项目打进同一个包。
- 不要把图集所有图片扔进同一个文件夹当「很多条」，也不要再套一层目录。
- 不要在「解压中」或「上传中」关窗。
- 不要删除占用中、已完成或仍在上传中的稿。
- 不要以为打开招募海报就等于已经录入。

---

## 11. 怎样算传完

上传清单里该条是 **已上传**，并且同时满足下面全部条件，用户才能在作品广场看见：

- 审核 = **已通过**
- 占用 = **空闲**
- 项目仍启用
- 你的账号仍是已录入
- 素材类型仍启用

缺任何一项，广场都看不到。刚传完若是「审核中」，等后台通过即可，不用重传。
