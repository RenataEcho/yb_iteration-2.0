FR-002 · 需求规则 · v1

1业务目标

在主子用户关系下增加「代发收益」能力：主用户可绑定多个子用户，经协议确认与子用户三方授权发布帐号后，关键词出单按「关键词→发布帐号→分配比例」自动分配。分配引擎口径与 FR-001 代发分配一致。

2页面与入口

  • 代发收益管理（主用户）：个人中心入口「代发收益」；顶部统计区：累计已分配（主大字）+ 子用户数、关键词数、授权帐号；右上角规则 icon + 「添加」按钮；列表区 Tab 切换「分配信息 / 子用户信息」。
  • 分配信息 Tab：按日 record-card 展示；标题「分配金额·xxx」+ 查看详情；三列统计：总金额、分配用户数、关键词数；底部分配时间。不展示「代发」标签与「系统自动分配，不可撤回」文案。顶部筛选仅保留时间（去掉状态选择）。点击下钻当日分配详情：顶部统计区 + 明细 list（每条 = 关键词卡片）。
  • 分配详情 · 明细卡片：标题 = {关键词} · {分配金额}；灰色信息域仅展示用户昵称、帐号昵称、账号ID。不展示发布平台标签、编辑入口、粉丝量、主页链接。
  • 子用户详情 · 分配明细：卡片标题 = {关键词} · {分配金额}（非「分配金额·xxx」）；三列统计：出单金额、发布帐号、分配时间。
  • 子用户详情 · 授权帐号：发布帐号卡片（平台徽章 + 昵称 + 灰色信息域：账号ID、粉丝量、主页链接 + 创建时间），无编辑操作。
  • 我的代发收益（子用户首页）：接受邀请并同意协议后默认进入本页；顶部统计区：累计已获得（主大字）+ 授权帐号数（底栏左右分布）；分配 record-card 标题「分配金额·xxx」；三列：关键词、发布帐号、分配时间；不展示「代发」标签与「系统自动分配，不可撤回」文案。
  • 子用户信息 Tab：头像卡片列表（昵称/ID + 协议状态 + 协议/邀请时间）；底部三列：已分配金额、授权帐号、分配比例；点击进入子用户详情（头像信息卡 + Tab 分配明细 / 授权帐号）。
  • 发起协议（主用户）：上方填写子用户 ID + 比例；下方展示分配信息与协议内容（布局参考子用户协议确认页）；底部「发送协议邀请」。
  • 协议确认（子用户 · 唯一接受页）：系统通知进入；展示分配信息与协议正文（rev_share_agreement）；同意/拒绝后分别跳转「我的代发收益」或返回；无额外 C 端授权页，三方发布帐号授权在平台外部完成。

3交互规则

  • 子用户视角闭环：接受邀请 → 同意协议（仅此一页）→ 进入「我的代发收益」；三方发布帐号授权在平台外部 API 完成，不在 C 端单独展示授权页。
  • 一个主用户可绑定多个子用户；每条主子关系独立维护协议状态与分配比例。
  • 分配前置条件：协议已同意 + 发布帐号三方授权有效 + 分配状态启用。
  • 代发收益首页分配 record-card 不展示「代发」标签与「不可撤回」说明；与 FR-001 代发分配 C 端展示区分。
  • 发布帐号授权走三方 API 对接，本 FR 不重定义三方授权步骤，仅展示授权结果。
  • 子用户「累计已获得」仅汇总本模块代发分配明细。

4边界规则

  • 代发收益分配记录不可撤回。
  • 协议「已拒绝」时不可参与分配；主用户可重发协议邀请。
  • 三方授权失效后，该发布帐号新出单不参与分配；历史分配记录保留。
  • 分配明细须包含分配时间字段（主/子/export 同步）。
  • 与 FR-001 代发分配：分配引擎复用，关系模型与授权方式独立，同一发布帐号不建议同时参与两套代发（互斥规则待技术确认）。

5业务流程

前后端交互与校验逻辑见页内 Tab 「业务流程」（流程图，含校验节点）。

涉及：协议邀请确认、三方发布帐号授权、关键词出单→分配明细。

1业务目标

为代发收益提供运营/研发可查的数据面：主子分配关系、三方授权发布帐号、代发关键词收益与分配明细，支撑问题排查与对账。

2数据表与字段

主子分配关系表：ID、主用户ID、子用户ID、分配比例、协议状态、分配状态、发布帐号数、已分配金额、创建/更新时间；操作：详情、编辑、重发协议。

列表顶统计区：已分配金额、待分配金额、启用关系、待确认协议（仅 Demo 展示，口径由后端定义）。

协议内容：复用现有说明内容配置（rev_share_agreement），本 FR 不单独设计协议配置页。

发布帐号表：ID、帐号昵称、帐号ID、主页链接、子用户ID、授权主用户ID、三方授权状态、帐号平台、状态、授权时间；操作：日志。

代发关键词表：关键词、项目方、主用户、发布帐号、所属子用户、累计产生收益、累计分配、数据更新时间；操作：详情。

关键词详情 list（详情抽屉 · 合并 6 列）：收益金额、收益产生时间、收益结算时间、分配金额、分配时间、分配批次。

分配记录表（扩展字段 · 本需求仅定规则）：分配行为 = 系统自动；业务来源 = 代发收益。

3列表与筛选

主子分配关系筛选：关系 ID、主用户 ID、子用户 ID、协议状态、分配状态。

发布帐号筛选：发布帐号 ID、帐号昵称、帐号 ID（平台唯一）、子用户 ID、主用户 ID、三方授权状态、帐号平台、状态、授权时间范围。

代发关键词筛选：关键词、项目方、主用户 ID、子用户 ID、发布帐号 ID/昵称、更新时间范围。

关键词「详情」以 overlay 抽屉展示合并 list，不挤压列表页宽度。

4边界规则

  • 已删除/失效发布帐号保留历史记录，状态分别标记为已删除/授权失效。
  • 关键词累计产生收益、累计分配以数据更新时间为准展示。
  • 代发收益分配写入时 分配行为=系统自动，业务来源=代发收益。
  • 三方授权回调失败或超时时，C 端展示授权中/失败状态，不写入有效授权记录。
